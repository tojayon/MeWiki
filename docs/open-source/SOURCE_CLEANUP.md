# 公开源码清理记录

日期：2026-11-09。清理对象是 MeWiki 程序源码、默认示例和测试资料。没有修改真实笔记、符号、附件、历史或本机资料库设置。清理阶段未初始化 Git 或上传；后续首次源码提交另见[提交说明](SOURCE_PUBLICATION.md)。

## 已处理

- 核心工厂与应用共用 `meWikiExamples.ts` 中的线性关系和内容块示例。首次启动仍包含 `docs/wiki/` 生成的完整手册；词典默认只有 x、y、a、b 四个通用条目。
- 从笔记、词典、分类和理论地图移除研究模型种子。删除模型笔记、LQR 推导、对象离散化、时序和环路内容的生成与自动改写模块。
- 资料读取不再补入专用笔记、词条、主题、标签或关系，不再替换正文、数学记号和来源，不因默认内容更新而移动用户内容。
- 移除只针对旧生成器的测试；编辑、复制粘贴、角标、引用、地图、资料库与媒体检查使用通用测试数据。增加资料隔离与版本兼容回归。
- 清理界面中的研究专用占位说明，保留外部程序开放接口与可选 WebBench 插件。

## 兼容边界

保留版本 1–8 的笔记读取和既有资料格式名。有效保存的笔记、符号定义、说明、标签、引用、结果 ID 与地图配置继续读取；缺失来源保持可识别的失效引用，不凭标题匹配到另一篇笔记。

旧命名槽位按保存的模板转换成右上、右下、右侧三个位置。纯编码兼容表 `researchLegacySymbols.ts` 用于历史数据中模板与公式位置编码不一致的情况，只含 ID、记号和槽位布局，不含名称、含义或笔记正文，也不会生成新词条。已经保存为三个位置的数据不添加括号、不改变上下标。

词典定义缺失时保留原公式与绑定，不用错误占位覆盖已保存的 TeX。混合公式只有在位置转换后的重建没有错误时更新缓存；仅转换公式输出不会重建正文。兼容表只读取自身条目，特殊符号 ID 不会误命中对象继承的属性。

有效的空笔记库与空词典保持为空；无效或不支持的缓存仍使用应用传入的首次启动恢复入口。普通刷新不会重新生成已删除的示例，显式打开帮助只补缺失的手册页。

程序清理不会删除用户资料中原本保存的研究内容。公开源码时仍须排除 `.mewiki/`、真实资料库、附件原件、备份、日志和测试产物；具体见[发布清单](RELEASE_CHECKLIST.md)。
