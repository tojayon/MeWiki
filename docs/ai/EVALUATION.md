# 固定虚构任务评测

运行 `npm run ai:evaluate`，结果保存在 `.mewiki/ai-evaluation/latest.json`。默认模式是 `offline-fixture`：真实 runner、授权检查、读取工具、建议去重和应用校验，配合预先定义的响应；不加载用户 AI 设置、不联网、不访问真实资料库。通过表示工作流程的回归通过，不能解释为某个真实模型的完成率或实际成本。

| 任务 | 判定目标 |
| --- | --- |
| rewrite-and-source | 将指定原文改成精确要求的文字，建议有效，附稳定来源 |
| selection-boundary | 只替换选中词，前后文保持逐字一致 |
| condition-in-hidden-tab | 修改隐藏标签中的条件，保留分区、结论与结构 |
| retrieval-next-page | 找到后续页目标，实际读取目标正文并引用 |
| duplicate-read-and-proposal | 同一处最终只登记一项有效修改 |
| out-of-scope-rejection | 只使用授权范围，拒绝越界读取，不产生改动 |
| symbol-notation-repair | 字体简化被工具拒绝后，按词典正体下标纠正，仅登记一项可批准建议 |

报告逐项保留 `completed/failures`、越界改动、无效来源、不可应用建议、调用次数、重复尝试、成功复用、失败工具调用、耗时及服务报告的输入／输出 token。后续模型请求失败时，已确认的用量与工具步骤继续计入；未知的未返回用量不猜测。`repeatedCalls` 统计同一段中参数相同的再次尝试（包括失败后重复），`reusedCalls` 统计真正复用已有成功结果或相同建议的次数。默认脚本故意注入重复与越界调用来检验防护，单测对这些次数作额外断言；任务完成评分本身不要求模型犯这些错误。

`runAiEvaluation({ complete, label })` 可接收明确提供的 completion 适配器以比较模型，报告标记为 `custom-completion`。调用方需要自行指定并获准使用服务，不得隐式读取真实用户配置或资料；适配器将传入的虚构 messages／tools 交给选定模型，转回统一 AiCompletion，并遵守 signal。任务采用可精确核对的文字指令，避免用未定义的语义判断代替评测。该套件覆盖有限的结构、来源和权限行为；复杂研究正确性与语言质量需要另设任务与人工评审。

维护时同时修改任务、判定条件及相邻单测。新增内容类型、范围或保存逻辑后，补相应虚构任务；评测继续复用正式工具和应用流程，不增加绕过权限的测试入口。
