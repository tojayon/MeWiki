# MeWiki 发展计划

以下为后续工作的顺序建议，不是已经提供的功能或发布日期承诺。已完成能力见 [README](../README.md) 和[变更记录](../CHANGELOG.md)。

## 首次源码提交之后

- 源码统一维护于 [tojayon/MeWiki](https://github.com/tojayon/MeWiki)，安全问题通过仓库私密报告入口提交。
- 在现有 Windows 与 Edge 干净验收基础上，补充其他平台的实机结果。
- 建立 GitHub 自动检查：代码检查、单元测试、构建及可复现的浏览器验收。
- 规划首个版本化 Release；若分发构建包或安装器，按实际范围核对字体、PDF 解码器和原生图像组件的许可、声明与来源材料。

当前源码范围与验证见[提交说明](open-source/SOURCE_PUBLICATION.md)，后续发行事项见[检查清单](open-source/RELEASE_CHECKLIST.md)。

## 优先完善

- 继续打磨编辑选择、公式输入、内容引用及手机阅读，重点处理焦点、滚动和长内容定位。
- 完善导入导出和备份恢复的说明、失败反馈及大资料库体验。
- 在已提供的声明式内容 API v1、图文导出 API v2 与本地安装基础上，按[插件分阶段路线](plans/2026-11-10-plugin-ecosystem.md)实现隔离执行与通用编辑器增强。
- 明确手册副本的更新与个人修改保留方式，避免用新版覆盖用户笔记。
- 用实际资料规模评估搜索、列表与地图性能，再决定优化范围。

## 插件生态

两类插件都纳入方向：外部工具与内容卡片、编辑器命令与面板及导入导出。P0、P1 与数据图文导出分支已落地，后续阶段独立验证：

1. P0（已实现）：统一随附与独立插件的数据契约，WebBench 使用同一清单与执行器，保留宿主 v1、内容和启停兼容。
2. P1（已实现）：声明式内容插件、本地 JSON / ZIP 安装、作者工具和独立示例、版本管理及卸载保留资料。
3. P1 扩展（数据贡献）：API v2 图文模板、平台画幅、PNG/JPEG、长图/分页、ZIP 与按库个人模板，不依赖第三方代码执行。
4. P2：隔离运行环境、能力代理和独立插件 API，再开放可执行包。
5. P3：通用命令、面板、用户选择范围内的可执行导入导出与编辑器增强。
6. P4：经审查的社区目录、官方与社区分发、手动更新和作者发布流程。

当前可从文件安装声明式内容插件与图文模板；没有任意脚本加载、通用编辑器贡献点或社区在线目录。实际契约见 [API v1](plugins/API_V1.md)与 [API v2](plugins/API_V2.md)，安装及作者流程见[插件开发入口](plugins/README.md)，长期架构见[生态设计](plugins/ARCHITECTURE.md)。图文导出的 HTML、PDF、自由画布和平台账户发布仍列为后续扩展。

## 后续探索

- 在现有中英文界面和双语 README 基础上完善英文手册，逐步增加其他界面语言。
- 桌面打包和更简便的升级方式。
- 可选的资料同步与协作。需要先设计账户、权限、冲突处理和附件传输，不能直接将本机服务改成公网服务。

新想法可以使用功能建议模板，说明具体任务、当前困难和希望改善的结果。
