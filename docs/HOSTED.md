# 官方在线版

[English](HOSTED.en.md) · [项目首页](../README.md) · [本地版使用手册](wiki/README.md)

觅维的正式在线地址是 **[https://wiki.mecore.cc](https://wiki.mecore.cc)**。无需安装本地程序，打开网页即可体验，或使用 MeAccount 登录后管理自己的在线资料。

## 访问与账户

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| 官方首页 | [wiki.mecore.cc](https://wiki.mecore.cc) | 登录与临时体验 |
| 在线工作区 | [wiki.mecore.cc/workspace](https://wiki.mecore.cc/workspace) | 登录后编辑与管理资料 |
| MeAccount 账户中心 | [accounts.mecore.cc/profile/](https://accounts.mecore.cc/profile/) | 统一头像与个人资料 |

点击首页登录入口后会跳转到 MeAccount，完成登录再返回 MeWiki。目前账户采用受控启用，是否可注册以实际登录页为准。MeAccount 管理身份，MeWiki 保存笔记和资料库；修改统一头像会用于已接入的官方产品。

## 先使用临时体验

首页点击“立即体验”，会为访客创建独立的临时身份和空间。同一浏览器的多个标签页可复用该体验，其他访客无法读取其中的资料。

- 默认最长使用 **2 小时**，连续闲置 **30 分钟**后到期，过期资料会自动清理。
- 最多 **20 篇笔记、5 MiB 当前内容**，不支持上传附件。具体限制以页面提示为准。
- 临时体验用于试用编辑、词典和地图；需要保留的内容应在到期前导出。
- 登录正式账户后切换到正式空间，**体验资料不会自动合并**。正式账户也不会因此读取访客空间。

## 本地版与在线版的范围

| 能力 | 本仓库的本地版 | 官方在线版 |
| --- | --- | --- |
| 身份与使用方式 | 本机运行，无需账户 | MeAccount 登录；另有临时体验 |
| 笔记、词典、公式、地图 | 支持 | 支持 |
| 资料位置 | 浏览器或自己选择的本地目录 | 服务器按账户、空间和资料库隔离 |
| 附件、历史、JSON／ZIP 备份 | 支持 | 正式账户支持；受在线配额限制 |
| 离线编辑 | 安装完成后支持 | 需要连接在线服务 |
| 自选 AI 服务、技能与审阅 | 支持 | 暂未开放 |
| 本地插件安装与本机目录、字体服务 | 支持 | 暂未开放 |
| 网页／DOI 信息抓取 | 支持 | 暂未开放 |
| 本地与在线自动双向同步 | 尚未提供 | 尚未提供 |

公共 GitHub 仓库维护本地应用与公共笔记核心。账户接入、在线数据存储和生产部署由独立服务版维护，公共仓库目前不包含完整的多用户自托管服务端。两端功能会逐步演进，以各自页面实际提供的入口为准。

## 数据与备份

正式在线资料的正文与历史保存在服务器数据库，附件由服务器存储；浏览器用于显示和本地缓存。退出账户或换一台设备，不会把已经保存的正式资料变为本机文件。服务使用 HTTPS、身份认证与服务端权限控制，按用户隔离数据；当前尚未提供端到端加密。

当前正式空间主要附件限额为**单文件 32 MiB、每资料库合计 256 MiB**。备份导入还会校验资料大小、附件引用和变更数量，通过预览再确认。大备份可先在本地整理为较小的资料库，并根据页面校验信息调整。

在“设置 → 备份与恢复”导出 JSON 或含附件 ZIP。**ZIP 适合完整迁移，JSON 只包含结构和附件引用**；远程网址不会自动转为附件原件。在线服务仍在持续完善，请为重要资料保留独立备份。

## 从本地迁移到在线

1. 在本地 MeWiki 确认资料已保存，进入“设置 → 备份与恢复”，导出**含附件备份（ZIP）**。
2. 打开 [wiki.mecore.cc](https://wiki.mecore.cc)，登录正式 MeAccount 账户。临时体验不用于含附件迁移。
3. 在线创建或选择目标资料库。**名称可以与本地不同**，恢复目标由当前选中的资料库决定。
4. 如果目标库已有内容，先导出它的备份。进入在线“设置 → 备份与恢复”，选择本地 ZIP，查看预览与校验结果，再明确确认导入。
5. 等待保存完成，检查笔记、词典、地图及附件，再继续编辑。在线库保留自己的历史，本地历史记录不会变成在线历史。

恢复会**替换目标库当前内容**，不是把两个库自动拼接。纯 JSON 不包含附件原件，迁移含图片、PDF 等内容时优先选择 ZIP。导入后，两边仍是独立资料库，后续编辑不会自动同步；反向迁移也通过备份完成。

如导入失败，保留本地原库和备份，查看页面给出的校验或配额原因。反馈问题可使用 [GitHub Issues](https://github.com/tojayon/MeWiki/issues)，提供复现步骤和已去除隐私的错误提示，不要公开自己的备份、登录信息或个人资料。
