# 快速开始

## 直接在线使用

官方在线地址为 **[https://wiki.mecore.cc](https://wiki.mecore.cc)**。无需安装，已有 MeAccount 账户可登录进入自己的工作区；目前账户采用受控启用。首页也可点击“立即体验”进入独立临时空间，默认最长 2 小时、闲置 30 分钟到期，不支持附件上传，登录后不会自动合并体验资料。

本手册主要介绍本地版。在线入口、功能范围与迁移指南见项目首页的[官方在线版说明](https://github.com/tojayon/MeWiki#官方在线版)；在线版目前暂未开放 AI、插件安装与本机目录等服务。**本地和在线资料不会自动同步**，可使用含附件 ZIP 备份迁移。

## 安装与启动

将 MeWiki 下载或克隆到自己的工作目录。安装 Node.js 22.13 或更新的受支持版本后，Windows 用户可以双击项目中的 `Start-MeWiki.bat`。启动器会检查依赖、构建应用并打开浏览器。保持启动窗口运行，关闭窗口会停止本地服务；停止前先确认页面显示已经保存。

首次安装需要连接网络下载依赖。安装完成后，文字、公式、地图、流程图和本地附件可离线使用。DOI 查询、网页信息和在线媒体仍需要联网。

也可以在项目目录的终端中执行：

```powershell
npm ci
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:5280`。开发时使用 `npm run dev`；修改源码后，正式运行需要重新构建，再重启 MeWiki 本地服务。

其他系统也可以使用上面的终端命令，或执行 `node scripts/start-mewiki.mjs` 自动准备依赖、构建并打开浏览器。当前主要验收环境为 Windows 与 Microsoft Edge，其他平台仍需补充实机验证。

## 第一次使用

产品中文名为“觅维”，英文名为 MeWiki，释义为“寻觅知识，以多维链接万物”。“觅”代表探索、寻觅知识；“维”代表维度、维系和链接万物，呼应 Me、M 标志与 Wiki。中文浏览器标签页和设置显示“觅维”，英文界面继续使用 MeWiki。

觅维工作区采用与 MeGit 一致的系列配色。浅灰白界面以深蓝标记当前选项和主要操作。

浏览器标签页使用深蓝底、亮青与白色笔画的圆形 M 标志，两侧白色笔画自然衔接圆外，不加灰色描边。“设置 → 关于觅维”使用方形图标，笔记左侧顶部只显示功能图标。方形图标的左下笔画和右侧飘带自然延伸至画幅边缘；添加为浏览器桌面应用或主屏幕快捷方式时，圆角由系统处理。应用图标和完整 Logo 随程序保存在本地；项目首页的“Logo 与应用图标”提供 SVG 原件和高清 PNG。更新后若标签页仍显示旧图标，可刷新页面，或关闭该标签页后重新打开。

首次打开会进入“MeWiki 使用手册”，左侧独立的“使用手册”标签页列出各章；切到“研究记录”可查看通用示例。左侧面板底栏最右侧的书本图标可打开或关闭手册标签页，悬停可查看操作名称，窄屏使用同一入口。切换列表后点击具体章节或示例才更换中间正文。默认阅读模式适合浏览，点击顶部编辑按钮开始修改。

建议先打开设置，选择新的本地资料库目录。应用会检查目录，再按提示迁移当前浏览器中的笔记与附件。成功后，资料直接保存在这个目录，适合长期使用和较大附件。具体见[保存与备份](15-storage-and-backup.md)。

## 创建第一篇页面

1. 切换“研究记录”，点击新建笔记。
2. 输入标题，添加例如 `项目/入门` 的标签。
3. 在正文添加文字块，输入一段内容；需要更多类型时，点击块之间的插入按钮。
4. 加入公式、图片或网页引用。
5. 退出编辑后检查显示效果，再观察保存状态。

标题显示在顶部导航栏。页面列表、正文和右侧辅助面板可以分别调整宽度或收起。窗口较窄时，工具会进入统一功能菜单。展开侧栏时，左开关位于左栏顶部最左侧，右开关位于右栏顶部最右侧；收起后，开关位于各自竖栏的第一个位置。

## 用示例练习

“线性关系基础示例”展示如何定义 `y = ax + b`；“内容块与引用示例”展示正文、行内变量、基础理论引用、表格、流程图和提示块。示例使用 `x`、`y`、`a`、`b` 四个通用词典条目，可以自行修改。

也可以在自己的测试页面插入“引用笔记内容”，在左侧分类表格找到基础示例，再在右侧渲染后的正文旁勾选段落或公式，点击顶部“插入引用”。后续修改来源，引用位置会同步显示最新内容。
