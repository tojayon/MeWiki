# MeWiki 使用手册

最近更新：[内容同步引用](07-links-and-references.md)支持直接阅读来源笔记并勾选段落、公式、图片等内容，来源修改后自动同步；[公共分类选择](03-pages-and-tags.md)统一页面和符号的搜索与标签表格；[插件与外部程序](19-plugins-and-integrations.md)介绍 WebBench 仿真回放的连接、插入与定位。

MeWiki 是在本机运行的 Wiki 文档编辑与管理工具。你可以组织页面、建立符号词典、编辑带来源的公式，把文献、媒体、数据和流程图放进同一份笔记，并通过反向链接、引用阅读和理论地图串起知识。

首次打开会看到本手册和少量通用示例。手册本身也是笔记，可以搜索、引用和修改；项目的 `docs/wiki/` 中另有完整 Markdown 原稿。顶部的“使用手册”按钮可以重新打开目录，并补齐被删除的手册页，保留已经编辑的页面。

程序更新后，项目中的 Markdown 原稿随之更新。资料库里已有的手册副本属于你的笔记，不会被新版原稿覆盖；可对照原稿补充需要的内容，或将所需章节作为 Markdown 导入新页面。

## 从这里开始

1. 阅读[快速开始](01-getting-started.md)，启动应用。
2. 在设置中选择一个新的本地资料库目录。长期使用和大附件建议使用本地资料库。
3. 在“研究记录”新建页面，添加标签，再用正文中的插入按钮加入文字、公式或媒体。
4. 学习[保存与备份](15-storage-and-backup.md)，导出一份含附件备份。

## 使用范围

MeWiki 当前用于单机资料管理，默认只监听本机地址。资料可保存在浏览器或你指定的本地目录；多人实时协作、云端同步、账户和网站发布尚未提供。公式关联和变量配方帮助梳理知识，数值计算与符号求解需要另用相应工具。

开始使用时可以阅读、编辑或删除“示例”标签下的页面。示例不包含原研究项目的真实笔记或附件。普通刷新不会重新生成已删除的示例。
