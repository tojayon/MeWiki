# MeWiki 使用手册

新增：[AI 服务与工作区](22-ai-workspace.md)，自行配置 API 地址、密钥与模型，检索阅读笔记、审阅应用建议并撤回修改。

在[界面与阅读](02-workspace.md#使用自己的界面字体)中了解如何给主软件选择或导入自己的字体，以及[分别调整界面与正文字号](02-workspace.md#分别调整界面与正文字号)：界面与图文导出共用资料库字体原件，字体选择和字号分别保存，支持刷新恢复和按库切换。

最近更新：[社交图文导出](20-social-export.md)的左侧设置分为可独立折叠的“内容、画幅、样式”，分类栏全宽且文字靠右；导出在浏览器新标签页打开，原笔记保留以便比对。模板菜单直接显示图标和功能文字；[界面与阅读](02-workspace.md)统一使用控件自身的焦点反馈，移除额外蓝色外框。系统与个人模板共用选择框并恢复整套参数，默认“MeWiki 原生”与前端正文共用样式，支持 PNG/JPEG、连续长图、多页图片和个人模板；[内容同步引用](07-links-and-references.md)支持直接阅读来源笔记并勾选内容；[插件与外部程序](19-plugins-and-integrations.md)介绍从文件安装、升级、版本切换和两类随附插件。

MeWiki 是在本机运行的 Wiki 文档编辑与管理工具。你可以组织页面、建立符号词典、编辑带来源的公式，把文献、媒体、数据和流程图放进同一份笔记，并通过反向链接、引用阅读和理论地图串起知识。

首次打开会看到本手册和少量通用示例。手册章节集中在左侧独立的“使用手册”标签页，不混入“研究记录”列表。顶部“使用手册”按钮用于打开该标签页，再次点击即可关闭；窄屏时在“更多笔记功能”菜单中操作。打开标签页只切换左侧列表，点击章节才在中间打开正文。章节列表支持独立搜索，右上角的关闭按钮也可关闭标签页。

手册左栏按“入门与界面、编辑与组织、词典与知识、媒体与数据、保存与维护、插件与导出”六类组织章节，沿用研究记录的分类表格、紧凑条目、分隔线和选中样式。点击分类可展开或收起，搜索框支持章节名、分类名和原有笔记标签，也可用键盘导航。已有手册会自动显示这些分类，无需重新导入；你修改过的标题、正文和笔记标签继续保留。

手册本身仍可搜索、引用和修改；关闭标签页不会删除手册，也不会清空当前正文或笔记筛选。开关状态在当前浏览器中按资料库分别记住。打开列表可浏览完整章节，实际点击章节时会补齐资料库中缺失的手册页，保留已经编辑的页面；项目的 `docs/wiki/` 中另有完整 Markdown 原稿。

程序更新后，项目中的 Markdown 原稿随之更新。资料库里已有的手册副本属于你的笔记，不会被新版原稿覆盖；可对照原稿补充需要的内容，或将所需章节作为 Markdown 导入新页面。

## 从这里开始

想先查看各种内容的实际效果，可以直接打开[内容类型展示](21-content-showcase.md)：从文字、公式到图表、音视频和 PDF，均提供可操作的本地示例。

1. 阅读[快速开始](01-getting-started.md)，启动应用。
2. 在设置中选择一个新的本地资料库目录。长期使用和大附件建议使用本地资料库。
3. 在“研究记录”新建页面，添加标签，再用正文中的插入按钮加入文字、公式或媒体。
4. 学习[保存与备份](15-storage-and-backup.md)，导出一份含附件备份。

## 使用范围

MeWiki 当前用于单机资料管理，默认只监听本机地址。资料可保存在浏览器或你指定的本地目录；多人实时协作、云端同步、账户和网站发布尚未提供。公式关联和变量配方帮助梳理知识，数值计算与符号求解需要另用相应工具。

开始使用时可以阅读、编辑或删除“示例”标签下的页面。示例不包含原研究项目的真实笔记或附件。普通刷新不会重新生成已删除的示例。
