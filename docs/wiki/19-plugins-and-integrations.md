# 插件与外部程序

MeWiki 可以独立使用，也可以嵌入其他程序。无论从哪里打开，笔记编辑与保存都由同一套 MeWiki 完成。

## 安装和管理插件

点击顶部工具栏的插头图标“插件管理”。空间较窄时，这个入口会收纳到“更多笔记功能”菜单中。

第一期提供“WebBench 仿真回放”插件。点击“安装并启用”后，编辑模式的内容插入菜单就会显示“插入回放位置”，独立窗口也可使用。停用或卸载后，已有卡片的标题、摘要和备注仍可阅读，原始来源数据也会保留；重新启用即可恢复相应操作。

目前安装的是 MeWiki 随附的插件，不需要下载文件或粘贴脚本。普通文本、公式、媒体等内容无需安装插件。

## 记录 WebBench 回放位置

### 在独立 MeWiki 中选择实验

1. 启动 WebBench 的回放查询服务，准备好需要引用的实验记录。
2. 在 MeWiki 中启用 WebBench 插件，打开笔记并切换为编辑模式。
3. 在内容插入菜单的“外部程序”中选择“插入回放位置”。
4. 从实验列表选择记录，输入可用时间范围内的物理时间，按需指定环路，点击“插入回放位置”。

默认回放查询服务为 `http://127.0.0.1:8766`，WebBench 为 `http://127.0.0.1:4173`。端口不同时，展开选择框中的“连接设置”修改，再点击“连接并刷新”。插入成功后会记住这两个地址。

服务未启动、列表为空或时间超出范围时会显示提示。可以刷新重试或取消，均不会向笔记添加空白卡片。

### 在 WebBench 中记录当前位置

1. 使用 WebBench 启动器打开仿真工作台，载入真实实验回放。
2. 移动到需要记录的物理时间，并选好环路和数据包。
3. 点击“科研研究笔记”，在内嵌的 MeWiki 中安装并启用 WebBench 插件。
4. 打开或新建一篇笔记，切换为编辑模式。
5. 在内容插入菜单中选择“插入回放位置”，填写观察备注。

卡片保存当前实验的身份、记录摘要、物理时间、环路、数据包与事件。它保存的是定位引用，完整的仿真数据继续由回放查询服务管理。

内嵌窗口已有真实回放时，点击插入会直接记录当前位置。尚未载入回放时，也可以打开上述实验选择框。

点击卡片上的“打开来源”，WebBench 会暂停播放并定位到保存的位置。即使当前已经换到另一个实验，它也会先载入对应实验，再定位。实验文件被替换或原始记录缺失时会提示原因，不会跳到别的实验。

在独立 MeWiki 中点击“打开来源”，会新开 WebBench 窗口并定位。原 WebBench 地址和回放查询服务需要仍然可用；端口变更时，可以重新从新地址插入引用。

旧版“回放证据”仍可阅读。旧格式没有保存文件摘要和完整服务地址，需要在原实验中重新插入新版卡片，才能获得可靠的跨窗口定位。

## 内嵌与独立窗口

两种方式使用同一 MeWiki 地址时，共用程序和资料库列表，可以分别选择 Cislunar 与个人 Wiki。每个窗口保持自己的资料库，独立入口与 WebBench 入口分别记住上次选择。WebBench 外层工具栏支持全屏、独立打开以及返回场景；“独立打开”仍保留 WebBench 入口的选择习惯。

在“切换资料库”中将研究资料库命名为 Cislunar 并“设为 WebBench 默认”，然后新建个人 Wiki，即可把资料分开。回放卡片插入当前窗口选中的库；切换资料库会取消尚未完成的内容选择。插件启用状态由同一 MeWiki 应用共用。具体操作见[保存与备份](15-storage-and-backup.md)。

首次迁移时，点击 WebBench 笔记窗口上方的“旧笔记迁移”：

- 原来使用本地资料库：查看提示的原目录，在 MeWiki 设置中检查并连接此目录，附件继续保存在原目录。
- 原来只保存在浏览器：从原 WebBench 地址导出旧浏览器笔记与附件，然后在 MeWiki 的设置中恢复 ZIP 备份。旧缓存不会被删除。

MeWiki 的浏览器缓存按网页地址区分，使用时固定采用同一地址，默认是 `http://127.0.0.1:5280`。资料库位于本地目录时，保存工作由 MeWiki 服务统一处理。

## 后续接入其他程序

其他程序可以像 WebBench 一样，主动提供当前内容，让你选择插入。它们不能通过这个接口直接读取笔记，或未经选择就写入笔记。

新的内容类型由相应插件提供显示和打开操作。开发者接入方式见项目的 `docs/integrations/README.md`。
