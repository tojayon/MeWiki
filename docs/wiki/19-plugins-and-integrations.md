# 插件与外部程序

MeWiki 可以独立使用，也可以嵌入其他程序。无论从哪里打开，笔记编辑与保存都由同一套 MeWiki 完成。

## 安装和管理插件

点击左侧底栏中、设置左边的插头图标“插件管理”，在按钮上方的小卡片中直接启停插件。勾选表示启用，取消勾选表示停用；悬停名称可查看用途。保存失败时卡片显示原因并保留此前状态。左栏收起时，点击竖栏中的任一工作区图标，临时面板底部仍提供相同卡片。

安装本地包、选择版本或卸载时，点击卡片底部的“管理插件”进入“设置 → 插件与集成”。也可直接从完整设置进入这一分类；关闭设置后回到原笔记和入口。

插件列表在名称旁显示版本和启用状态，右侧直接提供当前可用操作。“能力与来源”可展开查看插件标识、来源与支持能力；文件选择旁的信息图标提供安装与保留内容的说明，按 Escape 关闭后回到入口。安装预览仍直接显示名称、版本、来源与能力，供确认前核对。

目前随应用提供“WebBench 仿真回放”和“社交图文导出”。前者启用后在编辑模式的内容插入菜单显示“插入回放位置”；后者在“更多笔记功能”中提供图文导出入口，完整操作见[社交图文导出](20-social-export.md)。两者均可在独立窗口使用。停用或卸载后，已有卡片、原始来源数据及个人导出模板继续保留；重新启用即可恢复相应操作。

随附插件可在卡片中直接勾选启用，也可在完整管理页点击“安装并启用”。其他声明式内容插件和导出模板先从本地文件安装，再在卡片或管理页启用；普通文本、公式、媒体等内容无需安装插件。

### 从文件安装与更新

1. 从插件作者处获取 JSON 清单、ZIP 或 `.mewiki-plugin` 文件，在插件设置中点击“选择插件包”。
2. 核对安装预览中的名称、插件标识、版本、文件来源和能力，再点击“确认安装”。包最大 1 MiB，仅接受声明式数据，不运行下载的脚本。
3. 在列表中点击“启用”，返回笔记。内容插件在编辑模式的插入菜单中使用；导出模板在“更多笔记功能”中使用。
4. 更新时选择作者提供的新版本包。安装成功后重新启用；安装失败会保留原版本和启用状态。同一版本的不同内容不能覆盖，作者应发布新版本号。
5. 安装过多个版本后，可以用“已安装版本”选择旧版，再重新启用。版本切换不撤销已经写入笔记的内容；旧版不认识的新内容仍能阅读标题、摘要和备注。

卸载独立插件会移除它的安装包，笔记卡片和原始数据仍然保留，重新安装对应版本可以恢复显示与操作。目前从文件手动安装和更新，社区在线目录、可执行脚本插件及通用编辑器扩展仍待后续开放。

## 记录 WebBench 回放位置

### 在独立 MeWiki 中选择实验

1. 启动 WebBench 的回放查询服务，准备好需要引用的实验记录。
2. 在 MeWiki 中启用 WebBench 插件，打开笔记并切换为编辑模式。
3. 在内容插入菜单的“外部程序”中选择“插入回放位置”。
4. 从实验列表选择记录，输入可用时间范围内的物理时间，按需指定环路，点击“插入回放位置”。

默认回放查询服务为 `http://127.0.0.1:8766`，WebBench 为 `http://127.0.0.1:4173`。端口不同时，展开选择框中的“连接设置”修改，再点击“连接并刷新”。插入成功后会记住这两个地址。

服务未启动、列表为空或时间超出范围时会显示提示。可以刷新重试或取消，均不会向笔记添加空白卡片。

### 在 WebBench 中记录当前位置

1. 使用 WebBench 启动器打开仿真工作台，载入真实实验回放。
2. 移动到需要记录的物理时间，并选好环路和数据包。
3. 点击“科研研究笔记”，在内嵌的 MeWiki 中安装并启用 WebBench 插件。
4. 打开或新建一篇笔记，切换为编辑模式。
5. 在内容插入菜单中选择“插入回放位置”，填写观察备注。

卡片保存当前实验的身份、记录摘要、物理时间、环路、数据包与事件。它保存的是定位引用，完整的仿真数据继续由回放查询服务管理。

内嵌窗口已有真实回放时，点击插入会直接记录当前位置。尚未载入回放时，也可以打开上述实验选择框。

点击卡片上的“打开来源”，WebBench 会暂停播放并定位到保存的位置。即使当前已经换到另一个实验，它也会先载入对应实验，再定位。实验文件被替换或原始记录缺失时会提示原因，不会跳到别的实验。

在独立 MeWiki 中点击“打开来源”，会新开 WebBench 窗口并定位。原 WebBench 地址和回放查询服务需要仍然可用；端口变更时，可以重新从新地址插入引用。

旧版“回放证据”仍可阅读。旧格式没有保存文件摘要和完整服务地址，需要在原实验中重新插入新版卡片，才能获得可靠的跨窗口定位。

## 内嵌与独立窗口

两种方式使用同一 MeWiki 地址时，共用程序和资料库列表，可以分别选择项目资料与个人 Wiki。每个窗口保持自己的资料库，独立入口与外部程序入口分别记住上次选择。WebBench 外层工具栏支持全屏、独立打开以及返回场景；“独立打开”仍保留 WebBench 入口的选择习惯。

在“设置 → 资料库管理”中选择“默认资料库入口”，再将目标资料库“设为 WebBench 默认”或设为其他入口默认。入口来自插件声明、当前连接或已有设置，不按资料库名称猜选。设置默认库后，已打开的窗口继续使用原库，新窗口使用新的入口选择。卡片插入当前窗口选中的库；切换资料库会取消尚未完成的内容选择。插件启用状态由同一 MeWiki 地址下的浏览器窗口共用。具体操作见[保存与备份](15-storage-and-backup.md)。

首次迁移时，点击 WebBench 笔记窗口上方的“旧笔记迁移”：

- 原来使用本地资料库：查看提示的原目录，在 MeWiki 设置中检查并连接此目录，附件继续保存在原目录。
- 原来只保存在浏览器：从原 WebBench 地址导出旧浏览器笔记与附件，然后在 MeWiki 的设置中恢复 ZIP 备份。旧缓存不会被删除。

MeWiki 的浏览器缓存按网页地址区分，使用时固定采用同一地址，默认是 `http://127.0.0.1:5280`。资料库位于本地目录时，保存工作由 MeWiki 服务统一处理。

## 后续接入其他程序

其他程序可以像 WebBench 一样，主动提供当前内容，让你选择插入。它们不能通过这个接口直接读取笔记，或未经选择就写入笔记。

新的内容类型由相应插件提供显示和打开操作。开发者接入方式见项目的 `docs/integrations/README.md`。

声明式外部内容插件和图文导出模板已可独立开发和安装，示例及作者工具见 `docs/plugins/README.md`。图文导出只使用用户选择的内容，不让外部程序读取笔记；可执行插件、通用编辑器增强与社区目录按 `docs/plans/2026-11-10-plugin-ecosystem.md` 分阶段开放。

已启用图文导出插件后，可点击“打开图片创作”独立制作宣传图，也可从笔记更多菜单选择“图片创作”。画布由左侧画幅确定，支持文字、贴纸、装饰图、设备边框和批量套版；不需要先把电脑图片写进笔记。模板与可编辑作品分开保存，作品和贴纸按库隔离，停用或卸载继续保留。操作与备份见[图片创作手册](20-social-export.md#在画幅内添加文字和贴纸)。
