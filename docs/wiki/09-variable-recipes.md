# 变量配方

变量配方记录一个公式如何得到结果、需要哪些输入以及每项输入扮演什么角色。它帮助解释“这个量从哪里来”，适合较长的推导和公式复用。

## 建立配方

1. 在基础理论或研究记录中建立公式。
2. 声明结果变量，确认词典条目和角标。
3. 展开高级来源或配方设置，补充输入、条件和关系类型。
4. 在另一个公式使用结果时选择对应来源。
5. 打开变量依赖视图，逐层检查输入及其来源。

相同符号可以出现在多条配方中，使用时要结合条件判断哪条来源合适。

## 关系类型

| 类型 | 解释 |
| --- | --- |
| 显式 | 结果直接写成其他量的表达式 |
| 隐式 | 变量通过约束或方程关联，尚未直接解出 |
| 联合 | 多个量需要一起确定 |
| 共同涉及 | 记录共同出现的关系，尚未声明可计算方向 |

把共同出现误当成可计算依赖，会产生不正确的推导路线。应用按你声明的信息展示关系，不自动进行代数求解。

## 输入角色

可把基础量、参数、条件或外部输入区分记录。能够继续引用其他配方的量可以展开；作为基础输入的量保留在当前边界，便于审阅。

检查某一结果时，先核对单位、角标和适用条件，再沿来源追溯。出现循环时回到原公式确认关系是联合约束还是误连的单向依赖。

## 展开限制

为了保持复杂笔记可操作，依赖展开最多处理 160 个节点、64 层和 160 条配方。达到限制时缩小范围，或将推导分成几个中间结果。限制只约束这次展示，不会删除资料。
