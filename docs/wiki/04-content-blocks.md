# 正文与内容块

MeWiki 的页面由内容块组成。把文字、公式、媒体和数据分别保存为块，可以单独移动、编辑与引用。

想对照实际效果，可以打开[内容类型展示](21-content-showcase.md)。该页包含所有内置内容块，以及随应用提供的图片、音视频、PDF、三种数据图表和引用卡片，可以直接阅读、播放和翻页。

## 插入与整理

在编辑模式下，点击块之间或正文末尾的插入按钮，选择需要的类型。常见类型包括文字、标题、列表、表格、代码、提示块、标签页、公式、媒体、PDF、附件、网页、文献、数据图表、绘图和引用笔记内容。

点击某行内容前的三点菜单，选择“发送到 AI”，即可把这一行附加到“觅维 智能助理”，无需先选中文字。已有输入草稿会保留，填写处理要求后再发送；公式、列表、条件／结论和标签页内的内容也适用。操作与审阅说明见[AI 工作体系](22-ai-workspace.md#快捷提问与选中文字)。

拖动块的手柄改变位置，按页面反馈确认落点。标签页内也能插入和移动内容。多块选择、复制和删除应先确认选区；输入框正在编辑文字时，快捷键仍作用于该输入框。

阅读模式与[图文导出](20-social-export.md)不再预留插入手柄和隐藏编辑按钮的空间，内容块左右留白保持对称，标签页内的内容也取消编辑缩进。文字仍保持原有对齐，媒体和标签位置使用你设置的值；返回编辑模式后，操作按钮恢复各自的空间。

## Markdown 文字

正文默认采用所见即所得编辑。点击标题、粗体、斜体、删除线、行内代码、列表或引用中的文字，光标出现在点击位置，字号、字重、缩进与整体排版保持不变。提示块和标签页里的正文也采用相同方式；点击术语或符号仍查看详情，不会展开段落源码。

正文中的术语词汇与普通文字一样，可在行末从中间自然换行；未聚焦、正在编辑和阅读模式使用相同断行方式。符号引用也沿用正文公式的字号，聚焦编辑时不会缩窄符号或挤动后面的文字。

点击普通正文进入编辑、切换段落或退出编辑时，页面保持当前滚动位置，段落上下间距不变。长段落和列表中的行内公式在光标定位前就完整显示，不会先收缩再撑开文字；例如滚动到带有多处公式的列表中部，点击某一项的文字，可以直接在原位置继续输入。

选中文字后按 `Ctrl/Cmd+B` 加粗、`Ctrl/Cmd+I` 设为斜体；`Ctrl/Cmd+Alt+1` 至 `6` 设置标题层级，`Ctrl/Cmd+Alt+0` 返回普通段落。按 Enter 新起一段，在列表内继续下一项；Shift+Enter 在正文内换行，在列表内继续一项。任务列表的新项默认未完成。移开焦点保存，`Ctrl/Cmd+Enter` 完成本块，撤销和重做保留文字与格式。

要直接处理 Markdown 标记、图片路径或特殊写法，先点击正文，再使用本块右侧操作列中、删除按钮上方的“编辑 Markdown 源码”图标；同一位置的“返回排版编辑”可继续直观输入。提示块的设置按钮排在删除按钮下方，操作列不占用正文排版空间。代码块和表格的“编辑表格源码”入口保留各自的源码编辑方式。原有笔记无需迁移，保存与导出继续使用原有资料格式。

文字区域支持常见 Markdown，例如粗体、斜体、链接、列表、引用和行内公式：

```markdown
**重点**、*说明*、[网站](https://example.com)

- 第一项
- 第二项

行内变量 $x_i(t)$ 与公式 $y=ax+b$。
```

行内公式中与词典匹配的变量可点击查看符号详情。通过符号选择器插入可以明确关联条目，减少同形符号歧义。页面引用和符号插入见[链接与引用阅读](07-links-and-references.md)。

## 表格、代码与提示块

表格适合少量说明性内容，可编辑行列和单元格。普通表格和数据表统一采用深墨蓝表头、明亮标题文字与白色正文，外框和行列分隔线使用相同的深墨蓝；表头的强调、链接和编辑光标也使用适合深底的配色，在彩色或纹理背景上仍能清楚阅读。点击单元格编辑，按 Tab 在表头和正文之间继续移动，Enter 保存本格。需要导入较多观测数据或绘图时，使用独立的[数据与图表](13-datasets.md)块。

代码块采用近黑色终端背景、浅色文字和深色语言工具栏；指定支持的语言后提供本地彩色语法高亮，没有指定或无法识别语言时仍清晰显示原文。工具栏右侧可复制代码，编辑源码时也使用深色背景。行内代码使用紧凑的深色底片。网页、导出样板和生成图片使用一致的代码配色，代码只作为文档展示，不会作为应用程序执行。

提示块可以选择用途、图标和外观，适合备注、注意事项、结论或阅读提示。通过块设置调整，避免用多层边框堆积说明。

普通 Markdown 引用使用浅色实底和左侧竖线；标签页内的引用跟随标签页底色与文字配色。提示块与标签页继续保留各自设定的背景色，内部表格和代码使用独立实底，避免背景图案影响阅读。表格内文字和链接采用适合白底的深色，深色标签页里也能清楚辨认。

## 标签页容器

标签页适合把多个示例、不同推导或语言版本并列放置。修改页签名称，在每个页签内插入普通内容块；可调整页签外观和顺序。音视频离开所在页签时会停止播放。导出完整备份保留所有页签与嵌套内容。

## 引用其他页面的内容

选择“引用笔记内容”，在左侧标签分类表格中找到来源页面。右侧按原笔记的阅读样式显示完整内容，在段落、公式、图片等内容旁勾选，再点击顶部搜索栏同一行的“插入引用”。标签页可以直接切换阅读，既可选择整组，也可勾选其中的个别内容块。正文中会直接显示来源内容，来源保存修改后这里同步更新。引用内的内容只读，点击来源名称打开原页面修改；“修改引用范围”可重新选择。

引用按稳定内容块标识跟随来源，来源前面增删内容或移动所选块不会引用错位。新增的其他块不会自动纳入。引用范围限于当前资料库，删除来源或所选块会显示失效提示，可重新调整；系统拒绝循环引用。完整说明见[链接与引用阅读](07-links-and-references.md)。

例如项目总览需要展示技术笔记中的一段定义和一个公式：在总览中插入内容引用，选择技术笔记，只勾选这两个块。技术笔记新增其他说明不会改变引用范围；修改定义或公式后，总览会显示更新后的内容。

## 导出

单篇 Markdown 适合交换可读文本；媒体原件需选择“导出 Markdown 与附件”。要保留词典标识、公式来源、嵌套结构和所有附件，使用[含附件备份](15-storage-and-backup.md)。
