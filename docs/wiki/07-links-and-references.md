# 链接与引用阅读

页面、符号和公式来源通过稳定标识关联。改标题通常不会使内部链接失效；删除来源则可能影响引用。

## 在正文中直观编辑引用

正文和表格单元格进入编辑后，已关联的术语、符号、页面与本地附件仍显示名称、数学记号或引用标题，不显示链接源码。术语与符号跟随正文排版，悬停才显示下划线提示。每项引用是一个完整单元，光标只能停在其前后。术语文字在阅读、未聚焦和正在编辑时都可从中间自然换行，点击前后的断行保持一致；例如行末剩余空间不足以放下“端到端传输时延”时，可以把后半部分接到下一行。行末引用不会额外插入空行。

- **查看详情**：编辑模式下，直接点击已渲染的术语或符号会打开对应详情面板，所在段落、列表、提示块、表格和标签页保留渲染状态。点击面板外的正文关闭详情，并在点击处继续编辑，页面保持当前滚动位置；点击同一编辑区域会保留未保存文字与撤销记录。按 Esc 关闭并回到引用；例如点击句中的“均方误差”查看解释，随后点击相邻正文，整句仍显示粗体、公式等排版，光标停在点击处。
- **修改或更换**：先点击周围正文或单元格中的普通文字，把光标移到引用旁按 F2，或聚焦引用后按 F2，打开“编辑引用”悬浮面板。术语和符号在文字编辑过程中点击仍查看详情，粗体、标题等排版保持不变。通过“更换引用来源”选择同库目标；术语可以切换名称、规范全称、英文、缩写或具体别名，符号可以修改本次使用的角标，附件可调整 PDF 页码，引用标题中的页码也随之更新。点击“应用引用修改”保存，取消或 Esc 放弃面板中的修改。
- **查看出处**：在面板中使用“打开词典词条”或“打开引用来源”。词条含义由词典维护；切换本次引用的形式、来源或角标不会修改全局词典定义。
- **删除**：在引用前按 Delete，或在引用后按 Backspace，一次删除整项；也可以在面板中点击“删除此引用”，只移除当前位置的引用，保留相邻正文和来源笔记、文件。段落右上角的垃圾桶用于删除整个内容块。选区包含引用时同样整体删除。Ctrl+Z 可撤销，Ctrl+Y 或 Ctrl+Shift+Z 可重做。
- **复制**：在当前资料库内复制、剪切、粘贴可保留完整引用；向普通文本编辑器粘贴得到可读文字。跨资料库粘贴按可读文字处理，避免把引用绑定到另一库的条目。

符号引用在未聚焦和正在编辑时共用正文公式字号；一行包含多个符号或上下角标时，进入编辑也保持符号宽度与相邻文字位置。

原有笔记可直接使用，无需转换；保存和导出继续保留稳定链接。来源被移除时，仍保留原引用，可在面板中重新选择。正文直接按排版编辑，也可使用本块右侧、删除按钮上方的图标切换“编辑 Markdown 源码”；代码内容与“编辑表格源码”入口继续按源码编辑。

## 页面引用

在支持文字编辑的区域输入 `@`，搜索并选择页面，把引用插入正文。阅读模式点击后可在相邻阅读面板打开，方便一边写一边查阅。面板内的引用还能继续打开相关页面。

右侧阅读面板、同步引用及内容选择预览中的列表，沿用直接打开笔记时的词典引用样式。术语和符号平时跟随所在文字排版，不显示按钮边框或底色；鼠标悬停或键盘聚焦时才出现下划线提示。点击术语可在当前阅读位置打开解释悬浮面板，按 Esc 关闭后焦点回到引用文字。

应用内的 Markdown 页面链接形如 `#research-note/页面标识`。优先使用选择器生成，不需要自己记住标识。导入普通 Markdown 链接时应检查路径；外部相对文件链接不会自动变成资料库中的页面。

## 术语引用

正文输入 `#` 后，立即打开术语选择框，可以按术语名称、英文名称、英文缩写、中文缩写或别名搜索词典。在“术语引用形式”中选择本次显示名称、英文名称、中文缩写、英文缩写或一个具体别名／英文别称，再选择候选插入。同一句中可以多次引用同一术语，每次独立选择显示形式，自己输入括号、逗号和说明，自由组合出需要的写法。同一篇笔记的其他位置也可选择只显示 `MSE`；原有规范全称形式继续可用。`@` 只用于笔记引用。

行首输入 `#` 后继续输入空格即可正常编写标题，连续 `##` 至 `######` 也保留标题功能。代码、公式、已有链接和 URL 中的井号不打开选择框；取消会保留原文字。

各处引用独立保存形式，并随词典对应字段更新。先进入所在段落的编辑器，聚焦某处引用后按 F2，其选项同时标明类型与文字，“本次引用预览”展示修改效果；应用只改变这一处。未填写的名称形式会禁用并提示回词典补充。修改别名时保留同一行即可让已有引用同步；删除别名或清空缩写后，对应引用回退为术语名称。旧引用继续显示名称，首次出现的位置由写作者选择。详细示例见[符号与术语词典](05-symbol-dictionary.md#选择术语引用形式)。

## 在原位显示其他页面的内容

在笔记 A 的插入菜单中选择“引用笔记内容”，按左侧标签分类或顶部搜索找到笔记 B。右侧直接渲染 B 的内容，公式、表格、图片和标签页保持阅读样式；在需要的内容旁勾选，再点击顶部的“插入引用”。可以选择段落、公式、图片，也可以切换标签页，选择整组或其中的个别内容块。取消与插入按钮始终与搜索框同栏。

### 一次选择多个位置

1. 在 A 切换到编辑模式，在需要的位置打开内容插入菜单，选择“引用笔记内容”。
2. 在左侧展开标签分类，或搜索 B 的标题、标签，再选择 B。分类网格会为竖排的前置层级使用窄列，为横排的末级标签预留更宽的单元格；正文中的 `@`、内容引用和其他选择窗口共用这套布局。
3. 在右侧阅读已渲染的 B；内容旁的小方框用于选择，勾选后原位高亮。可以选择不相邻的多个内容块。
4. 遇到标签页时，先切换页签定位内容。勾选标签页容器表示引用整组，子内容随之选中；要仅引用某段，取消整组选中，再勾选对应子块。
5. 检查顶部已选数量，点击“插入引用”。修改已有引用时，同一位置显示“保存引用范围”；点击“取消”或按 Esc 会放弃本次选择。

右侧用于查阅和选择，修改正文仍需回到来源页面。内容块是最小引用单位；如果一个文字块包含多行，选择它会引用整个块。只需要其中一部分时，可先在 B 将那部分整理成独立内容块，再引用。

### 同步和范围

引用仅保存来源页面和内容块标识，A 中显示的是 B 当前保存的内容。B 改名或移动所选块后，A 仍显示正确来源并按 B 的当前顺序展示；B 新增的其他块不会自动加入。选择整个标签页会包含其后续内容变化，直接选择某个子块则只跟随该块。

引用区域只读。点击来源名称在阅读面板打开 B，再回到原页面编辑；在 A 点击“修改引用范围”可换来源或调整勾选。只能引用同一资料库的内容，个人库和 Cislunar 库不会交叉读取。最多直接选择 200 个块，嵌套引用最多 8 层，展开后的总内容也受大小限制。

删除来源或其中某块后会显示提示，保留引用设置供修复；系统会阻止循环引用。来源的反向链接中可以找到引用它的 A。

### 导出和迁移

完整资料库备份保留联动关系与附件。Markdown 导出包含当前可读内容和引用元信息；“Markdown 与附件”仅打包引用范围内实际使用的资源。单篇导入会把本篇内部的内容引用关联到导入的新副本；跨篇引用仍需资料库中存在原始来源，因此完整迁移请使用完整备份。

## 符号引用

在文字编辑器输入单个 `$` 或中文输入法的全角 `￥`，都可使用同一个符号选择器搜索词典，插入行内数学记号。例如输入 `￥年龄`，选择对应词条即可插入符号引用；插入后使用标准的 `$…$` 数学记号。也可以直接输入 `$x_i(t)$`；渲染后，能够匹配词典的变量可点击查看浮动详情。详情包含名称、本体与各位置含义，便于当场核对。

中文输入法仍在选字时不会弹出选择器，候选确认后按最终文字判断。只需要输入金额等普通文字时，按 Esc 或点击取消即可保留原文；代码、链接和已有公式中的 `￥` 不作为插入入口。

多条词典记录采用相同记号时，需要选择语义正确的条目。公式块中的结构化引用更适合需要精确追踪来源的情况。

## 公式来源

符号实例可关联来自其他公式的结果。先在来源公式声明结果，再在消费该结果的公式中选择来源。系统可以追踪使用关系，帮助检查符号是否来自预期理论。

有来源关联的符号、公式和页面受到删除检查。遇到保护提示时，查看引用列表并处理使用处；修改来源之后，相关核对状态可能需要重新确认。

## 反向链接与面板

右侧反向链接显示当前页面或符号被哪些内容使用。符号详情中的“使用此符号的公式”和“定义与计算公式”在该标签页集中查看。

多个引用阅读面板打开后，可以拖动边界调宽、关闭不需要的页面，或暂时收起左右侧栏。顶部功能按钮会随可用空间收纳，侧栏开关始终位于对应侧栏顶部或收起竖栏的第一个位置。

## 外部链接

普通网址可以作为 Markdown 链接或网页卡片保存。PDF 页码引用使用 `#page=页码`；原件需存在或网络来源可访问。迁移到另一台电脑时，使用[含附件备份](15-storage-and-backup.md)保留本地原件。
