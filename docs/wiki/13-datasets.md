# 数据与图表

在“数据与绘图”中插入“数据与图表”。可导入 CSV、TSV、UTF-8 文本和 `.xlsx`，或直接粘贴数据。旧 `.xls` 需先转换为 `.xlsx` 或 UTF-8 CSV。

## 导入数据

首行作为列名，后续行作为数据。CSV 支持引号、字段内换行和空值，TSV 使用制表符。示例：

```csv
时间,观测值,参考值
0,1.0,1.0
1,1.6,1.5
2,2.1,2.0
```

Excel 可以切换工作表。原件独立保存，刷新后仍可下载；需要重新选表时点击“重新读取工作表”。读取在后台进行，失败或超限会保留已有数据。

## 编辑与绘图

数据表每页预览 20 行。“编辑数据”使用 CSV 文本，点击“应用数据”更新数据和默认图表；当前不提供逐格编辑。

图表可选折线、散点和柱状图，选择横轴与最多 10 个数值系列。散点图需要数值横轴，其他图支持类别横轴。空值和非数值项跳过，折线遇缺失值断开。较宽图表可横向滚动。

分别使用导出 CSV、图表 SVG 和下载原件保存需要的结果。MeWiki 不执行导入数据里的表格公式；导出 CSV 在其他表格软件中的解释由对方的软件设置决定。

## 解析限额

| 项目 | 上限 |
| --- | --- |
| 单个待解析文件 | 10 MB |
| 每张表 | 10,000 行、50 列 |
| 数据单元格 | 200,000 个 |
| 数据总文本 | 2,000,000 字符 |
| Excel 工作表 | 100 张，总单元格和文本仍受上述限制 |
| Excel 展开内容 | 总计 32 MB，单条目 16 MB |

这些限额用于控制解析与预览。较大原件可以通过[普通附件](11-documents-and-attachments.md)保存，本地单文件上限仍为 1 GB。
