# 保存与备份

## 切换资料库

点击左侧底栏的数据库图标，在按钮上方的小卡片中直接选择已登记的资料库，勾号标记当前库。新建、改名、移除或调整默认入口时，点击卡片底部的“管理资料库”，进入“设置 → 资料库管理”。左栏收起时，点击左边竖栏中的任一工作区图标，临时面板底部也可打开同一卡片。每个资料库分别保存笔记、基础理论、符号、关系、附件和历史版本，共用同一套 MeWiki 程序。

资料库列表按名称、路径、当前状态与操作对齐。入口选择旁的信息图标可查看资料隔离和切换保存说明；按 Escape 关闭后回到入口。当前库与默认入口状态直接显示在对应条目中。

- **新建资料库**：填写名称和新的本地文件夹，创建包含完整手册与通用示例的新库。当前研究内容不会复制进去。
- **添加已有资料库**：选择已有的资料库文件夹并命名，保留该目录的内容和历史。
- **改名**：只修改列表中的名称，不移动文件。
- **从列表移除**：只取消登记，目录、笔记与附件仍保留。以后可重新添加；当前正在使用的库需先切换出去。

切换前会提交正在输入的文字并保存；保存或目标库读取失败时，卡片显示具体原因并保持当前资料，处理提示后可重试。切换成功后卡片关闭，键盘焦点回到资料库入口。每个窗口固定使用自己选中的库，其他窗口切换资料库不会改变这个窗口。切回未绑定本地目录的浏览器资料库时，也会读取其他窗口的最新修改。

独立打开 MeWiki 和从外部程序打开会分别记住上次选择。在“默认资料库入口”中选择 WebBench 或其他程序，再将目标库设为该入口默认；没有入口记忆或默认配置时进入原资料库，不按名称猜选。设置默认库后，已打开窗口仍保持原库，返回笔记也不会覆盖新设置。

### 将项目资料与个人资料分开

1. 原有笔记继续留在原资料库，不会自动搬动或复制。在入口列表中选择 WebBench 或相应外部程序，将项目资料库设为该入口默认。
2. 点击“新建资料库”，命名为“个人 Wiki”，选择独立的本地文件夹。
3. 在独立 MeWiki 中切换到“个人 Wiki”；WebBench 入口仍使用自己的选择。

原来仅保存在浏览器中的资料，可以先在当前库的设置中迁移到本地目录，再新建其他资料库。插件的安装与启用状态由整个 MeWiki 共用，插件卡片和其他笔记内容则归各自资料库保存。

如果另一个窗口从列表移除了当前库，页面会保留当前内容并提示。若有未保存修改，从卡片进入“管理资料库”，先“导出当前修改”，确认下载完成后再切换；这份 JSON 保留修改和附件引用，原件继续留在原目录。导出后又发生编辑时需要重新导出。

## 两种保存位置

| 模式 | 笔记与附件位置 | 适用情况 |
| --- | --- | --- |
| 浏览器模式 | 当前浏览器的数据目录，笔记缓存与附件分别保存 | 试用、小资料 |
| 本地资料库 | 你指定的目录，笔记文件与 `assets/` 原件 | 长期使用、大附件、迁移 |

浏览器模式普通附件单文件上限 100 MB，用户导入字体单文件上限 100 MiB，均受浏览器总配额影响；清理站点数据或更换浏览器后，这份数据可能不可用。MeWiki 使用自己的缓存命名，不会自动读取原系统的浏览器缓存。

本地资料库单个原件上限为 1 GB。插入文件会复制到当前资料库的 `assets/`，原位置不移动。页面删除或附件替换后，旧原件暂时保留，供历史恢复。各资料库的名称、目录与入口默认项记录在项目的 `.mewiki/research-library-settings.json`，这个设置文件与资料库本身分开。

## 配置资料库

打开“设置 → 存储位置”，输入新的目录，先检查，再按界面选择迁移当前笔记或打开已有资料库。页面标明当前资料库名称；这会修改当前库的保存位置。要保留多个独立资料库，请使用“资料库管理”中的新建或添加。迁移会先处理当前库的附件，校验成功后切换保存位置。同一目录只能登记为一个资料库，遇到已有文件时先检查预览。切换设置分类会保留尚未提交的路径输入。

正式资料文件目前名为 `research-library.webbench.json`。这是保留兼容的数据格式名，MeWiki 独立运行仍使用它；不要手工改名。正常使用通过界面编辑，避免在保存过程中直接修改文件。

读取旧资料时会转换必要的数据结构，保留已经保存的笔记、符号说明和引用。程序不会自动补入研究模型、改写正文或恢复已删除的示例。已有资料库中的手册页面也保留你的编辑，新版说明可从项目的 `docs/wiki/` 查看。

## 自动保存、冲突与历史

编辑后关注保存状态，等待完成再关闭服务。多窗口或外部文件变化可能引起版本冲突；系统不会直接覆盖新的磁盘版本。按提示保留当前副本，再读取磁盘并比较处理。

在“设置 → 历史版本”查看和预览恢复。本地资料库保留最近 30 个经过校验的历史版本，迁移备份单独放在 `migration-backups/`，用于升级恢复。历史记录与实时资料位于同一磁盘，应另做独立备份应对磁盘故障。

## 选择正确的导出

完整备份操作集中在“设置 → 备份与恢复”；单篇 Markdown 导出仍在笔记工具栏中。

| 操作 | 包含什么 | 适合用途 |
| --- | --- | --- |
| 导出完整备份（JSON） | 页面、符号、关系、附件引用 | 结构快照；原件另存 |
| 导出含附件备份（ZIP） | 完整结构与本地附件、封面、当前库已导入字体 | 换电脑、完整恢复 |
| 导出 Markdown | 单篇可读文本和附件引用 | 文字交流 |
| 导出 Markdown 与附件 | 单篇 Markdown 与相对路径原件 | 交给其他文档工具阅读 |
| 社交图文导出 | 所选内容的 PNG/JPEG、长图或多页图片与配套文案 | 社交平台分享 |
| 导出个人模板 | 图文样式、作者信息、内联图片和模板所用字体 JSON | 跨库复用、单独备份排版配置 |
| 导出作品备份 | 图片创作画布、共用图层、本批原图、文案、逐图调整和所用字体 ZIP | 恢复可编辑宣传作品、跨库复用 |
| 复制完整资料库目录 | 资料文件、原件、历史等 | 本地归档与迁移 |

网络在线引用在备份中保留网址。需要离线原件时先下载保存，再导出含附件备份。本地资料库流式打包；浏览器打包优先使用临时文件，暂存不可用时只允许不超过 32 MiB 的小包，较大资料应先迁移到本地资料库。

发布用图片不代替可恢复的资料备份。个人导出模板由 MeWiki 本地服务按库保存，现有资料库 JSON、含附件 ZIP 和单篇 Markdown 不自动包含它们；请在[社交图文导出](20-social-export.md)窗口单独“导出个人模板”，迁移后通过“导入个人模板”恢复。模板文件包含署名、头像及所用的导入字体，不包含笔记正文。

[图片创作作品和个人贴纸](20-social-export.md#保存图片设计与备份)也由本地服务按库和插件隔离保存，独立于笔记备份。作品首次手动保存后自动记录修改；迁移前从“图片设计操作 → 导出作品备份”另存 ZIP，到目标库“导入作品备份”恢复为新设计。备份包含本批原图和所用字体，不能用只含 PNG/JPEG 的成品 ZIP 代替。需要长期保留的个人贴纸也可放入设计随作品备份。删除作品、移除贴纸或停用插件均保留素材原件。

通过[界面设置](02-workspace.md#使用自己的界面字体)或[图文导出](20-social-export.md#导入与重复使用自己的字体)导入的字体属于同一套当前资料库资源。浏览器暂存字体在连接本地目录时一并迁移，含附件完整备份会带上字体；复制完整本地目录也会保留。资料库 JSON 和单篇 Markdown 不携带独立字体。需要在其他应用使用原字体，可在“设置 → 通用 → 界面字体”或导出“样式 → 本地字体”中选择后点击“下载原字体”。

界面字体的选择、界面字号和正文字号按资料库保存在当前浏览器，与导出模板字体、字号分开；备份包含原件，界面偏好需要在另一台设备或清理站点数据后重新选择。同一资料库迁移保存位置时保留稳定标识，当前浏览器的选择会继续生效。字号的独立调整与恢复见[界面与阅读](02-workspace.md#分别调整界面与正文字号)。

## 恢复

恢复 ZIP 前先设置本地资料库，再到“设置 → 备份与恢复”选择备份并查看恢复预览。原件与资料校验通过后再恢复笔记。恢复将改变当前资料，先导出当前备份。迁移具体步骤见[迁移已有资料](16-migration.md)。
