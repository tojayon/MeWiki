# 保存与备份

## 切换资料库

顶部工具栏的“切换资料库”（窄窗口中在“更多笔记功能”里）可以管理多套资料；底部的当前资料库名称也可点击打开。每个资料库分别保存笔记、基础理论、符号、关系、附件和历史版本，共用同一套 MeWiki 程序。

- **新建资料库**：填写名称和新的本地文件夹，创建包含完整手册与通用示例的新库。当前研究内容不会复制进去。
- **添加已有资料库**：选择已有的资料库文件夹并命名，保留该目录的内容和历史。
- **改名**：只修改列表中的名称，不移动文件。
- **从列表移除**：只取消登记，目录、笔记与附件仍保留。以后可重新添加；当前正在使用的库需先切换出去。

切换前会提交正在输入的文字并保存；保存失败时保持当前资料，处理提示后重试。每个窗口固定使用自己选中的库，其他窗口切换资料库不会改变这个窗口。切回未绑定本地目录的浏览器资料库时，也会读取其他窗口的最新修改。

独立打开 MeWiki 和从 WebBench 打开会分别记住上次选择。首次从 WebBench 进入时使用设为“WebBench 默认”的库；没有设置时优先选择名为 Cislunar 的库，否则进入原资料库。可以在列表里点击“设为 WebBench 默认”，已打开的窗口仍保持原来的库。

### 将 Cislunar 与个人资料分开

1. 原有笔记继续留在原资料库，不会自动搬动或复制。将它改名为“Cislunar”，点击“设为 WebBench 默认”。
2. 点击“新建资料库”，命名为“个人 Wiki”，选择独立的本地文件夹。
3. 在独立 MeWiki 中切换到“个人 Wiki”；WebBench 入口仍使用自己的选择。

原来仅保存在浏览器中的资料，可以先在当前库的设置中迁移到本地目录，再新建其他资料库。插件的安装与启用状态由整个 MeWiki 共用，插件卡片和其他笔记内容则归各自资料库保存。

如果另一个窗口从列表移除了当前库，页面会保留当前内容并提示。若有未保存修改，在“切换资料库”中先“导出当前修改”，确认下载完成后再切换；这份 JSON 保留修改和附件引用，原件继续留在原目录。导出后又发生编辑时需要重新导出。

## 两种保存位置

| 模式 | 笔记与附件位置 | 适用情况 |
| --- | --- | --- |
| 浏览器模式 | 当前浏览器的数据目录，笔记缓存与附件分别保存 | 试用、小资料 |
| 本地资料库 | 你指定的目录，笔记文件与 `assets/` 原件 | 长期使用、大附件、迁移 |

浏览器模式单文件上限 100 MB，受浏览器总配额影响；清理站点数据或更换浏览器后，这份数据可能不可用。MeWiki 使用自己的缓存命名，不会自动读取原系统的浏览器缓存。

本地资料库单个原件上限为 1 GB。插入文件会复制到当前资料库的 `assets/`，原位置不移动。页面删除或附件替换后，旧原件暂时保留，供历史恢复。各资料库的名称、目录与入口默认项记录在项目的 `.mewiki/research-library-settings.json`，这个设置文件与资料库本身分开。

## 配置资料库

打开设置，输入或选择新的目录，先检查，再按界面选择迁移当前笔记或打开已有资料库。这会修改当前库的保存位置；要保留多个独立资料库，请使用“切换资料库”中的新建或添加。迁移会先处理当前库的附件，校验成功后切换保存位置。同一目录只能登记为一个资料库，遇到已有文件时先检查预览。

正式资料文件目前名为 `research-library.webbench.json`。这是保留兼容的数据格式名，MeWiki 独立运行仍使用它；不要手工改名。正常使用通过界面编辑，避免在保存过程中直接修改文件。

读取旧资料时会转换必要的数据结构，保留已经保存的笔记、符号说明和引用。程序不会自动补入研究模型、改写正文或恢复已删除的示例。已有资料库中的手册页面也保留你的编辑，新版说明可从项目的 `docs/wiki/` 查看。

## 自动保存、冲突与历史

编辑后关注保存状态，等待完成再关闭服务。多窗口或外部文件变化可能引起版本冲突；系统不会直接覆盖新的磁盘版本。按提示保留当前副本，再读取磁盘并比较处理。

本地资料库保留最近 30 个经过校验的历史版本，迁移备份单独放在 `migration-backups/`，用于升级恢复。历史记录与实时资料位于同一磁盘，应另做独立备份应对磁盘故障。

## 选择正确的导出

| 操作 | 包含什么 | 适合用途 |
| --- | --- | --- |
| 导出完整备份（JSON） | 页面、符号、关系、附件引用 | 结构快照；原件另存 |
| 导出含附件备份（ZIP） | 完整结构与本地附件、封面 | 换电脑、完整恢复 |
| 导出 Markdown | 单篇可读文本和附件引用 | 文字交流 |
| 导出 Markdown 与附件 | 单篇 Markdown 与相对路径原件 | 交给其他文档工具阅读 |
| 复制完整资料库目录 | 资料文件、原件、历史等 | 本地归档与迁移 |

网络在线引用在备份中保留网址。需要离线原件时先下载保存，再导出含附件备份。本地资料库流式打包；浏览器打包优先使用临时文件，暂存不可用时只允许不超过 32 MiB 的小包，较大资料应先迁移到本地资料库。

## 恢复

恢复 ZIP 前先设置本地资料库，选择备份并查看恢复预览。原件与资料校验通过后再恢复笔记。恢复将改变当前资料，先导出当前备份。迁移具体步骤见[迁移已有资料](16-migration.md)。
