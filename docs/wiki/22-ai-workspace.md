# AI 服务与工作区

MeWiki 可以使用你自己的 AI 服务。先在“设置 → AI 服务”保存 API 地址、API Key、接口类型和模型，再通过左侧底栏设置旁的“AI 工作区”图标打开右侧“AI”标签。模型可以逐步检索笔记、阅读原文、查询词典，并提出笔记或术语修改建议。每项建议由你点击应用后才进入资料库。

## 右侧 AI 面板

AI 与大纲、反向链接、变量配方共用右侧面板，点击“AI”标签即可切换。底栏的 AI 图标也会直接选中该标签，并展开已收起的右侧面板；符号词典和理论地图等视图同样可以从这里打开。

AI 面板采用对话工作区：上方显示聊天历史、执行过的工具和修改预览卡片，底部固定聊天输入区。参考来源紧贴输入框上方左侧，滚动长对话时也保持可见；多条来源单行横向滚动，长标题省略显示，悬停可查看完整标题，点击打开对应笔记。桌面上可以一边查看 AI 结果，一边阅读或编辑中间的笔记。

每轮助手答复使用图标头像和深色底、白色文字的 MeWiki 徽标，悬停徽标可查看实际服务与模型。该轮工具记录放在回复正文上方，运行中展开，完成后可点击查看；该轮产生的“修改预览”卡片紧跟在正文后方。卡片仅汇总修改项数、涉及的目标数，并保留每项目标、操作和查看／应用／撤回按钮，不重复展示修改正文；同一目标的多项修改只计一个目标。具体内容在中间修改预览面板中查看。继续追问、关闭重开或刷新后，建议仍留在原答复中；没有正文的工具任务也会保留已生成的建议。

旧会话中无法确定所属轮次的建议，以及超出聊天保留范围的早期建议，显示在会话前方的“历史建议”区，仍可查看修改、应用或撤回。

会话标题与“清空会话”“AI 服务设置”“关闭AI 工作区”图标位于输入框下方，顶部只保留右侧面板的标签页。开始对话后以首条可见提问作为标题；长标题自动省略，悬停可查看全文。清空会话的确认在输入区旁显示，已应用的笔记内容保留。

点击底栏的统计图标“Token 使用记录”可查看逐次回复的输入与输出用量，最新记录在前，最多显示五条的高度，更多记录在面板内滚动。短窗口会进一步缩小记录区，保留输入框可用；点击外部或按 Escape 关闭。每次记录包含该条提问触发的所有工具调用轮次，运行中显示已报告的累计用量；停止或中断时保留已报告的部分。较大数值会缩写，悬停查看完整数量。

记录随本库会话保存，最多保留最近 100 次，清空会话时一并清除。旧会话只恢复最后一次已保存的统计，不补造更早的记录。服务没有报告的用量仍显示为零，不能据此判断是否免费。

AI 回复支持 Markdown，包括标题、粗体、列表、引用、链接、表格、代码和数学公式。代码块提供复制按钮；较宽的代码和表格在各自区域内横向滚动。你的提问保留原始文字与换行。回复中的 HTML 不执行，外部链接在新页面打开。

输入框下方显示当前模型、资料范围与发送按钮。点击模型名称向上展开“模型设置”，可选择已配置的 AI 服务并修改本次模型名称；点击菜单外部或按 Escape 收起设置。选择“当前笔记”或“当前资料库”决定工具可读取的笔记，两者均可查询当前库的词典；展开模型设置可查看具体笔记数量和范围说明。

在输入框按 Enter 发送消息，Shift+Enter 换行，也可点击向上箭头“发送消息”。中文输入法确认候选词不会发送。多行输入会自动增高，到达上限后在输入框内部滚动。回复期间发送按钮变为“停止任务”，仍可输入下一条追问草稿，待本次回复结束后再发送。

停留在历史底部时，新回复自动跟随；向上翻看旧消息时保留阅读位置。点击“返回最新消息”回到最新输出。切换右侧标签会保留任务输入，正在运行的任务继续执行；切回“AI”即可查看进度。窄屏使用相同的上下布局和右侧抽屉，查看正文时可用顶部右侧面板开关收起。

## 配置自己的服务

1. 打开设置，选择“AI 服务”，点击“添加服务”。
2. 填写便于识别的服务名称，以及服务商提供的 API 地址。通常使用基础地址，例如 `https://api.example.com/v1`；不要把密钥写进地址或笔记。
3. 选择该地址实际支持的接口：OpenAI Chat Completions、OpenAI Responses 或 Anthropic Messages。兼容服务需要选择它提供的协议，MeWiki 不会自动切换协议。
4. 输入 API Key 和完整模型名称。免密的本地模型服务可以留空密钥。可将一项服务设为默认，随后点击“保存服务”。
5. 点击“测试服务”检查模型响应、流式输出和工具调用。测试发送一条不含笔记的虚构请求，也可能产生少量费用。工具调用未通过时，先检查模型与服务兼容性。

“获取模型”读取服务的模型列表；没有该接口时直接手动填写模型即可。修改模型名称后需要再次保存。可添加多项服务，在工作区选择本次服务和模型；失败不会自动把资料发送给其他供应商。

已经保存的密钥不会显示回输入框。留空保留旧密钥，输入新值替换；“清除已保存密钥”需要保存后才生效。将地址改为另一个站点时，需要重新输入密钥，避免旧凭据被意外发送。多个窗口同时修改配置会提示重新加载，防止覆盖另一个窗口的保存。

## 执行笔记任务

1. 打开需要处理的笔记，点击底栏“AI 工作区”图标，或选择右侧“AI”标签。
2. 在底部选择资料范围，点击模型名称可调整本次服务与模型。“当前笔记”只开放当前笔记和本库词典；“当前资料库”开放当前库的普通笔记及词典，排除使用手册。
3. 在底部输入明确要求，例如“阅读当前笔记，检查定义的适用条件，提出补充建议，并给出来源”。
4. 按 Enter 或点击向上箭头“发送消息”。上方按对话显示你的要求与 MeWiki 回复，工具记录在正文之前，该轮修改统计卡片在正文之后；悬停 MeWiki 徽标查看实际服务与模型。参考来源固定在聊天输入框上方，Token 统计收在底部图标中。下一条消息可以继续追问。
5. 运行时，中间笔记区会跟随 AI 正在生成的修改；同一篇笔记的多处修改累积在一个页面，标题、列表、公式和表格直接显示为排版后的内容。右侧保留对话、工具进度和来源。任务结束后审阅差异，确认后点击顶部勾选，应用当前笔记的待审修改。也可从右侧每项建议的“查看修改”定位到对应位置。

还可以尝试“在本库搜索稳定性，整理带来源的综述草稿”或“查询词典中的稳定性，提出更明确的术语定义”。提问时缩小范围、指出目标和输出形式，更容易获得可审阅的结果。

资料范围决定哪些笔记可供工具读取；模型按需取得标题、片段和正文，并不会在任务开始时自动上传全部笔记。只有服务地址、模型和授权笔记范围均相同时，才会携带该范围的最近对话；切换后旧记录仍可查看，但不会进入新范围的请求。需要完全重新开始时可“清空会话”。

## 审阅、应用与撤回

预览中的流程图沿用笔记的[放大查看](14-diagrams.md#放大查看)：点击图形或放大图标打开独立窗口，按 Esc 返回审阅。查看不应用建议，也不改变原笔记。

任务开始后，中间先保留当前笔记，收到修改片段后逐步更新预览。顶部“正在修改”表示内容尚未生成完毕，此时不能应用。文字建议，以及原生块、笔记属性、已有词条中的字符串字段可逐步预览；数组、移动、删除和其他结构操作在完整建议到达后显示。未完成的修改只用于本次预览，不保存到笔记或会话；停止、失败、关闭、刷新或切库会丢弃这些片段，已经完整生成的建议仍可审阅。

点击“返回编辑”、按 Escape、选择其他建议或主动切换笔记会暂停自动跟随，可以继续手动编辑或阅读。任务仍在运行时，点击右侧输入区的眼睛图标“跟随 AI 修改”可返回最新修改。自动更新不会抢走输入焦点。服务需支持流式工具调用，并先返回完整的目标信息，才会逐步显示内容；集中返回完整工具调用的服务会在建议完整到达后显示。

支持的建议包括笔记新建、属性修改与删除，正文追加，原生内容块增删改与移动，标签页管理，符号与术语的完整可编辑字段，以及理论地图和关系。每项操作先生成建议，确认后才保存；有引用、字段无效或原文已变化时会拒绝执行。

| 内容 | Agent 可以提出的操作 |
| --- | --- |
| 笔记 | 新建、改标题／标签／属性、删除；保留内容的稳定 ID |
| 原生内容块 | 修改文字、公式、列表、提示、数据、图表、媒体说明和内容引用等可编辑字段，插入、删除或移动 |
| 标签页 | 读取容器与具体子块路径，新增、改名、删除和排序标签页，单独编辑里面的内容 |
| 符号 | 新建、修改、删除；名称、别名、记号、定义、分类、标签、单位、范围及三个固定索引位置的默认值和说明 |
| 术语 | 新建、修改、删除；中英文名称与缩写、稳定别名、原子词汇、定义、标签、范围和状态 |
| 理论地图与关系 | 创建、修改、删除地图，调整成员、角色与布局，管理笔记或地图的理论关系 |

例如“把‘通信事件’标签页改名为‘控制闭环通信事件’，改写里面的说明，保留另一个标签页”，Agent 会定位容器、标签页及子块，不再把 `examples` 容器一概视为不可编辑。修改公式时会保留并校验符号与结果来源，仍被引用的结果不能直接删改。

原生修改须先完整读取对应目标：单块和标签页先读取块及所属路径；删除整个容器还须读取将删除的子内容。整篇属性、删除和根层插入等操作需要读完笔记正文、属性及块清单的分页；已有词条要读取完整词条。地图仅可修改本次授权范围内且已完整读取的成员和引用，全局地图要求全库范围。大范围任务可能达到读取预算，需拆分。

外部来源的备注、位置和删除可提出建议；插件私有数据保持原样，不能由 Agent 修改或直接创建外部来源内容。附件只可引用本次授权笔记已有的资源，不上传、读取或删除附件原件。当前不提供图片创作、导出任务、插件安装或系统设置操作。

点击建议中的“查看修改”，中间笔记区进入修改审阅，右侧对话仍保留。同一篇笔记的全部待审修改共用一个页面，“修改文字块”和“修改内容块”使用相同的排版，不逐处翻页。差异出现在实际修改位置，前后原文和未修改的公式、图片等继续显示。

标签页容器只显示一套标签栏和当前页内容。点击其他标签，即可查看那一页累积的修改；有修改的标签带小圆点，标签增删与改名在栏内标红、标绿，顺序调整带箭头。右侧点击具体建议，会打开对应标签并滚动到目标位置，嵌套标签依次展开；删除的标签仍可在审阅中选择查看。预览中的选择不会改变笔记或原有浏览偏好，实时增量和任务结束时保留你的手动选择；再次点击右侧建议则重新定位。

| 差异显示 | 应用后的结果 |
| --- | --- |
| 红色底色、`−` 和删除线 | 这些文字会删除；整段删除也在原段落位置标红 |
| 绿色底色和 `+` | 这些文字会新增 |
| 相邻的红、绿内容 | 原内容替换为新内容；普通文字的较深底色突出实际改变的词句 |
| 普通排版的上下文 | 内容保留 |

默认使用笔记的渲染排版：Markdown 标题、强调、列表、链接、公式和表格显示为实际内容；复杂内容按整块显示修改前后的红、绿版本，普通文字保留词句强调。顶部代码图标“查看源码差异”可切换为源码对比，再次点击“查看渲染差异”返回排版视图；文字建议的源码提供行号，顶部 `+ / −` 统计其增加和删除的文本行数。

追加建议显示在真实页尾，新建笔记的正文全部标为新增；新增公式、表格等整体标绿。原生建议按具体子块、标签页、笔记属性或词条字段对比；地图与关系显示笔记标题和可定位的内容摘要。顶部左右箭头仅在涉及不同笔记或其他目标时出现，用于切换目标。运行中暂不能应用。

例如要求“把‘系统始终稳定’改为‘系统局部稳定’，删除过时假设，保留公式”，会先看到红色旧句和绿色新句，`始终 / 局部` 进一步突出；删除建议在假设的原位置单独标红，公式继续保留。改写优先在原文字块内进行；明确要求增加补充时才追加到页尾。

每项修改旁有一组图标，位于内容上缘，不遮挡正文；桌面悬停或键盘聚焦时更清晰，窄屏直接显示。标签页自身的改名、增加、删除和排序操作出现在对应页的内容顶部；修改页内文字的按钮紧贴该文字块，切换标签后即可处理。

| 图标 | 操作 |
| --- | --- |
| 勾选“同意此修改” | 只保存这一项，继续在当前笔记和标签页审阅剩余修改 |
| 叉号“拒绝此修改” | 从预览移除这一项，恢复其位置的原文；右侧显示“已拒绝”，可点击“恢复此建议”重新审阅 |
| 铅笔“调整此修改” | 在 AI 建议基础上继续修改，点击“保留调整”更新待审预览，再点击同意才写入笔记 |

例如改写了两个标签页，你可以先在第一页同意一处，再切换第二页拒绝另一处，无需逐处翻页。每组按钮对应右侧的一项建议；同一项包含多个字段时一起处理，不按单个词或单行拆分。全部处理完后返回正文，不自动跳到其他笔记。

调整正文时先显示排版，点击文字进入现有文字／引用编辑控件；公式提供输入与公式预览，标题和结构字段使用相应的输入框、选择框或列表。点击“取消调整”会放弃尚未保留的局部草稿；切换标签或退出审阅前需先保留想继续审阅的调整。删除、移动操作没有可调整的正文，可直接同意或拒绝。调整后的建议与拒绝状态按库保留，刷新后仍可继续；临时输入在“保留调整”前不保存。正在调整时，整页应用以及右侧对这一项的同意／拒绝暂不可用，避免跳过尚未保留的输入。

顶部勾选在同一笔记有多项待审修改时为“应用当前页面修改”，一次应用该页显示的全部待审修改；只有一项时为“应用建议”。返回箭头为“返回编辑”，按 Escape 也可退出审阅。悬停图标可查看名称。返回编辑后恢复原编辑器，键盘焦点回到打开预览的“查看修改”按钮，尚未应用的内容不会写入笔记。右侧仍可直接按项应用、拒绝或撤回。

同一页内对同一字段的多次改写以最后一项结果显示；如果组合后某项没有新增变化，会标为“已合并”，不另建撤回记录。一次应用前会检查整组建议，任一项存在冲突或不能组合时，整页都不会部分写入。逐项同意后，独立的剩余修改可继续处理；若其他建议也改了刚接受的同一句话，会提示冲突并保留已接受的结果。恢复已拒绝的旧建议也会重新校验原文，有冲突时需按最新内容重新生成。

窄屏审阅会占满正文空间，隐藏被覆盖的侧栏控件并暂停它们的键盘交互；返回后继续使用原面板。收起 AI、清空会话、切换笔记或资料库会结束当前预览，不会自动应用建议。

对已有笔记提出修改前，Agent 必须先通过工具阅读该笔记。应用建议时会重新检查资料库身份和原文；原文已变化会拒绝覆盖，请根据最新原文重新运行。只读、正在加载或存在保存冲突时不能应用。

预览与应用共用原文校验。原文已变化的旧建议仍可查看生成时的差异，但显示冲突并禁用应用；请先返回编辑，按最新原文重新生成。只读时可以审阅，切换编辑模式后才能应用。

已应用的建议提供“撤回此修改”。撤回仅恢复该次变更，目标内容若又被编辑，会提示冲突并保留后来的内容。对于同一笔记的连续修改，按相反顺序撤回。开始新任务不会自动撤销已应用的结果。

## 停止与恢复

“停止任务”会取消本次请求，停止后续工具调用，已经收到的回复和完整建议仍可查看，未完成的中央草稿清除。窄屏可直接使用中央工具栏的停止图标。点击输入框下方的关闭按钮、收起整个右侧面板或切换资料库也会停止请求；只切换大纲等右侧标签不会停止。重新展开或从底栏打开 AI 后可以查看中断记录，需要时重新发起任务。供应商已经处理的部分仍可能计费。

工作区会话按资料库 ID 自动保存在当前浏览器，包括已发送的提问、已收到的回复、来源、建议、可撤回记录和输入框中尚未发送的文字。切换右侧标签页、笔记或功能视图，关闭后重开，或刷新页面，仍可继续查看和编辑；不同资料库的对话与输入草稿各自保存。刷新前正在显示 AI 时，刷新后自动恢复 AI 面板；主动收起后保持收起，可以从底栏再次打开。

切到其他浏览器标签页或离开页面前，会立即保存最新已收到的对话与输入。切换浏览器标签页不停止任务；刷新时尚在运行的任务显示为中断，已收到的回复保留，需要重新发起，不会自动续跑。尚未完整生成的笔记修改预览不会作为正式建议或笔记保存。发送后清空输入框，只有手动“清空会话”才会同时清除聊天和未发送文字。

会话没有进入笔记备份；清理浏览器数据也会失去这些记录，已应用的笔记内容仍然保留。浏览器存储不可用或空间不足时会提示“AI 会话未能保存，请保持窗口打开。”，此时应先保留需要的文字。每个会话最多保留 40 项建议。

每次任务最多进行 32 轮工具交互、40 次工具调用，每轮最多 8 个工具，最多生成 20 项建议；读取量与上下文另有限制。达到预算后停止继续调用工具，尝试根据已有结果给出一次总结，并保留已完成的建议供审阅。连续三轮只有重复或失败调用时也会停止，避免反复读取原文、重复提出同一修改；相同文字改写会合并为一项建议。旧版“本次任务执行步数已达到上限”通常来自固定的 12 轮限制，现在改为上述预算及收尾提示。剩余工作可缩小到具体段落或标签后继续。

## 密钥、资料与费用

请求经过 MeWiki 本机服务发送到你选择的 API 地址。云端服务会接收到本次对话和工具返回的授权资料，费用由该服务商结算；MeWiki 不提供内置额度。使用本机模型地址时可以在本机推理。token 显示来自服务报告，未提供时显示为零，不代表免费。

服务配置与笔记分开保存在本机 `.mewiki/` 配置中。Windows 密钥由当前用户的系统加密保护；其他平台使用仅当前用户可读写的文件存储，不提供同等系统加密。密钥不放入笔记、会话、资料导出或浏览器本地存储，也不会从设置接口回显。迁移电脑时需要重新配置服务凭据。

当前检索使用关键词，不是向量语义检索；不会自动读取附件原件、PDF 页面文字或 OCR，不提供联网搜索、多 Agent 协作、任意脚本或系统命令执行。外部内容只提供可读的标题、摘要和备注，不向模型发送插件私有数据或附件二进制。服务能否完成复杂任务，还取决于模型的工具调用能力和上下文容量。

## Agent 如何随 MeWiki 更新

Agent 的工具说明和执行入口共用同一注册表。MeWiki 新增内容类型、修改资料结构、保存流程或权限时，开发者要同步检查 Agent 的可读投影、工具、测试和本手册。新增功能只有接入工具并通过验证后，才会出现在 Agent 的可用能力中。
