# 绘图与流程图

在“数据与绘图”中插入“绘图与流程图”。同一块分别保存 Mermaid 源码和手绘笔画，切换模式不会清空另一种内容。

## Mermaid 流程图

选择流程、时序或结构模板，编辑源码后实时预览。例如：

```mermaid
flowchart LR
  A[阅读资料] --> B[整理定义]
  B --> C[建立公式与来源]
  C --> D[检查结论]
```

语法错误会显示位置提示并保留源码，修正后恢复预览。渲染全部使用本地资源，可离线使用。为保持文档内容可控，不支持外部图片、HTML、交互链接和配置指令。

显示区域依据实际节点、标签和连线的完整边界校准，并保留留白；阅读区域或嵌套标签页变化时会重新校准，图形随可用宽度等比例缩放。导出的 SVG 使用同一完整边界。

源码最多 20,000 字符。大图建议拆成多个主题图，增加阅读空间也有助于检查关系。

## 放大查看

点击流程图，或点击图形工具栏的“放大流程图”图标，即可打开独立的矢量查看画布。打开时显示完整图形；把指针移到想看的节点上滚动滚轮，即可围绕该处连续放大或缩小。按住鼠标左键拖动画布可移动到其他节点。编辑模式、只读模式和标签页内的流程图均可使用。

工具栏提供缩小、当前倍率、放大和“适应画布”。点击倍率恢复到原始大小（100%）；点击“适应画布”重新居中显示全图。图形使用 SVG 矢量，在放大查看细小文字和连线时保持清晰。触屏可单指拖动、双指缩放。

例如，将上面的阅读流程切换成纵向布局：把首行 `flowchart LR` 改为 `flowchart TB`，再打开预览。先放大“建立公式与来源”节点查看文字，拖动查看后续步骤，最后点击“适应画布”返回完整流程。

点击关闭按钮、窗口外的遮罩，或按 Esc 返回原位置。键盘可聚焦流程图或放大图标，再按 Enter 或空格打开；聚焦画布后，`+`/`-` 缩放、方向键平移、`0` 恢复原始大小、`Home` 适应全图。关闭后重新打开会回到全图。查看不会修改源码、笔画、导出尺寸或笔记保存状态。空源码、正在生成或语法错误时，放大入口暂不可用；图形恢复后可继续打开。

## 手绘草图

工具提供自由笔、直线、箭头、矩形、椭圆和文字，可调整颜色与线宽，支持撤销和重做。画布保存矢量笔画，刷新后继续编辑。每块最多 500 笔，每笔最多 4,000 点，总计最多 50,000 点。

点击图形工具栏的“放大草图”图标，可在同样的查看画布中缩放、平移已保存的矢量笔画。笔记中的草图画布仍用于绘制，不会因绘制时点击而打开窗口。

只读模式可放大查看和导出 SVG。需要在其他矢量工具中处理时导出 SVG；要继续在 MeWiki 中编辑，保留完整资料库备份。

## 导出选择

Markdown 导出包含 Mermaid 代码，草图输出当前 SVG。完整备份保留两种模式及可编辑笔画。图形在其他 Markdown 阅读器中的表现取决于其 Mermaid 和 SVG 支持。
