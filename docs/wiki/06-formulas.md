# 公式编辑

公式块同时提供可视化的符号编辑与 LaTeX 输入。词典关联、角标和来源让公式可以被检查与复用。

## 连续输入符号与运算符

1. 插入公式块，打开符号编辑面板。
2. 在左侧搜索框输入文字，从自动筛选的下拉条目中选择符号。
3. 检查放大的符号预览。点击右上、右下和右侧位置输入角标或参数；已有值直接点击即可修改。
4. 点击插入符号，把当前符号加入公式。面板保持打开，可继续选择和插入。
5. 右侧按类别平铺运算符，像键盘一样点击插入；符号与运算符可以交替输入。

推导来源等高级设置默认折叠，需要时展开。图标的操作说明放在悬停提示中。

## 选择、复制与移动

先点击公式编辑区域取得焦点，再选择公式项。可选择单个或连续多个符号与运算符，用 `Ctrl+C`、`Ctrl+X`、`Ctrl+V` 复制、剪切与粘贴；同一公式和不同公式之间均可操作。`Ctrl+A` 在公式编辑区选择公式项，输入框内则选择输入文本。

拖动已选的公式项到插入位置可以改变顺序。复制多个项会保留顺序、角标和关联信息；跨资料库粘贴后检查词典匹配结果。来源已删除或目标词典缺少条目时，按提示重新关联。

使用撤销、重做修正刚才的编辑。公式内操作与正在编辑的角标输入框各有作用范围，先退出小输入框再选择公式项。

## 粘贴 LaTeX

展开 LaTeX 输入区域，粘贴公式源码，界面实时显示渲染预览。语法错误会显示位置提示，先修正，再检查识别出的符号、运算符和角标，最后确认插入或应用。

```tex
y_i(t) = a x_i(t) + b
```

匹配以当前词典为依据。TeX 宏、复杂环境和同形记号可能无法逐项还原；渲染成功也应核对结构化匹配结果。复制纯 TeX 适合与其他公式工具交换，完整备份更适合保留来源和词典标识。

## 换行、对齐和结果

工具栏的图标提供对齐和插入换行，悬停查看说明。插入换行后，空行的光标应位于下一行，可继续输入。多行公式可用来整理长推导。

为公式设置标题、适用条件和结果变量，便于其他页面引用。需要记录该结果依赖哪些输入时，展开来源或配方设置，详见[变量配方](09-variable-recipes.md)。应用记录定义与依赖，不自动证明等式或求解未知量。
