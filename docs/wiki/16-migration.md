# 迁移已有资料

MeWiki 保留现有研究笔记的数据格式和稳定标识，支持通过备份导入旧资料。独立应用不会自动打开原研究项目的资料目录，也不会把真实研究笔记作为默认示例。

## 从原系统迁入

1. 在原系统确认保存完成，导出“含附件备份”。如果没有附件，可导出完整 JSON。
2. 启动 MeWiki，在设置中配置一个新的本地资料库目录。
3. 先给 MeWiki 当前资料做备份，再选择恢复文件，检查预览。
4. 等待附件校验与恢复完成，检查几篇笔记、词典、公式来源、PDF 和媒体。
5. 确认保存完成后重新打开应用，复查资料能够读取。

原系统与 MeWiki 若同时打开同一个资料目录，会产生共同写入的风险。迁移时优先使用新目录，通过备份交换；不要让两个运行中的应用同时维护同一份文件。

## 换电脑或移动目录

导出含附件 ZIP，或停止编辑、确认已保存后复制完整资料库目录。在新电脑安装 MeWiki，配置目标目录，再恢复 ZIP 或打开复制好的资料库。项目的 `.mewiki/` 设置只记录本机路径，换电脑后重新设置。

仅复制 JSON 会缺少本地附件原件。仅复制 `assets/` 会缺少页面结构。纯 Markdown 可以阅读与导入文本，但无法重建全部稳定标识、来源、词典和地图关系。

## 兼容规则

当前笔记格式为第 8 版，受支持的旧版资料会在校验后迁移。文件名 `research-library.webbench.json`、格式 `webbench-research-library`、Markdown 的 `webbench-*` 标记和 `webbench-asset:` 引用为兼容资料交换而保留。

不认识的新版本、损坏文件或不匹配附件会提示错误。保留原备份，先核对文件是否完整，再按[排错说明](18-troubleshooting.md)处理，避免手工删除格式字段绕过校验。

## 导入后使用手册

恢复旧资料可能替换当前的初始页面。点击左侧面板底栏最右侧的书本图标可打开独立的手册标签页，再点击目录或具体章节阅读，缺失的手册页会在此时补入；再次点击按钮可关闭标签页。左栏收起时先点工作区图标临时展开，窄屏也使用同一入口。已有同标识的手册修改会保留，手册不会混入研究记录列表。普通刷新不会重新注入示例；需要参考时也可打开项目的 `docs/wiki/README.md`。
