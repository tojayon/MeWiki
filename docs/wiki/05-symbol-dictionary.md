# 符号与术语词典

正文中的稳定词典引用在编辑时也保持渲染显示：术语显示所选名称或缩写，符号显示数学记号。点击引用打开“编辑引用”，可以更换目标或本次显示形式、角标；只有在词典中编辑定义才会改变全局条目。引用整体删除、撤销与复制方式见[直观编辑引用](07-links-and-references.md#在正文中直观编辑引用)。

词典把符号和术语的名称、含义与使用方式集中管理。相同条目可在多个公式和笔记中使用；通过稳定条目 ID 引用后，修改名称或符号记号，所有已绑定内容会自动显示最新定义。

左栏顶部的“符号”和“术语”与基础理论、研究记录、理论地图并列，分别使用求和与原子图标，悬停图标可查看名称。点击图标只更换左侧列表；当前笔记或词条详情继续显示，点击列表里的具体词条后才打开它。只切换标签页时，正在编辑的词条草稿也会保留。符号保留 TeX 记号、角标和参数编辑器；术语记录规范名称、英文名称、英文缩写、中文缩写、逐条别名、含义、适用范围、标签和废弃状态。两类条目都支持搜索、层级标签和使用次数提示；术语也可按英文名称或缩写查找。

搜索、标签筛选与清除筛选在同一行，浏览另一类内容时该行同时显示新建按钮。点击漏斗图标选择标签，生效后漏斗变蓝，悬停显示当前标签；点击清除筛选同时取消搜索和标签限制。符号与术语分别保留自己的筛选条件，窄侧栏也不会把控件排到第二行。

左侧列表中的符号、术语条目名称加粗显示，名称、别名和说明统一靠右对齐。符号预览按公式的实际宽度分配空间，较长时单独占一行，文字在下方靠右显示；超过整行宽度的公式可横向滚动查看，分数和上下角标会保留完整高度。

阅读模式中的术语和符号引用默认跟随正文排版，不加粗、变色或常驻下划线。鼠标悬停或键盘聚焦时，术语显示点状下划线，符号显示虚线下划线；点击术语会在当前笔记上方打开解释悬浮面板，点击面板中的词典按钮才进入完整词条；符号仍按原有方式打开符号解释面板。键盘用户也可以用回车打开。

## 创建条目

点击顶部“符号”图标并新建符号，填写名称、本体的 TeX 记号、含义、单位和标签。名称用于搜索与一致性检查，记号决定公式显示。名称改动后旧名称会保留为别名，方便检查历史正文。标签用于分类，一个条目可以属于多个主题。

每个位置都有值和说明，建议一起填写：

| 位置 | 示例 | 说明示例 |
| --- | --- | --- |
| 本体 | `x` | 状态或输入变量 |
| 右上角标 | `k` | 迭代次数 |
| 右下角标 | `i` | 对象编号 |
| 右侧 | `(t)` | 自变量为时间 |

角标值可以留空。说明用于解释该位置代表什么；它与实际显示的值分别保存。示例中的含义由使用者定义，应用不会自动推断物理意义。

切换到“术语”，点击“新建术语词条”，填写规范名称和含义。英文名称、英文缩写和中文缩写均可留空，例如“均方误差”的英文名称为 `Mean squared error`，英文缩写为 `MSE`。编辑时“规范引用预览”显示组合后的完整称呼。中间还显示其他内容时，新建入口位于左侧搜索框旁；没有术语时也可以直接创建首个词条。

填写页按“命名与引用”“含义与使用”和“术语组成”分区。名称、英文对照、缩写与别名集中在“命名与引用”，规范引用预览随填写实时更新；“含义与使用”填写整体定义、适用范围与标签，含义和范围均可输入多行文字，适用范围的换行会保留在词条详情和解释悬浮面板中。名称和整体含义标记为必填。宽面板并排显示前两个分区，缩窄窗口或展开侧栏后会按实际可用空间自动变为单栏，填写中的草稿继续保留。

点击“新增别名”逐行记录中文别名、英文别称、旧称和常见写法，每行只保存一个别名；英文名称、英文缩写和中文缩写分别填在对应字段中，其他英文别称填入别名行。名称或别名不能与同类条目重复。逗号可以是别名本身的一部分，不再用于拆分别名。每条别名保留自己的身份，修改同一行的别名后，已绑定到它的引用同步更新；删除前面的其他别名不会让引用指向错误的条目。需要停用术语时可标记为已废弃，已有引用仍保留。

术语由多个基本片段组成时，在“术语组成”中逐项添加原子词汇。原子词汇必须按照术语名称的顺序完整覆盖，片段不能重叠；例如 `ABCDEF` 可以拆成 `AB`、`C`、`DEF`。每个片段都填写独立解释，保存前应用会检查组合拼接后是否与术语名称完全一致。没有拆分的旧术语会把完整名称作为一个可查看的原子词汇。

原子词汇编辑卡片以 `01`、`02` 等顺序编号，下方“当前组合”按相同顺序显示片段，便于核对覆盖情况。卡片右上角可删除该片段，“新增原子词汇”会在末尾添加一项。填写完成后点击底部“保存词条”或顶部勾选按钮；“取消编辑”或顶部返回按钮会放弃本次草稿。底部“标记为已废弃术语”与保存按钮放在同一区域，停用词条仍保留已有引用。

## 查看含义

中间详情把本体含义卡片放在符号左侧，右上、右下和右侧的卡片靠近对应位置。卡片四周彩色边框便于区分各部分。点击位置可以编辑，名称显示在顶部导航栏。

术语详情页只在中央显示一次完整术语名称，并保持在同一行；不在术语下方重复显示原子词汇文字。术语下方按原子词汇顺序排列几段可点击的下划线。解释小卡片在术语的下一行按原子顺序从左到右横向排列，通过连接线指向对应下划线。悬停中央术语中的对应片段时，该片段变为蓝色；点击片段或下划线可定位对应解释卡片。详情结构图会利用中间面板的全部可用宽度，空间不足时，长术语和卡片行各自横向查看，卡片始终保持一行；点击解释入口也会将对应卡片移入视野。下方继续显示术语整体含义、别名、范围和标签。修改术语名称或某个片段的解释后，已有稳定引用仍指向同一条目。

右侧“反向链接”汇总使用当前符号的页面和公式，也展示定义与计算公式的相关来源。修改或删除条目前先查看这里，确认影响范围。

## 在公式中使用

在公式编辑面板的搜索框输入名称、记号或相关词，从筛选结果选择条目。面板会显示实际符号预览；点击右上、右下或右侧位置，在小浮窗中填写这次使用的内容，再插入公式。

公式输入、结果符号、正文符号插入和同形符号含义选择，都使用与左栏相同的标签分类表格。分类可折叠，搜索会筛选条目；同一符号出现在多个标签下时共享选中状态。方向键选择当前可见条目，回车确认。

词典默认值方便重复输入，公式中的局部值用于当前一次使用。需要改普遍定义时修改词典，需要改一个实例时修改公式中的符号。

## 选择术语引用形式

在正文输入单个 `#`，立即弹出“插入术语”选择框，再继续输入名称、英文、任一种缩写或别名进行搜索。在选择器的“术语引用形式”中选择本次要使用的名称、中文缩写、英文缩写、英文名称或别名／英文别称，再点击相应候选或按 Enter 插入。每处引用单独选择，默认仍只显示术语名称。选择框只列出术语；笔记引用使用 `@`。

按方向键选择，Enter 插入，Esc 取消并保留原来的 `#` 和查询文字。行首输入 `#` 后继续输入空格会关闭选择框，照常编写 Markdown 标题；连续的 `##` 至 `######` 也不会触发术语选择。代码、数学公式、链接、URL 片段及转义写法 `\#` 中的井号保持原样，中文输入法候选确认后才显示词条。

| 引用形式 | 示例 |
| --- | --- |
| 术语名称 | 均方误差 |
| 仅英文名称 | Mean squared error |
| 仅中文缩写 | 均误 |
| 仅英文缩写 | MSE |
| 别名／英文别称 | 平方误差均值，或单独选择 Mean square error |
| 规范全称（原有形式） | 均方误差（Mean squared error, MSE） |

需要组合多种名称时，可以在同一句中多次引用同一术语，分别选择不同形式，括号、逗号与说明文字由自己输入。例如先插入“均方误差”，键入 `（`，再次输入 `#` 引用同一词条并选择“仅英文名称”，键入 `，` 后再引用一次并选择“仅英文缩写”，最后键入 `）`，即可写成“均方误差（Mean squared error，MSE）”。这三处引用分别跟随名称、英文名称和英文缩写更新，也可自由替换为中文缩写或某个英文别称；修改其中一处的显示形式不影响另外两处。

选择“别名／英文别称”后，每个别名单独列出，中英文别称都可以选择。缩写或别名形式在插入时只列出已填写的候选。原有“规范全称”形式继续保留，使用中文全角括号，英文名称与英文缩写用 `, ` 分隔；只填写其中一项时只显示该项，两项都为空时仅显示术语名称。

这些形式都绑定同一词条，阅读模式下点击均可打开术语解释面板。修改词典后，英文名称、缩写和别名引用随对应字段更新；某个缩写被清空或别名被删除后，对应引用回退为术语名称。旧引用保持原有的名称形式。需要更换已插入引用的显示形式时，切换到编辑模式，点击该引用，在“编辑引用”的“术语引用形式”中选择。选项同时显示类型和具体文字，下方“本次引用预览”显示应用后的效果；点击“应用引用修改”只更新当前这一处。没有填写的字段显示“未填写”且不能新选，可通过“打开词典词条”补充后再选择。

## 统一旧正文

打开条目详情中的“一致性检查”，可以预览所有笔记中仍以普通文本出现的名称、别名、英文名称或中英文缩写。每一处显示笔记标题、上下文和命中词，可分别选择：

- **绑定这处文本**：把普通文本转换成稳定的 `mewiki-term:<id>` 或 `mewiki-symbol:<id>` 引用，显示当前规范名称或符号。绑定后，术语名称或符号记号的后续修改会同步到这里；需要缩写或别名形式时，用 `#` 选择对应形式插入。
- **替换这处文本**：只把当前命中替换成规范名称，仍是普通文本，适合不需要长期追踪的文字。

扫描会跳过代码块、行内代码、Markdown 链接、数学公式和 URL，不会自动改写正文。建议先逐处确认语义，再绑定或替换；同一别名在不同上下文中可能代表不同条目。

## 行内符号

正文的行内公式中，与词典匹配的变量可以点击查看详情。使用符号插入选择器能保留明确的条目关联；在正文输入 `#` 可以选择术语，输入单个 `$` 或中文输入法的全角 `￥` 可以选择符号。中文候选确认后才显示选择器；使用 `￥` 选择词条后同样插入标准行内公式引用。稳定引用使用条目 ID，不依赖显示名称，因此改名或改记号不会丢失关联。若不同条目使用相同记号，检查所选条目和含义，不要仅凭外观判断。

详细操作见[公式编辑](06-formulas.md)与[链接与引用阅读](07-links-and-references.md)。
