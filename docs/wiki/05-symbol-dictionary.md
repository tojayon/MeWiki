# 符号词典

词典把符号的外观和含义集中管理。相同条目可在多个公式中使用，每次使用时填写不同角标和参数，而本体含义保持一致。

## 创建条目

进入“符号词典”并新建符号，填写名称、本体的 TeX 记号、含义、单位和标签。名称用于搜索与检查，记号决定公式显示。标签用于分类，一个条目可以属于多个主题。

每个位置都有值和说明，建议一起填写：

| 位置 | 示例 | 说明示例 |
| --- | --- | --- |
| 本体 | `x` | 状态或输入变量 |
| 右上角标 | `k` | 迭代次数 |
| 右下角标 | `i` | 对象编号 |
| 右侧 | `(t)` | 自变量为时间 |

角标值可以留空。说明用于解释该位置代表什么；它与实际显示的值分别保存。示例中的含义由使用者定义，应用不会自动推断物理意义。

## 查看含义

中间详情把本体含义卡片放在符号左侧，右上、右下和右侧的卡片靠近对应位置。卡片四周彩色边框便于区分各部分。点击位置可以编辑，名称显示在顶部导航栏。

右侧“反向链接”汇总使用当前符号的页面和公式，也展示定义与计算公式的相关来源。修改或删除条目前先查看这里，确认影响范围。

## 在公式中使用

在公式编辑面板的搜索框输入名称、记号或相关词，从筛选结果选择条目。面板会显示实际符号预览；点击右上、右下或右侧位置，在小浮窗中填写这次使用的内容，再插入公式。

公式输入、结果符号、正文符号插入和同形符号含义选择，都使用与左栏相同的标签分类表格。分类可折叠，搜索会筛选条目；同一符号出现在多个标签下时共享选中状态。方向键选择当前可见条目，回车确认。

词典默认值方便重复输入，公式中的局部值用于当前一次使用。需要改普遍定义时修改词典，需要改一个实例时修改公式中的符号。

## 行内符号

正文的行内公式中，与词典匹配的变量可以点击查看详情。使用符号插入选择器能保留明确的条目关联。若不同条目使用相同记号，检查所选条目和含义，不要仅凭外观判断。

详细操作见[公式编辑](06-formulas.md)与[链接与引用阅读](07-links-and-references.md)。
