# 理论地图

理论地图将笔记之间的依据和引用关系可视化，适合检查知识结构、发现遗漏的前提以及查看某条结论会影响哪些页面。

## 选择范围

| 范围 | 用途 |
| --- | --- |
| 全局地图 | 查看整个资料库的关系 |
| 主题地图 | 围绕选定主题组织相关页面 |
| 本篇地图 | 集中检查当前页面及其相关知识 |

切换“理论地图”工作区，使用范围与筛选控制展示内容。选中节点查看详情或打开原笔记。节点代表已有知识对象，连线来自记录的引用、依据或推导关系。

新建或设置主题地图时，通过标签分类表格多选引用笔记，可搜索标题和标签。编辑关系起点与终点时也使用同一分类表格，条目显示所属笔记与具体内容名称，方便区别整篇页面和其中的公式等内容。

## 建立可读的知识关系

在基础理论页面中区分前提和结论，将适用条件写清楚。研究记录中通过页面引用、基础理论依据和公式来源连接这些知识。地图根据保存的信息组织关系，不会根据相近的句子自动推断证明。

建议先建立少量高质量连接：一条定义、一组条件、一条结论和使用它的记录，再逐步扩展。发现不正确的关系时回到原页面修改依据或来源。

## 布局与检查

可使用地图提供的定位、缩放和自动整理功能查看大图。手动整理节点后保存当前地图；主题地图可以保留适合阅读的布局。节点较多时缩小范围，逐条核查比一次展开全部内容更容易理解。

核对状态表达人工审阅进度。来源发生变化后，重新检查条件和结论是否仍成立，再确认状态。

## 地图文件

地图支持导入导出独立文件。导入时检查匹配对象与提示，地图文件本身不能替代完整资料库备份；换电脑仍应迁移原页面、符号和附件。地图文件中的旧格式标识为兼容已有资料而保留。

对变量级依赖的追踪，使用[变量配方](09-variable-recipes.md)。
