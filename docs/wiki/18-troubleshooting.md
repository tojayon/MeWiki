# 排错与维护

## 启动失败或页面打不开

先确认 Node.js 为 22.13 或更新的受支持版本，并且依赖安装完成。双击 `Start-MeWiki.bat`，查看启动窗口提示。默认地址是 `http://127.0.0.1:5280`；端口被占用时先关闭旧 MeWiki 服务，或按 README 选择其他端口。

更新源文件后，正式运行要重新执行 `npm run build`，然后重启 **MeWiki 本地服务**并刷新页面。开发模式由 `npm run dev` 提供。不要通过删除资料库来解决服务仍加载旧代码的问题。

## 保存失败或资料看起来丢失

检查设置中的目录、当前浏览器和访问地址是否与原来一致。浏览器数据按站点保存，切换浏览器、端口或清理站点数据会影响浏览器模式。长期资料应迁移到本地目录。

保存报错时保留当前窗口，先按提示导出副本，检查磁盘空间、目录权限和是否有其他程序修改文件。冲突时保留当前内容，再读取磁盘版本。完整恢复使用含附件 ZIP 或完整目录备份。

## 媒体不显示或不能播放

先判断来源是本地附件还是网络链接。本地原件缺失可重新关联同一文件；网络来源检查是否过期、需要登录、允许外链。媒体格式支持不代表所有编码都可解码，可以下载原件用本机软件检查。

大图片可能只能下载查看。PDF 超过 100 MB 时使用独立阅读或本机阅读器。扫描 PDF 没有文字层时需要外部 OCR。浏览器模式超过 100 MB 的附件，先迁移到本地资料库。

## 公式无法匹配或复制

点击公式编辑区域取得焦点，确认选择了公式项，再复制。角标或搜索框中的复制只处理文本。粘贴 TeX 时先看实时预览和错误位置，再检查词典匹配，特别是同形符号和复杂宏。

渲染正确但关联不正确时重新选择词典条目和来源；应用不会从等式自动推断符号含义。跨资料库复制后要检查目标词典是否包含相应条目。

## DOI、网页信息或下载失败

检查网络、DOI 格式和来源地址。DOI 服务可能没有完整资料，可以手动补充；已有手动字段会保留。网络下载需要公开原件直链，登录分享页应保存为网页链接，或手动下载后导入。

## 流程图显示异常

检查源码错误提示，移除外部图片、HTML 和配置指令。图形会按完整内容边界自适应，可尝试调宽阅读区域或切换回当前标签页。复杂图拆分为多个块；导出 SVG 检查完整边界。源码最多 20,000 字符。

## 更新与备份习惯

更新程序后，`docs/wiki/` 中是随程序交付的最新手册。已有资料库中的手册副本可能是旧版，点击“使用手册”只会补齐缺失章节，保留原有页面和个人修改。需要最新说明时对照原稿，或将对应 Markdown 章节导入新页面。

更新前导出含附件备份，停止服务后更新程序文件，保留实际资料库目录和 `.mewiki/` 设置。安装依赖、重新构建、重启 MeWiki 后检查保存、附件和关键页面。定期把备份放到另一块磁盘。

项目检查命令为 `npm test`、`npm run lint`、`npm run build`，浏览器验证为 `npm run test:e2e`。这些检查不需要原项目、三维场景、回放服务或 Python。
