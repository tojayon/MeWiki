# 页面、标签与属性

## 页面管理

新建页面后输入明确的标题，并用正文标题块划分章节。页面列表可搜索标题和内容；大纲根据标题块生成，点击条目定位到正文。页面重命名仍保留稳定的内部标识，已有页面引用可以继续使用。

删除前会显示确认。被其他内容使用的理论、公式或符号可能受到引用保护；先检查反向链接并处理来源，避免丢失依据。需要大规模整理时，先导出完整备份。

## 用标签组织内容

页面和符号均使用标签分类。一个对象可以拥有多个标签，因此同一页面可以同时属于项目、主题和用途。

层级标签使用 `/`，例如：

```text
项目/机器人
方法/优化
阅读/待处理
```

在左侧选择标签进行筛选；层级结构方便从大主题逐步缩小范围。标签下显示的是同一份页面，修改一次会影响所有入口。符号词典也采用标签体系，旧式固定分类不再作为主要组织入口。

页面和符号的选择窗口共用左栏的标签分类表格。点击分类单元格展开或收起，搜索名称、记号或标签可缩小候选；搜索时会临时展开相关分类。一个对象有多个标签时可出现在多个位置，选中的仍是同一个对象。方向键沿当前可见条目移动，回车确认；中文输入候选确认期间不会提前插入。

这套选择方式用于正文 `@`/`$`、内容引用来源、理论依据、公式符号与结果、推导来源、变量配方、地图成员和关系节点。地图成员支持多选，已选状态在各个分类位置同步显示。

## 核对状态

页面可标记为待核对、核对中或已核对。状态表达人工检查的进度。内容或相关依据变化后，系统可能将原先已核对的内容恢复为“待核对”，提醒重新检查。筛选状态可以集中处理待办资料。

## 属性与 YAML

点击顶部“笔记元数据”信息图标，在浮窗中维护作者、日期、标签和自定义信息。空间不足时此入口收进“更多笔记功能”。需要文本方式时使用 YAML；解析失败会给出提示，修正后再应用。

```yaml
author: 我的名字
project: 入门项目
tags:
  - 项目/入门
  - 文档
```

字段按属性编辑器支持的规则保存。页面标题、标签等已有字段与元数据相互关联，使用编辑器预览确认后再提交，避免重复维护矛盾的值。

Markdown 导入导出支持前置元数据。完整迁移页面、词典与来源关系时使用[完整备份](15-storage-and-backup.md)。
