# 常用操作

快捷键作用于当前焦点。公式编辑区、正文输入框和角标浮窗之间切换时，先确认当前选区。

## 常用键盘操作

| 操作 | 用法 |
| --- | --- |
| 打开应用设置 | `Ctrl+,`；macOS 使用 `⌘+,` |
| 底栏快捷配置 | Tab 聚焦资料库、语言或插件图标后 Enter 打开上方卡片；Esc 关闭并返回图标。临时左栏中第一次 Esc 关闭卡片，再按一次关闭临时侧栏 |
| 打开或关闭使用手册 | 点击左侧面板底栏最右侧的书本图标，窄屏使用同一入口；左栏收起时先点击工作区图标临时展开，再次点击书本关闭手册标签页，点击章节才更换正文 |
| 复制、剪切、粘贴 | `Ctrl+C`、`Ctrl+X`、`Ctrl+V` |
| 全选 | `Ctrl+A`，作用于当前编辑区域 |
| 撤销 | `Ctrl+Z` |
| 重做 | 按编辑区提供的重做按钮，或其支持的 `Ctrl+Y` / `Ctrl+Shift+Z` |
| 页面引用 | 正文编辑时输入 `@` 并选择页面 |
| 术语引用 | 正文编辑时输入 `#` 搜索术语，可在“术语引用形式”选择规范全称、英文名称、缩写或别名；输入 `# ` 继续编写标题 |
| 符号插入 | 正文编辑时输入单个 `$` 或全角 `￥` 并选择词典条目；中文输入法确认候选后显示选择器 |
| 查看术语或符号 | 点击对应引用查看详情，所在段落保持排版；Esc 关闭详情 |
| 修改引用 | 在正文编辑器内聚焦引用，或把光标移到引用旁按 F2，在浮层中更换目标、显示形式或本次角标 |
| 正文加粗／斜体 | 选中文字按 `Ctrl/Cmd+B`／`Ctrl/Cmd+I`，也可先切换格式再输入 |
| 标题／普通段落 | `Ctrl/Cmd+Alt+1` 至 `6`／`Ctrl/Cmd+Alt+0` |
| Markdown 源码 | 点击正文后，使用本块右侧操作列、删除按钮上方的“编辑 Markdown 源码”图标；同一位置的“返回排版编辑”恢复直观输入 |
| 删除引用 | 在引用前按 Delete 或在引用后按 Backspace，整项删除；Ctrl+Z 恢复 |
| 完成本块 | Ctrl/Cmd+Enter 保存当前文字并选择下一内容块 |
| 分段与换行 | Enter 新起段落或列表项；Shift+Enter 在正文换行或继续列表项 |
| 列表选择器 | 方向键选项，Enter 确认，Esc 关闭 |
| DOI 查询 | 输入后自动查询；Enter 或移开焦点可立即查询 |
| PDF 搜索 | 输入词组后 Enter |

悬停工具图标可查看说明。组合键被系统或浏览器占用时，使用对应的界面按钮。

## 整理一篇文献

新建研究记录，添加项目与阅读标签，插入文献引用并填 DOI，检查自动补全的信息，再关联 PDF。阅读时复制页码引用，把问题、结论和自己的判断写到正文。稳定的定义另建基础理论，使用页面引用连接。

## 建立一条推导

先在词典定义符号和每个位置的含义，再在基础理论记录适用条件与公式。声明结果和输入配方，在研究记录复用公式来源，最后用反向链接、变量依赖和理论地图检查关系。

## 加入数据或附件

先确认已使用本地资料库，再导入媒体或大附件。需要绘图的数据放进数据块，其他原件用附件块。整理完成后导出含附件备份，确认能在新目录恢复。

## 让总览跟随详细笔记更新

在详细笔记中把需要复用的定义、公式或图片整理成独立内容块。回到总览插入“引用笔记内容”，从分类表格找到详细笔记，直接在渲染后的内容旁多选，再点击顶部“插入引用”。以后在详细笔记维护内容，总览自动展示同一来源的最新版本。想扩大或缩小范围时使用“修改引用范围”。
