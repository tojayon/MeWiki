资料交换协议、附件引用与旧格式迁移保留兼容。默认只包含 19 篇手册、2 篇通用示例和 4 个通用数学符号。测试使用临时目录，没有连接原研究资料库。

大文件真实检查可按需执行：

```powershell
$env:MEWIKI_MEDIA_LARGE_TESTS = '1'
npm test -- server/researchMediaLarge.test.ts
Remove-Item Env:MEWIKI_MEDIA_LARGE_TESTS
```

该检查覆盖 100 MB、500 MB 和 1 GB，需约 3 GB 可用空间。常规单测已覆盖大小边界、分片、校验、备份和冲突逻辑。
