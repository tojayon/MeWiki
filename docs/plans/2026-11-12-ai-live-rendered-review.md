# AI 实时协作与渲染差异实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** AI 运行时在中央逐步呈现正在生成的修改，默认以笔记原生渲染呈现增删改，完整建议仍由用户批准后保存。

**Architecture:** 在现有三协议传输和 NDJSON 上增加受限工具参数增量；草稿解析与授权校验在独立纯函数中完成，草稿只存在任务内存。中央沿用审阅宿主和原生只读内容组件，默认渲染前后内容，纯文字保留词句强调，源码比较作为可选视图。任务自动跟随最新建议，用户返回编辑或主动导航后暂停跟随。

**Tech Stack:** React / TypeScript、现有 Markdown / 公式 / 表格渲染、Vitest、Edge Playwright；不新增运行依赖。

## 取舍与边界

- 选择工具参数真实增量；只在完整建议到达后自动打开会让长段生成仍处于空等，直接写真实笔记则改变现有批准与保存边界。
- 中央按当前建议呈现，其他已生成建议保留在右侧，可主动选择；不新增自动保存或批量批准。
- 不完整参数不执行工具、不计入已读、不进入建议列表、会话或历史。只有已授权且已读取的已有笔记可以预览修改；最终调用仍走原注册表的完整校验。
- 中止、失败、关闭和切库清除未完成草稿，已完成建议保留。返回编辑暂停跟随，提供重新跟随入口；用户主动浏览旧建议时不抢回视图。
- 渲染复用现有安全链接、HTML 禁用、公式和内容控件，不把 Markdown、链接、公式源码直接拼进 HTML。复杂结构按渲染后的整块前后比较，纯文字进一步突出词句。
- 源码与资料格式、工具操作范围、宿主 v1 保持兼容；服务端更新后构建并重启已确认的本项目正式服务。

## Task 1：传输增量

- 文件：`src/ai/types.ts`、`client.ts`、`server/aiTransport.ts`、`aiServicePlugin.ts` 及相邻测试。
- 新增 `AiToolStreamUpdate = { key: string; name: string; arguments: string; reset?: boolean }`；`arguments` 是增量，`reset` 时替换缓冲。`AiStreamEvent` 增加 `type: 'tool'` / `update`，回调名 `onTool`。
- 先验证三协议分片、客户端参数限制、取消和跨分片密钥脱敏，再实现；只在回调和本机传输增加事件，保留既有上游协议。

## Task 2：暂态草稿与任务状态

- 文件：新 `src/ai/drafts.ts` 及测试，`runner.ts` / 相邻测试，`AiWorkspace.tsx`。
- 解析旧建议的顶层字符串参数，以及原生更新中受限的一层字符串 fields；目标字段必须完整才开放预览。内容允许尚未闭合的字符串，正确处理转义、Unicode 与重复字段，复杂结构等待完整建议。
- runner 独立 `onDraft` 回调，不扩充可持久化 `AiRunProgress`；草稿不写 controller 或 session。停止和迟到结果有同样的代次校验。
- 工作区开始任务时自动开启中央协作，草稿／完成建议更新当前项；返回、主动选项和导航暂停跟随；提供停止与重新跟随。

## Task 3：默认渲染差异

- 文件：`AiProposalReview.tsx` / `.css`、相邻渲染测试；界面新消息统一由主任务补英文。
- 支持尚无建议的运行状态、正在生成的不可应用草稿、完整建议；保留原面板开关、44px 工具栏和恢复焦点。
- 默认使用原生只读组件呈现标题、段落、列表、表格、代码、公式和链接，红删绿增；复杂内容保留前后渲染，不拆开公式。提供源码视图图标切换。
- 自动更新不反复抢走焦点或滚动；窄屏必须能停止、返回和打开侧栏。

## Task 4：验收与文档

- Edge 用受控流证明完成 `done` 前中央已渲染，内容持续增加、草稿不可应用／不持久化，返回暂停、重新跟随、中止及迟到结果安全。
- 检查渲染态强调／列表／表格／公式／链接，源码切换，已有中央应用撤回、嵌套、过期、只读、英文与窄屏流程。
- 同步第 2、22 章手册、架构、开发和接手说明及集成契约；运行 `npm test`、lint、翻译、build 和隔离 Edge。
- 独立复核，记录实际结果；不提交、不覆盖已有修改和真实资料。
