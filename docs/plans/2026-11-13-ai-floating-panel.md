# AI 可移动悬浮聊天面板

目标：AI 聊天脱离右侧大纲，以常驻、可拖动及调整大小的非模态面板靠近笔记；点击空白不关闭，从选区唤起时优先避开原文并靠近选区。

方案：独立 `AiFloatingPanel` 管理窗口位置、尺寸、收起与键盘操作，`AiWorkspace` 保留聊天、任务、草稿及审阅生命周期。面板放在笔记原生 dialog 内，避免顶层遮挡；不添加遮罩或外部点击关闭，不抢占笔记操作。标题栏拖动／方向键移动，角部调整大小；收起仅隐藏聊天，正在运行的任务继续，明确关闭才中断并保留会话。位置／尺寸按稳定资料库 ID 保存，窗口与可视视口变化时限制边界，坏配置使用默认值。

选区入口额外传递临时矩形，不将坐标写入会话或笔记。每次选区请求重新展开并定位，优先右／左侧，其次下／上方；空间不足时选择遮挡原文最少的位置。单纯打开使用本库上次位置。右侧大纲、反向链接及变量配方与聊天相互独立，不再含 AI 标签。

实施与验收：

1. 新增几何单测，覆盖选区避让、窄屏／键盘视口、越界、坏偏好和缩放恢复，先观察缺少实现的失败。
2. 新增 Edge 专项，覆盖空白不关闭、真实拖动与调整大小、键盘及触屏、选区重定位、收起时任务继续、关闭恢复、按库隔离与窄屏菜单。先观察当前侧栏布局不符合要求。
3. 实现浮窗与几何模块，连接 `ResearchNotebook`、`AiSelectionToolbar`，清理侧栏插槽及重复关闭入口，保留保存／审阅规则。
4. 更新既有右侧布局相关断言与用户可见操作说明，保留对话、重试、选区、审阅及撤回的原有覆盖。
5. 同步第 2、22 章手册、架构、开发和接手说明，完成 `npm test`、lint、i18n、build 及相关 Edge 验收，再更新 `docs/VERIFICATION.md`。
