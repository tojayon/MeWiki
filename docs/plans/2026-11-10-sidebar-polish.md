# 搜索框与左侧面板修整

目标：搜索时只增加输入光标；设置入口靠右，底栏左侧预留账户区；四个工作区的左栏在内容较多时均可上下滚动。

实现范围：

1. 通过隔离配置和通用长列表复现滚轮问题，覆盖符号词典、基础理论、研究记录与理论地图。
2. 搜索输入统一复用公共焦点样式，移除搜索容器的额外描边、阴影和焦点变色。普通表单与按钮继续使用各自的交互样式。
3. 每个左栏仅保留一个有效滚动区域；让分类列表占满可用高度，搜索与底栏保持固定。验证滚轮与分类条目的 Home/End 导航。
4. 底栏预留可扩展的账户容器，将资料库入口和紧凑设置入口放在右侧。当前不实现登录，也不显示无功能的登录按钮。
5. 同步使用手册、开发说明和实际验收记录，运行完整单测、代码检查、构建及相关 Edge 验收。
6. 保留工作区已有修改，不提交。完成构建后核实本项目正式服务进程并重启。

主要文件：`src/ui-controls.css`、搜索框所属组件及样式、`ResearchNotebook.tsx`、`ResearchNotebook.css`、`LibraryManager.css`、`e2e/sidebar-interactions.spec.ts`。

验证：先在修改前运行新增 Edge 检查确认故障；修改后使用正式构建运行新增检查与手册、设置、分类选择、响应式工具栏等相邻回归。测试只使用隔离配置及虚构内容。
