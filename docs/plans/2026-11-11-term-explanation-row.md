# 术语与下方原子解释卡片

目标：完整术语在中间面板居中并保持单行；下方按原子顺序显示分段下划线，解释卡片统一放在下一行，从左到右排列。保留悬停片段变蓝、连接线和点击定位。

实现：将原有左右交替的多列网格替换为两行布局。标题与卡片行各自支持横向滚动，卡片不换行；连接线从对应下划线连接到卡片顶部，随尺寸与滚动更新。点击片段或下划线时，将对应卡片移入横向视野并聚焦。

验收：扩展已有 Edge 场景检查桌面居中、所有卡片在下方同一行并保持顺序，以及 720px / 390px 下的片段对齐、卡片横向查看、连接线与点击定位。先复现旧布局中卡片不在下方的失败，再验证修复。同步工作区和词典手册、开发说明；运行完整检查和相邻 Edge 回归后重新构建并重启本地服务。资料格式与用户资料不变。
