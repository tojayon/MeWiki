# 流程图放大预览实施计划

**目标：** 为“绘图与流程图”增加与图片一致的独立查看窗口，保留编辑、只读和嵌套内容中的查看能力。

**方案：** 沿用图片使用的 `DeviceInspectorModal`。流程图点击预览或工具栏放大图标打开窗口；草图从工具栏打开，避免抢占编辑画布的绘制事件。窗口使用当前完整边界的独立 SVG 图片，隔离 Mermaid 的样式和元素 ID，保持矢量清晰度。界面状态不进入资料，换块、切换模式或内容变化关闭旧快照。空源码、渲染中与错误状态禁用放大。

**技术：** 现有 React、原生 dialog、SVG、Microsoft Edge / Playwright，无新增依赖。

## 验收顺序

1. 在 `e2e/research-rich-content.spec.ts` 增加浏览器回归，确认旧实现因缺少放大按钮失败。
2. 在 `ResearchDiagramBlock.tsx` 接入共享窗口，在相邻 CSS 中增加宽度、完整图形显示和原生点击入口样式；在 `src/i18n/en.ts` 同步英文。
3. 覆盖鼠标、Enter/Space、Esc、关闭按钮、遮罩、焦点恢复、只读、草图、无写回、错误恢复与中英文窄屏。
4. 同步 `docs/wiki/14-diagrams.md` 的查看步骤及示例；检查 AI 投影、工具、建议与保存路径。本次纯查看状态无新增领域操作，不向模型注册界面工具。
5. 执行 `npm test`、`npm run lint`、`npm run build`、翻译检查，以及隔离配置与端口的相关 Edge 回归，记录实际结果。
6. 核对本项目正式服务并依照根目录维护要求重启；不得测试或改写真实资料，不自动提交。

## 实施记录

入口、矢量图片窗口、唯一无障碍标题、原生焦点恢复、中英文文案和第 14、21、22 章手册已实现。窗口只保存临时显示状态，资料格式、AI 可读投影、领域工具和批准保存流程不变。

审查发现 AI 审阅祖先也处理 Escape，先用专项回归确认第一次 Escape 会直接退出审阅，再仅在图形窗口打开时阻断键盘事件冒泡，保留原生 cancel。回归同时检查两级关闭、入口焦点、建议保留与笔记内容不变。无写回断言使用结构比较，避免初次规范化的 JSON 字段顺序影响；最终返回焦点由显式“查看修改”入口触发并验收。

实际检查与服务更新结果统一记录在 [验收记录](../VERIFICATION.md)。
