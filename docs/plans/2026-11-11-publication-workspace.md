# 图文导出样板与可视选择实施计划

> 接续当前共享工作区逐项实施，保留已有修改，不自动提交；沿用暂不重启正式服务的选择。

**目标：** 打开导出即能看到当前配置的样板；通过比例和清晰度选择画幅；在中间原文上选择内容与分页。

**架构：** 中间区域提供样式预览、选择内容和导出结果三个视图，保留两栏各自 44px 工具栏。样板在本地浏览器更新，与正式输出共用可信静态排版模块及原生阅读组件，不占用 Edge 图片生成任务。原文复用冻结只读上下文和正文组件，只记录本次内容范围、页签和分页；模板和已有像素参数保持兼容。

**技术：** React、TypeScript、现有受限 DOM 与静态 HTML、隔离无脚本 iframe、Edge / Vitest。

## 方案与取舍

- 采用本地即时样板。自动调用完整图片任务会占用单任务服务并反复等待浏览器启动；纯示意图则无法可靠反映当前模板。共用静态排版并在无脚本 iframe 展示短样板，实际图片仍由用户生成验收。
- 比例提供方形、竖向与横向常用比例；清晰度使用 720p / 1080p 等熟悉档位，超出当前服务上限的档位禁用。原有自定义像素值保留在高级设置，旧个人模板无需迁移。
- 清晰度改变时字号和留白同比缩放，比例变化允许重新排布；长图的高度由内容决定，上限放高级设置。
- 原文选择在中间显示完整只读正文，逐个顶层块提供勾选和此前分页，支持全选、清空和展开全部页签。保持原笔记及资料库不变。

## 实施步骤

1. 新增画幅领域检查：比例/清晰度换算、保留布局、长图上限、旧自定义参数与上限；先观察失败后实现。
2. 提取服务端静态排版中的无环境依赖部分至领域模块，服务端继续校验二进制图片；补共享样板和正式输出同源、安全与参数检查。
3. 新增样板预览组件：固定虚构内容、原生只读捕获、参数模板共用 HTML、无脚本 iframe、按容器缩放、配置更新取消过期工作。样板不请求生成任务。
4. 新增中间原文选择组件，接入视图切换、勾选/分页/当前页签，并将左栏尺寸改为比例/清晰度与高级设置。
5. 更新既有 Edge 导出场景并新增默认样板、配置变化、清晰度、真实原文选择、键盘/窄屏、跨库及无写入验收。
6. 同步第 20 章手册、开发说明、接续指南、插件/集成约定和验证记录；运行翻译、单测、lint、build 和相关 Edge，记录实际结果。

## 接续反馈：隐藏工具的占位

用户指出 Callout 等原生内容视觉偏左。核对到通用 `.research-note-block` 无条件保留右侧 28px（公式 40px）工具空间，左侧只有 8px；`.research-note-blocks` 及嵌套标签页还保留插入手柄缩进。阅读与静态导出没有这些编辑工具，却继续使用编辑布局。

修正共用阅读布局：没有直接编辑插入工具的内容块使用对称水平留白，没有插入手柄的块列表取消编辑缩进；嵌套标签页的特殊左缩进仅用于实际编辑工具存在时。导出依旧使用同一组件 CSS，样板、完整原文与真实图片同步更新；保留用户主动设置的媒体/标签位置与正文对齐。先以页面和实际静态输出的几何边距复现，再检查修正后左右相等及编辑按钮仍可用。

列表判断同时检查普通块与末尾插入工具，确保空笔记、空标签页也保留把手空间；通过桌面与 390px 的真实按钮边界和菜单操作验证。
