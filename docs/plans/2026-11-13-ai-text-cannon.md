# AI 修改文字大炮动效实施计划

**目标：** AI 自动跟随笔记修改时，在中央笔记可视区域底部显示大炮，转向当前可见改动并发射文字片段；不改变建议、审批及保存流程。

**实现：** 在 `AiProposalReview` 中增加独立的视觉覆盖层。复用本地分层 SVG 和已渲染的差异位置，原生 Web Animations API 只控制 transform／opacity。文字只以文本节点展示，不执行生成内容；底座固定，炮身转向并后坐，炮耳随转向但不随后坐。

## 1. 几何与文字片段

- 新建 `src/components/aiTextCannon.ts` 和相邻单测，先观察缺失实现的失败，再实现从转轴计算炮口、角度和文字增量。
- 验证左右瞄准、容器偏移／缩放、无效及背向目标、段落中部替换、删除与 Unicode 文字，不切开组合字符。

## 2. 视觉覆盖层

- 新建 `src/components/AiTextCannon.tsx`、`AiTextCannon.css`，从本地 `/brand/mewiki-text-cannon.svg` 载入并隔离内部 ID，保留单一矢量来源。
- 在 `AiProposalReview.tsx` 中将滚动区域置于定位容器内，仅运行中、自动跟随、笔记渲染预览且无错误时挂载。底部居中，小尺寸自适应，图层不接收鼠标／触屏，不参与可访问性朗读。
- 依据稳定块／标签页／字段位置，从新增或删除的渲染片段中取得落点。按最少 320ms 的间隔合并最新片段，瞄准 160ms、文字飞行 260ms、后坐和落点 180ms；无动画依赖。
- 滚动、缩放、隐藏页面及卸载时清理旧轨迹；不可见目标不发射，不因动效强制滚动。不回放历史，不产生写入；减少动态效果时保持静态大炮与透明度落点提示。

## 3. 浏览器验收

- 新建 `e2e/ai-text-cannon.spec.ts`，使用虚构笔记、受控流式响应与隔离设置／端口。
- 覆盖底部居中、按目标转向、实际炮口与轨迹、连续文字合并、停止及退出清理、滚动和视窗变化、减少动态效果、来源及笔记内容无意外写入；相邻 AI 审阅回归。
- 运行完整 `npm test -- --maxWorkers=2`、`npm run lint`、`npm run i18n:check`、`npm run brand:check` 和标准构建。浏览器验收针对固定隔离产物，保留共享工作区既有改动，不操作真实资料或模型。
