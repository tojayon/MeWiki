# 在浏览器新标签页中导出

点击笔记的图文导出入口时打开独立浏览器标签页，原标签页保留笔记、阅读位置与编辑状态，便于来回比对。新页铺满窗口并沿用模板与预览两栏工具栏；关闭图标只关闭导出标签页。

## 实现

- 用户点击时同步打开空白标签页，再等待编辑失焦提交后固定当前库、笔记与标签页快照，写入新标签页自己的临时会话存储并导航。
- URL 仅包含稳定资料库 ID 和随机会话标识；正文、目录和模板内容不进入地址。新页主动解除 `opener`，不启动笔记工作区控制器，不改写笔记缓存或入口资料库偏好。
- 刷新继续读取原快照；来源标签页切换笔记、编辑正文或切换资料库时，导出不随之跳转。取得新内容需从笔记重新打开导出。
- 资料库 ID 必须与快照匹配，插件仍需启用且版本一致。无快照、复制到其他标签页、变更库 ID、停用或卸载等情况显示明确提示。
- 关闭或离开导出页时取消生成与资源读取，并以可在页面离开后完成的请求释放后台任务；浏览器拦截新标签页或临时存储不可用时，原页保留现场并说明原因。
- 模板、下载、导出服务和资料格式继续沿用既有契约；本页不扩展插件或外部宿主的笔记访问能力。

## 验收

先确认旧界面不会打开新页，也不会提示新标签页被拦截；再检查实际新标签页、原页编辑与比对、刷新、关闭、任务释放、跨库隔离和失效链接，以及全部既有导出场景。同步第 20 章手册和开发说明，运行单测、代码检查、翻译校验、构建与隔离 Edge 检查。正式服务不用于测试。

实现与验收已完成：764 项单元测试、35 项隔离 Edge 检查通过，代码检查、翻译校验及构建通过。覆盖原页编辑与切换笔记、刷新和关闭、真实图片、后台任务释放、跨资料库保存模板、失效链接和新标签页被拦截。详细结果见当轮[验收记录](../VERIFICATION.md)。
