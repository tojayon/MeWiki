# MeWiki 界面精简与统一

**目标：** 按 “Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining.” 统一工作区、设置、词典、地图、AI 和导出界面，让内容与当前操作成为视觉主体。

**方案：** 保留浅色、4px 圆角、44px 单行工具栏和蓝红橙状态。共用中性色面板、分隔线与控件变量；只调整界面外壳，不覆盖正文、公式、图表、导出成品和差异审阅的语义配色。设置页用分组和对齐替代重复标题及说明卡片，重复教程按需查看，字段、数据范围、费用、密钥行为、错误和不可撤销提示继续直接显示。

## 实施顺序

1. 在 `src/index.css` 定义界面颜色变量，接入 `ui-controls.css` 与共享弹窗、笔记导航、右栏、地图和导出外壳；保留原有布局与数据契约。
2. 增加 `UiInfo.tsx/.css`，复用现有弹层定位、Escape 和外部关闭流程。提供明确的按钮名称、按需说明、键盘焦点恢复和窄窗口滚动。
3. 精简 `SettingsPage`、语言与字体设置、资料库与插件列表；减少重复页眉说明和卡片边框，保留搜索和路由、设置草稿与保存流程。
4. 词典移除重复分区说明，将模板教程、一致性扫描说明等放入信息入口；地图保留角色和关系图例，缩短重复操作提示。AI 与导出沿共享变量统一视觉，不改变提案审批或成品排版。
5. 同步 `docs/UI_GUIDELINES.md`、相关 `docs/wiki/`、验收与接手入口。新增有意义的 Edge 交互回归，运行已有设置、词典、导航、AI、导出相邻检查。

## 验收

- 桌面／390px、中文／英文，无控件裁切、横向溢出或滚动归属改变；左右开关始终可达。
- 信息入口支持点击、键盘、Escape 与外部关闭；必要提示仍在原操作附近，错误状态不隐藏。
- `npm test`、`npm run lint`、`npm run i18n:check`、`npm run build` 与相关 Edge 检查通过，截图目视核对。
- 本侧聊仅修改请求的 UI 与相邻文档／检查；保留工作区现有修改，不自动提交。测试使用虚构资料、独立设置、构建与端口，不操作正式服务进程。

## 当前实现

- 设置、资料库、插件和词典已以分隔线与行对齐替代重复说明卡片，语言直接选择、字体帮助按需展开；术语原子规则、错误和预览保留。
- 导出的样板、内容选择、设备边框及纹理说明改为相邻信息入口；数量只在内容分区出现。重要限制、云端发送范围、密钥清除和测试费用保持可见。
- 统一中性边框、背景与选中态，保留地图角色和关系线、AI 红绿状态、正文和导出成品配色。新增界面专项覆盖说明关闭与焦点、跨语言草稿、地图及导出窄窗口。
- 验收使用 `.mewiki/ui-clarity-*`、`127.0.0.1:5501` 开发预览和 `127.0.0.1:5502` 固定构建；源码变化触发刷新的场景改用固定构建重跑。最后相关 19 项 Edge 回归与 AI 服务专项通过，全量单测 1139 项通过，lint、翻译检查、隔离和标准构建通过，详见 `docs/VERIFICATION.md`。
