# 导出工作区自动草稿实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**目标：** 调整导出参数、正文范围与图片创作后，刷新和重新打开仍可继续；未落盘或保存失败时阻止无提示离开。

**架构：** 宿主在 IndexedDB 保存工作草稿，按稳定库 ID、插件、导出器、笔记与入口模式隔离。每个导出标签页使用独立槽位，刷新读取自己的草稿，新标签页读取最近草稿；每个范围保留最近八份。草稿只包含导出配置、选择和本地图片，不保存笔记正文与成品。原笔记快照仍按原会话隔离。

**技术：** React、TypeScript、IndexedDB、Vitest / fake-indexeddb、Playwright / Edge。

## 1. 存储和恢复

- 新增 `src/state/publicationDrafts.ts` 与相邻测试：完整往返、Blob 原件、库和入口隔离、多标签页各自恢复、失败报告、有界结构校验。
- 草稿允许未完成的数值调整，生成时继续走严格校验。已删除正文块与页签不从旧草稿复活。
- 图片源记录文件 Blob 或同库作品原件标识，不序列化函数；主图和逐图编辑一并恢复。

## 2. 自动保存和界面

- 新增 `usePublicationDraft`，短暂合并频繁操作、串行保存，不让迟到保存误报新状态成功。
- `PublicationPage` 在挂载编辑工作区前异步读取草稿；`PublicationDialog` 初始化全部可编辑状态，参数变化自动写入。
- `usePublicationImages`、`useCompositionEditor` 支持初始化，`useCompositionLibrary` 恢复作品身份时校验保存基线，避免覆盖其他页面更新。
- 工具栏用图标提示保存中 / 已保存，失败显示原因和重试按钮。关闭按钮先完成保存，浏览器刷新、关闭和离开在未保存时用原生提示。
- 系统 / 个人模板切换仍重置参数；自动草稿不更新个人模板或暗中创建作品。结果图片重新生成。
