# 图片创作画布实现计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将图片创作作为与笔记导出并列的主要模式，在左侧画幅定义的唯一画布中编辑文字、贴纸、装饰图和设备，并以共用模板批量生成。

**Architecture:** 有版本的受限图层场景只保存相对布局，不保存第二套画布尺寸；预览和 Edge 导出共用静态 DOM/SVG。整批场景与按稳定图层 ID 的逐图覆盖分别保存。旧图片与笔记请求继续兼容。作品与个人素材按稳定资料库 ID 隔离，用户首次保存后才持久化本次主图。

**Tech Stack:** React、TypeScript、既有静态设备/纹理函数、本地字体、Vitest、Microsoft Edge / Playwright、zip.js（有界作品 ZIP）。

## Task 1：图层契约与静态渲染（已完成）

- 新建 `src/domain/publicationComposition.ts` 与测试，定义文字、系统贴纸、装饰图片、主体摆放、受限逐图覆盖、变量文字与相对布局。
- 扩展 `publicationTypes.ts`、`publicationImagePages.ts`、`publicationPagination.ts`、字体资源及模板交换；保持无新字段的旧请求输出不变。
- 先覆盖非法输入、模板/单图继承、安全转义、不同分辨率布局、字体和实际导出边界，再实现并验证。

## Task 2：编辑状态、批次与保存（已完成）

- 新建编辑状态与有界撤销/重做，拖动按一次事务，区分整批与当前图片。
- 保留已有懒读取与串行批量任务，传递全批序号、文案、逐图覆盖及字体；生成时冻结场景。
- 新建按资料库/插件隔离的作品与个人贴纸存储，显式保存、打开、作品包导入导出和修订冲突；停用插件不删除内容。

## Task 3：工作区和独立入口（已完成）

- 模板仍在左侧第一行；增加主要模式切换。
- 中间画布由左侧画幅决定，提供文字、贴纸、装饰图、主体的选择、拖动、大小/旋转、键盘和属性编辑；设备屏幕内与画布上的图层分别定位。
- 图层显隐、锁定、复制、排序；底部批次切换、变量文案、统一/单图编辑及恢复共用值。
- 接入已有资料库字体；独立打开空白图片创作，无笔记控制器和笔记写入。
- 保持单行工具栏、中性面板、原生焦点和窄屏可用性，新增文案同步英文。
