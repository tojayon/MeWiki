# 术语填写页整理

**目标：** 将术语填写页整理为有清晰层次、充分利用中间面板、在窄窗口仍可完整填写的表单。

**设计：** 沿用 MeWiki 的浅色背景、深色文字、蓝色强调与 4px 圆角。宽面板中并排展示“命名与引用”和“含义与使用”，名称、双语字段、规范引用预览及逐条别名集中在前一组，含义、范围和标签集中在后一组；下方用带顺序编号的编辑卡片整理原子词汇。窄面板自动变为单栏，依据中间面板宽度响应，避免展开侧栏后仍挤成双栏。输入框统一尺寸、字体、边框和聚焦状态；状态复选框与文字同排，底部明确提供取消和保存入口。

**取舍：** 保留现有表单流程和字段，不改成逐步向导；使用紧凑分区替代一长列和过多折叠面板，填写时可同时查看相关信息。术语详情图、正文引用、词典过滤与保存协议继续沿用现有实现。

**实施：**

1. 补充真实填写场景的 Edge 检查，覆盖宽面板利用率、随面板缩窄自动排版、草稿保留、长范围文字、移动端填写与底部保存/取消；先观察当前版不能满足布局要求。
2. 整理 `src/components/ResearchTermDictionary.tsx` 的编辑区，修改 `ResearchDictionary.css` 中限定于术语编辑器的样式，同步中英文消息。继续使用现有草稿与校验函数，不增加资料字段或依赖。
3. 同步 `docs/wiki/05-symbol-dictionary.md` 的分区填写及保存说明，补充开发说明。
4. 运行完整 `npm run check` 与术语、侧栏、翻译、手册的相关 Edge 回归，查看桌面与手机截图；只用隔离配置与虚构资料。
5. 记录实际验收结果，检查差异，核对正式进程后重新构建并重启服务，确认首页与构建一致。保留工作区已有修改，不自动提交。
