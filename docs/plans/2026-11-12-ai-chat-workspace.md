# AI 对话工作区实现计划

目标：保留右侧 AI 标签，改为上方对话历史、底部固定输入框与模型控件，符合用户明确提出的 Codex 式对话布局。

## 设计

- 采用独立滚动的聊天历史与固定底部输入区。会话标题和清空 / 设置 / 关闭图标收在输入框下方，不额外占用顶部一行；顶部仅保留与正文同为 44px 的面板标签。整体使用 flex 分区与独立滚动。
- 底部输入框支持 Enter 发送、Shift+Enter 换行，中文输入法确认不发送。运行中可继续写下一条草稿，发送按钮切换为停止任务。
- 输入框下放模型菜单、资料范围和发送 / 停止图标。模型菜单向上展开服务和本次模型设置，使用现有自配服务与模型逻辑；资料范围始终可见，详细说明在模型菜单内。
- 历史显示用户和 AI 消息、工具进度、来源、用量与非空建议，保留现有应用 / 撤回和基线校验。AI 回复复用正文 Markdown 渲染，代码和表格在面板内部滚动；用户提问保留原始文字。空会话显示简洁引导，快捷键说明留在手册。
- 新消息在用户停留底部时跟随滚动；向上阅读时保持位置，提供返回最新消息入口。底部输入区与侧栏标签切换生命周期不变。
- 复用原生表单与中性细边框，适配 300px 右栏、390px 窄屏及较短窗口；不引入运行时资源或修改服务、工具契约、会话格式。

## 实施与验收

1. 在 `e2e/ai-workspace.spec.ts` 新增几何与交互场景，先确认当前顶部表单布局失败：输入区吸底、历史单独滚动、多轮追问、模型菜单、Enter / Shift+Enter / 中文输入法、运行中草稿、返回最新消息。
2. 修改 `src/components/AiWorkspace.tsx` 与 CSS；更新中英文消息，调整已有 AI 场景到对话控件并保留原业务断言。
3. 同步 `docs/wiki/22-ai-workspace.md`、`02-workspace.md`、Agent 架构、开发接手与实际验收记录。
4. 执行全部 AI Edge 场景，目视桌面与窄屏截图；运行 `npm test`、`npm run lint`、`npm run i18n:check`、`npm run build`。相邻设置 / 侧栏验证使用独立构建输出，避免其他聊天生成 dist 时影响页面。
5. 保留已有工作区改动，不提交；本轮只改前端，构建后只读核对正式服务页面资源。
