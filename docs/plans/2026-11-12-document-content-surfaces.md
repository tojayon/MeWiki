# 正文容器底色与终端代码样式

**目标：** 表格、数据表、引用等内容容器在纹理背景上仍清晰，网页与图文导出统一使用近黑色终端代码样式。

**排查结论：** 共用正文主题的表格包装与单元格、数据表正文未设置实色底层；代码包装、工具栏与语法高亮仍采用浅色主题。Callout、标签页、引用笔记卡片、媒体、绘图与图表已有实色或用户指定底色，不应覆盖。普通段落、公式与图片透明区域继续尊重正文和素材本身的布局。

**实现：**

1. 用隔离 Edge 检查先复现透明表格与浅色代码，覆盖网页阅读/编辑、样板及真实输出。
2. 共用正文主题补齐白色表格与浅色实底引用；数据表从自身共用 CSS 修复。代码采用近黑底、浅色正文、深色工具栏和本地深色语法高亮，覆盖无语言代码、编辑源码和行内代码；不加额外交互蓝框。
3. 原生输出继续复用网页规则，参数模板复用同一代码配色与高亮；样板与服务字体样式入口同步，保留全部字体及纹理图层实现。验证多页表格/代码连续性及真实图片实色像素。
4. 更新第 4、20、21 章手册和开发/接续说明，运行单测、lint、翻译、构建和相关 Edge，记录实际结果。

**追加表头美化：** 用户要求移除灰色表头。普通表格、数据表与所有导出模板共用深墨蓝实底、明亮标题文字和浅色链接，正文与数据表行号保持白底；跨页表头保留同一配色。通过共用主题管理，避免逐处重复颜色。补充表头强调/链接的对比度、样板和真实 PNG 像素检查，更新相应手册。

**追加边框统一：** 外框和所有行列分隔线均使用表头同款深墨蓝，普通表格、数据表和参数模板一致。表头编辑时保留实底，输入文字和光标跟随单元格颜色，链接悬停保持浅色；回归验证点击输入、Tab 跨表头/正文以及保存结果。
