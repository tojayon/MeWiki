# 文字大炮命中呈现实现计划

**目标：** 文字炮弹命中后，才在对应位置显现修改，建立发射与正文变化之间的联系。

**设计：** 继续复用 SVG、WAAPI 和现有审阅数据。用 CSS Custom Highlight 的文字范围控制临时可见性，保留原排版、React 节点和完整审阅内容；回放按原始 UTF-16 位置分段，每段落地后显现对应文字，最后一段显现截断的剩余内容。同一处替换的旧文字在命中时隐去；结束、取消和不可用资源立即恢复完整差异，不改变建议、会话、笔记或保存时机。

**环境问题：** 已实测 Windows client-area animation 为关闭，Edge 与 Helium 在不覆盖系统媒体偏好时均返回 reduced motion。自动跟随继续尊重此偏好；主动点击回放只为本次播放启用完整运动，不修改系统或持久设置。新增真实逐帧位移检查，已先观察 0 帧的失败，再修复并通过。

1. 为 `aiTextCannon.ts` 增加原文偏移与 grapheme 前缀单测，覆盖 emoji、组合字符、折叠空白与长文末段。
2. 在 `e2e/ai-text-cannon.spec.ts` 添加命中前后截图像素检查，先观察提前显示文字的失败；保留真实逐帧飞行验证。
3. 增加 `aiCannonTextReveal.ts` 管理临时 Highlight，`AiTextCannon.tsx` 在布局阶段准备、命中阶段显现；流式更新只显现已命中的前缀。不可见目标、滚动／尺寸／偏好变化、停止、素材失败及卸载清理。
4. 回放队列绑定每段的原文起止位置，瞄准该段；超过队列上限的目标不隐藏。结束恢复完整审阅，快速完成与只读行为保持。
5. 更新第 22 章、AI 架构、开发／接手和验收记录。运行完整单测、lint、i18n、品牌、构建及大炮与相邻审阅 Edge；隔离端口 5551、`.mewiki/ai-cannon-visibility/`，只使用虚构资料和受控回复，不操作正式服务进程。

已完成：新增 2 项原文位置单测、5 项 Edge 场景并加强原回放检查，完整单测 1190 项与固定构建 Edge 65 项通过。批次、自动定位和旧词配对均先复现失败再修复；像素截图核对命中前后真实文字，逐帧核对真实位移。最终构建、语言、品牌及交付核对见[验收记录](../VERIFICATION.md)。
