# Agent 修改范围、并行编辑与任务接续实施计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 落实用户同意的前三项改进，保护选区外内容、保留独立的手动修改，并显式接续部分完成任务。

**Architecture:** 在现有工具与草稿共用入口校验选区源码范围，保留旧 v1 引用并在唯一可定位时补算范围；无法可靠定位时要求重选。应用建议按实际操作涉及的块／字段比较基线，使用当前资料生成结果与撤回快照。任务分段保留有界的成功读取日志、建议身份与摘要，在原服务、资料范围与基线重新校验后恢复读取状态并继续；仍由用户审阅保存，不持久保存模型私有推理。

**Tech Stack:** TypeScript、React、现有 remark 解析器、Vitest、Playwright / Microsoft Edge。

---

## 1. 精确选区边界

- 新增 `src/ai/selectionRanges.ts` 与相邻测试；维护 `textSelection.ts`、`AiSelectionToolbar.tsx`、`drafts.ts`。
- 先写失败测试：选几个词后改写前后文被拒绝；合法局部改写通过；Markdown 强调、跨块、列表、条件／结论、重复选文与旧引用均有明确边界。
- 使用可读文本到源码的保守映射及 DOM 选区上下文定位重复文本；保存每个字段范围，拒绝歧义和非法范围。完整建议必须保留所有范围外原文；流式片段不得提前显示范围外改动。
- 运行相关 Vitest，先确认失败原因，再实现并转绿；补 Edge 实际选词与模型越界回复。

## 2. 独立手动修改与 AI 建议共存

- 维护 `proposals.ts`、`nativeProposals.ts`，提取共用的操作依赖校验，补应用／预览／组合／撤回测试。
- 先复现同篇另一段、同块其他字段、标签页另页手改导致整项失效；实现仅比较修改所依赖的字段和容器身份，保留当前其他字段。
- 删除、移动和结构依赖采用严格边界；同一字段变化仍拒绝覆盖并提供原文／当前内容／AI 建议对照。撤回只恢复本次实际改变的内容，不回滚先前手动修改。

## 3. 部分完成与继续任务

- 新增有界 checkpoint 类型／恢复校验，维护 `runner.ts`、`chatActions.ts`、`session.ts`、`AiWorkspace.tsx` 及英文文案。
- 先写预算、停滞、刷新恢复、继续去重、原文／供应商／选区／材料变化拒绝接续等失败测试。
- 每个完整工具批次记录成功读取参数与建议身份；达到预算／停滞标为部分完成，保留摘要。用户点击继续后核对原请求范围、服务和基线，重新执行本地只读工具恢复权限，不重复提问或登记已有建议；新的执行段保留原预算限制。
- 普通新提问、编辑重发、重试、停止、切库和历史归属继续沿用既有边界。

## 4. 文档与验收

- 同步 `docs/wiki/22-ai-workspace.md`、AI 架构、接手／开发说明与验收记录；不修改已有用户手册副本。
- 完整运行 `npm test`、`npm run lint`、`npm run i18n:check`、`npm run build`，隔离固定构建进行相关 Edge 回归，检查截图及文档链接。
- 使用独立测试配置与虚构资料；保留共享工作区已有修改。本轮在现有工作区接续，不自动提交或推送。
