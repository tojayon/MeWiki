# MeWiki Logo 接入计划

**目标：** 将用户确认的蓝白 M 与黑底方形图标应用到 MeWiki，并保留完整 Logo 和其他变体作为项目内资源。

**实现：** SVG 原件统一保存在 `public/brand/`。使用已有 Sharp 依赖生成浏览器、桌面快捷方式所需的 PNG、ICO 和 README 横幅；所有引用均为项目内资源。替换静态品牌标志，不改动资料库和正文。

## 任务

1. 保存既有目标文件基线，保留未提交修改与暂存关系。
2. 引入完整 Logo、圆形标志、方形和圆角应用图标；提供 `scripts/generate-brand-assets.mjs` 统一生成派生文件。
3. 更新 `index.html` 的浏览器、触屏图标和应用清单；在左侧导航、设置品牌区和关于页显示新图标。保持单行工具栏及原有键盘导航。
4. 更新中英文 README 横幅、快速开始手册和开发维护说明。
5. 执行 `npm test`、`npm run lint`、`npm run i18n:check`、`npm run build`，使用独立配置完成 Edge 桌面、手机宽度、设置及手册相邻回归。核对图标 MIME、尺寸、完整加载和所有资源均为本地。
6. 复核本轮差异，更新验收记录；确认常驻 MeWiki 进程身份后更新本地服务，仅对正式服务检查静态资源。

本轮不自动提交；所有浏览器检查使用虚构示例和隔离配置。

## 实际结果

品牌资源、浏览器图标、导航、设置与关于页以及中英文首页已接入，相关手册同步完成。767 项单元测试、37 项 Edge 相邻检查及最终构建后的 4 项手册复查通过，构建、翻译与派生资源检查通过。

当前服务已确认能提供最终前端和新图标；重启操作被自动审批审查以“策略阻止”拦截，未执行。详细证据见 `docs/VERIFICATION.md` 的同日品牌接入记录。

## 方形轮廓修正

按用户反馈重绘方形构图：左下笔画继续向画幅下方延伸，右侧蓝白飘带沿原曲线延伸至右侧，去掉圆形裁切留下的内部弧形收尾。方形源图成为唯一笔画原件，圆角、白底和透明前景及各版 PNG 统一派生；圆角版整体裁切背景与笔画。同步浏览器、主屏幕和 README 横幅，完成新轮廓的小尺寸、圆形遮罩和项目内显示验收。
