# 图文导出错误定位

目标：将“导出参数或内容无效”的合并提示拆为可操作的诊断，让使用者知道是哪项设置、纹理或内容失败。保留现有校验限制、旧模板与资料格式。

1. 先用尺寸范围、组合留白、纹理层、设备缩放、图片、原生内容和本地任务接口测试复现统一提示；在旧构建中验证样板同样缺少定位。
2. 共用固定的系统设置路径和校验工具；数值显示当前值及范围，组合约束给出参与冲突的参数与调整建议，不回显资源数据或用户路径。
3. 静态内容按本次顺序报告项号和类型；图片、原生快照、公式和 Markdown 排版保留上下文，实际解码报告图片来自正文、头像、封面还是纹理层。
4. 样板与正式生成沿用同一校验；中英文只在显示边界翻译系统字段、序号与原因，任务接口继续使用原有 `error` 字符串。
5. 同步第 20 章手册、开发／集成／插件文档与验收；运行单测、lint、构建及独立 Edge 回归，验证改正参数后可真实生成。使用虚构资料，保留现有工作区和正式服务状态。
