# 设备边框连续圆角修整

目标：修复手机机身和屏幕转角不匹配、圆角偏大与缩放边缘粗糙的问题。保留现有边框参数、模板格式、正文样式和并行开发修改。

1. 先增加手机横竖屏的四边等厚、圆角中心一致和圆角比例检查，并在 Edge 验证连续曲率、四角实际像素及 720p/1080p/1440p。
2. 手机以同一机身规格生成屏幕内缩区域，机身圆角从 62 缩至 44，四边统一 12，屏幕圆角由内缩量推导。横屏使用同一组几何旋转。
3. 本机 Edge 157 已实测支持 CSS `corner-shape: superellipse(1.6)`，用于边框、屏幕及边缘高光。较旧浏览器保留相同尺寸的普通圆角；现有圆弧安全区域是保守范围，也能保护连续圆角内的文字。
4. 将外壳和屏幕几何直接换算到最终输出像素，取消设备父层整体缩放；只有正文保留与原分页相同的同比缩放。细化金属边线与听筒位置。
5. 同步使用手册、开发说明和接手记录，运行单测、lint、构建及设备相关 Edge 回归，并目视检查真实输出。保留当前服务状态，不打断主聊天。
