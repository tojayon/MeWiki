# MeWiki 独立设置页

目标：将应用偏好、资料库维护和插件管理整合为可搜索、可直接打开的应用内设置页，保留笔记阅读与编辑现场。

设计参考：[VS Code 设置](https://code.visualstudio.com/docs/configure/settings)的搜索、分类和作用范围；结合 MeWiki 本地优先、多资料库的特点组织内容。桌面采用分类侧栏与内容双栏，手机收纳为分类选择器。保留浅色、4px 圆角和 44px 顶栏。

## 实施顺序

1. 为设置 URL、返回路径、库身份保留和搜索匹配补充测试，先验证缺失行为。
2. 增加设置导航与页面容器；进入设置时保留笔记组件，返回恢复焦点、滚动和草稿。
3. 复用并拆分现有语言、资料库、存储与恢复、插件组件，统一入口，不另建数据操作逻辑。
4. 加入分类、搜索、当前资料库说明、已有阅读与侧栏偏好，以及版本和帮助入口。常规偏好即时生效；迁移、恢复保留检查和确认流程。
5. 完善中英文与手册，更新相关浏览器验收入口。
6. 运行翻译检查、单测、lint、build，以及 Edge 设置、语言、资料库、媒体和工具栏检查；目视核对桌面和手机。确认正式服务身份后重启加载构建。

测试只使用隔离示例和临时目录；不提交推送，不覆盖真实资料。
