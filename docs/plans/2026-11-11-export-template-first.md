# 图文导出模板优先布局

**用户目标：** 模板设定放在左侧面板的第一步，系统模板、个人模板、保存当前配置和其他模板操作集中在前面。

**布局：** 左侧第一组为“模板”，首行并排显示“系统模板”和“个人模板”。下方依次提供模板名称、保存、复制、删除、导入导出和恢复默认样式。之后再显示内容与画幅、字体与配色、封面与作者信息。窄屏沿用同一顺序，模板选择与保存操作在打开窗口后即可看见。

**取舍：** 只把系统模板上移会继续分散管理入口；把模板选择改成额外标签页会增加一次切换。因此集中现有操作，不增加标签页或新的模板格式。系统模板选择不依赖个人模板读取成功，个人操作沿用读取中、保存中、生成中禁用规则。

**兼容：** 继续复用现有模板加载、保存、复制、删除、导入导出和静态渲染。明确选择系统模板或恢复默认样式时退出个人模板选择并清空待保存名称，避免随后误以为仍在修改原个人模板。个人模板持久内容、原生共享样式、资料及插件契约保持兼容。

**验收：** 更新现有 Edge 用例，检查桌面与 390px 的模板首行、模板操作位于内容前、保存重开、切换后旧模板仍可恢复及真实图片导出。同步第 20 章使用手册、英文文案和实际验收记录，运行单测、翻译检查、lint、build 与导出专项。沿用用户暂不重启正式服务的选择。

**结果：** 已完成，742 项单测与 5 项 Edge 导出检查通过，翻译、lint 和构建通过；桌面与窄屏截图已目视核对。实际过程见[验收记录](../VERIFICATION.md)，本轮未重启正式服务。
