# Agent 原生内容操作接入计划

**目标：** 让 MeWiki Agent 能读取和定位原生内容，并通过可审阅、可撤回的建议管理笔记、标签页、符号、术语与理论地图。

**架构：** 保留现有文字建议与会话格式；增加受约束的结构化领域操作。工具定义与执行共用字段契约，复用现有领域校验和 controller 保存。新增操作在独立模块实现，再接入现有审阅。不得覆盖并行进行的流式预览工作，不自动提交。

1. 在 `src/ai/nativeEdits.test.ts` 先覆盖标签页中的编辑、完整词典字段、引用保护、基线冲突、撤回与持久化，再实现 `nativeEdits.ts` 和字段契约。
2. 增加带路径、内容和分页的块读取、完整词条和地图读取；现有内容修改必须先读，严格遵循笔记授权范围。插件私有数据及附件原件不进入 AI 投影。
3. 注册结构化操作，覆盖笔记属性与删除、原生块增删改和移动、标签页管理、符号及术语增删改、地图及关系管理。容器使用专门操作，保留内部稳定 ID；附件只引用已知资源。
4. 扩展建议、审阅、按项应用和撤回、会话恢复。记录领域操作连带改变的核对状态，防止撤回覆盖后续内容。中央审阅显示用户可理解的字段与渲染内容。
5. 更新 `docs/wiki/22-ai-workspace.md` 和 `docs/ai/ARCHITECTURE.md` 的能力清单及维护契约；用类型覆盖约束防止新增原生内容后遗漏 Agent 接口。
6. 运行专项测试、`npm test`、`npm run lint`、`npm run i18n:check`、`npm run build` 和隔离 Edge 检查。测试仅使用临时示例资料。侧聊实现已移交主聊天统一整合；由主聊天完成最终验收并重启已确认的 MeWiki 正式服务。

## 实施与验收状态（2026-11-12）

上述能力已接入工具契约 v3，并与[实时协作](2026-11-12-ai-live-rendered-review.md)整合。容器及子块定位、精确字段查询、读取分页及预算、词典与地图范围、插件私有字段隔离、controller 批准保存及安全撤回均有专项覆盖。新增 ID／初始化时间稳定；会话保留 v1，并恢复原生效果快照。内容类型和动作由穷尽检查约束，新字段仍需主动维护。

最终核心／工具联合专项 7 文件 99 项通过，全量单测 1045 项通过。独立复核发现的合法操作误拦与旧文字／原生建议衔接问题已增加失败回归并修复；地图仅导航不阻止撤回，AI 实际改变的视图路径和后续内容编辑继续校验。最终 Edge、文档与服务记录见[验收记录](../VERIFICATION.md)。
