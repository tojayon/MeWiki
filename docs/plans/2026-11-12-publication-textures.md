# 图文导出背景纹理

用户已批准将纹理放入左栏“样式”分类，沿用现有样板、导出和个人模板流程。

## 实施顺序

1. 为可选纹理参数、旧模板兼容、确定性生成和素材校验增加测试。
2. 共用背景层提供无纹理及暖白纸纹、棉纸纤维、点阵手帐、工程方格、横线稿纸、亚麻织纹、柔光雾面、边缘水彩；保存颜色、强度、大小、质感、方向、范围和种子。
3. 在样式中加入预设参数、三个本地变体候选，以及本地图片裁切、去光照、镜像接缝处理和三种配色候选。只在用户选定候选后应用素材。
4. 个人模板沿用 v1 格式，纹理属于宿主可选参数；不扩展插件清单契约。缺失纹理字段的旧模板保持原样。
5. 同步使用手册、开发说明和接续记录，运行单测、lint、翻译检查、构建与隔离 Edge 验收，检查真实成品和移动端。

## 验收要点

- 默认无纹理；换模板恢复其完整参数，折叠设置不丢值。
- 样板和 PNG/JPEG、分页、长图、封面使用同一背景样式。
- 自定义图片只接收有界本地 PNG/JPEG，不传本地路径，不联网；关闭、换模板和新上传取消迟到操作。
- 生成变体只改变候选，选择后应用；模板备份包含纹理参数和处理素材，不包含正文。
- 原生选择、滑块和按钮保留浏览器反馈，不额外添加蓝色描边。
