# 主界面用户字体实施计划

> 在当前共享工作区实现，保留现有字体、导出边框与其他修改，不自动提交；沿用用户暂不重启正式服务的选择。

**目标：** 在“设置 → 通用 → 界面字体”选择或导入当前资料库的字体，即时应用到主界面与笔记普通文字，刷新后恢复。

**架构：** 复用 `userFonts.ts` 的 100 MiB 字体校验、附件与 IndexedDB 原件。界面偏好按稳定资料库 ID 保存在浏览器，不改笔记协议；工作区提供器管理 FontFace 加载、根级字体变量和清理。界面与导出共用原件并通知同库窗口刷新列表，导出参数仍独立。

**技术：** React Context、TypeScript、FontFace、CSS 变量、现有资料库服务、Vitest 与 Edge / Playwright。

## 选择与边界

- 采用现有字体库，避免用户为界面和导出重复导入。仅填写系统字体名称无法稳定跨设备使用，另建界面字体库则会重复保存与备份，因此沿用当前资源模型。
- 通用设置增加字体选择、导入及下载原件的纯图标按钮；默认项恢复 MeWiki 原来的字体。设置可搜索，中英文和窄屏可操作。
- 根级变量覆盖普通界面、表单、菜单、导航和笔记正文；原有明确指定正文黑体的规则改为同一变量并保留默认回退。公式、代码、PDF 内嵌文字和专用图形字体保持自身排版，不用全局通配符强制覆盖。
- 每库单独保存偏好；切换资料库取消旧加载、移除旧 FontFace 和变量，迟到结果不生效。加载失败保留字体选择以便重新导入修复，并安全回退；无存储权限时当前会话仍可选择。
- 字体原件的完整备份和迁移机制不变。界面偏好与导出模板参数分开，不自动改正文或导出模板。
