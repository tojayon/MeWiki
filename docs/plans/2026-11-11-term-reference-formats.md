# 术语双语名称与引用形式实施计划

**目标：** 术语保存英文名称、英文缩写、中文缩写和逐条别名；正文通过稳定条目引用，逐处选择名称、规范全称、英文名称、两类缩写或具体别名。

**架构：** 版本 8 保持不变，三个名称字段和稳定别名记录均为可选字段。保留已有 `aliases: string[]` 供旧格式使用，新增可选 `aliasEntries: { id, name }[]` 维护别名身份，两者在保存时同步；旧别名按原文字生成确定身份，读取不改写旧资料。引用在 `mewiki-term:` 地址的查询参数中记录显示形式及别名 ID，未指定形式的旧链接继续显示名称。规范全称使用 `名称（英文名称, 英文缩写）`，空字段自动省略；被移除的缩写或别名回退为名称。

**技术栈：** React / TypeScript、现有 Markdown 渲染、Vitest、Microsoft Edge / Playwright。

1. 在 `researchTerms.test.ts` 与 `researchLibraryFile.test.ts` 增加字段规范化、旧资料兼容、格式解析、缺失回退、别名改名与重排、搜索和资料往返检查，先验证失败。
2. 在 `src/domain/researchTerms.ts` 实现可选字段、别名记录、格式化与查询参数；同步 `researchLibraryFile.ts` 的类型校验、`researchChoices.ts` 的搜索数据和 `ResearchMarkdown.tsx` 的显示。
3. 改造 `ResearchTermDictionary.tsx` 的名称字段与逐条别名编辑，详情和 `ResearchTermPopover.tsx` 展示对照名称。保留原子词汇解释图及各字段草稿。
4. 在正文 `@` 选择器增加术语引用形式选项，默认仍按原操作插入名称；选择别名形式时逐条列出候选。规范全称与所有缩写按当前词典实时解析，引用地址保留稳定身份，现有笔记与符号选择不变。
5. 增加 Edge 场景，验证创建/编辑与重新打开、按英文或缩写搜索、规范全称插入、中英缩写和别名引用、改名后同步、取消/键盘与窄屏。同步使用手册、开发说明、必要格式说明和验收记录。
6. 运行 `npm run check` 与相关 Edge 回归，目视核对界面；只用隔离虚构资料。复核后重新构建并重启本地服务，不提交或改写真实资料。
