# 官方插件提案：社交图文导出

日期：2026-11-11。状态：用户已批准实施，首版数据导出代码已落地，最终联合验收由当轮实际记录确认。操作与限制以[使用手册](../wiki/20-social-export.md)和 [API v2](../plugins/API_V2.md)为准；本文保留设计依据，未落地的 HTML/PDF 等仍是后续方案。

首版实施差异：入口位于“更多笔记功能 → 社交图文导出”；导出窗口选择顶层内容块，未新增块菜单专用入口；个人模板采用包含内联头像/封面图片的版本化 JSON，便于单文件备份，不提供设计中的 ZIP 模板包；模板由本地服务按库与插件持久保存。画幅、分页和静态内容以实际校验为准，不自动发布到平台。

## 目标与使用流程

面向在 X（推特）、小红书、知乎、微信公众号等平台分享知识的作者，把 MeWiki 的笔记或选定内容排版成适合发布的图片与文稿。第一版名称为“社交图文导出”，插件 ID 为 `org.mewiki.social-export`。

典型操作：

1. 在“设置 → 插件与集成”启用插件，打开笔记后从“更多笔记功能 → 社交图文导出”进入。
2. 选择整篇笔记或勾选顶层内容块，检查同步引用、标签页和资源的实际导出范围。
3. 选择平台预设与排版模板，例如“小红书知识卡片 → 清爽科普”。
4. 调整尺寸、字体、配色、留白、作者署名和页眉页脚，查看逐页预览。
5. 有需要时在块前添加分页，另存为自己的模板，再下载单张图片或多页 ZIP。

例如，一篇含正文、两条公式和一张图的笔记，可以导出为封面与数张知识卡片；换成 X 预设后重新排版为横向图片。内容保持原意，平台切换只改变呈现方式。导出专用标题和副标题由作者填写，首版不自动改写笔记。

## 现有能力与需要补充的基础

- 当前[插件 API v1](../plugins/API_V1.md)只提供声明式外部内容、表单和来源定位，不提供导出命令、面板、资料读取或任意代码运行。
- 当前已有[单篇 Markdown、带附件 Markdown 与资料库备份](../wiki/15-storage-and-backup.md)。它们继续保留，发布用导出另设入口。
- `ResearchReadOnlyContent.tsx`、Markdown、公式、图表和媒体组件可提供领域解析与显示逻辑参考；不能直接截取编辑器 DOM 充当发布排版。
- 项目已有 KaTeX、Sharp 和 ZIP 工具。首版补充运行依赖 `playwright-core`，由本机安装的 Edge 完成正式图片排版与生成；浏览器测试仍独立使用 Playwright 配置。
- 新能力不修改宿主 v1 协议、旧 evidence、未知插件数据和 `webbench-research-library` 资料格式。

## 三种实现路径

1. **通用导出引擎 + 声明式模板插件，推荐。** 核心负责读取用户选择、静态化、分页、图片生成和下载；官方插件提供预设与可调参数。以后社区也能使用同一契约制作模板。开发量集中在一次性的导出基础上，适合本次“部分自定义”的需求。
2. **直接截图阅读页面。** 原型最快，但编辑界面的宽度、折叠状态和交互控件会影响成品；难以稳定分页与更换平台版式。可用于技术对照，不作为正式方案。
3. **完整可执行插件与自由画布。** 自定义程度最高，但需要先完成隔离运行、编辑器贡献点、拖拽布局和更复杂的历史管理。待后续确有自由设计需求时再展开。

采用路径已补充到[阶段路线](2026-11-10-plugin-ecosystem.md)：只处理数据的图文导出贡献点提前落地，不依赖 P2 可执行隔离。[路线 P3](2026-11-10-plugin-ecosystem.md#p3编辑器命令面板与导入导出)的通用命令、面板及可执行导入导出仍以 P2 为前置；本分支不代表 P2/P3 已完成。

## 首版交付范围

### 导出格式

- PNG：适合文字、公式、线图的清晰导出，作为默认格式。
- JPEG：适合照片较多或希望减小体积的内容，提供质量调整。
- 多页图片：固定尺寸自动分页，可单页下载或按顺序打包 ZIP。
- 长图：适合连续阅读，达到引擎上限时建议改用分页，不能静默裁掉内容。
- 配套文案：可复制标题、副标题与正文纯文本；多页 ZIP 附带文案文件，便于在平台编辑器中使用。

首版同时提供三套可复用的视觉模板：清爽科普、学术笔记、重点卡片。模板与平台预设分开：同一视觉风格可以套用多种画幅。

### 平台预设

以下尺寸是首版设计起点，均表示最终图片像素，属于 MeWiki 的排版建议，不是已经核实的平台强制要求。平台规则会变化，预设需要版本化并允许覆盖。

- 小红书：默认 3:4 多页知识卡片，1080 × 1440；可自定义为 1:1 等画幅。
- X：优先提供 16:9 摘要或知识图卡，例如 1600 × 900，也可选择通用画幅。
- 知乎：优先提供纵向知识图和单幅解释图，允许自定义宽度及分页。
- 微信公众号：优先提供适合正文阅读的纵向图卡与长图，允许自定义宽度。

选择平台决定建议画幅、正文密度与输出组合；选择模板决定颜色、字体和内容装饰。界面显示最终尺寸和预计页数，不使用“保证平台兼容”的标识。

### 用户可调整的参数

- 配色：背景、正文、标题与强调色。
- 字体：从本地打包且许可允许分发的黑体或宋体中选择，调整正文字号与行距；标题按模板比例缩放。
- 尺寸与留白：预设或自定义画幅与页面留白。
- 封面：是否生成封面，标题、作者填写的副标题和本地封面图。
- 页眉页脚：页眉文字、页脚文字、作者名、头像或 Logo、页码与日期；文字可留空，页码可开关。
- 内容外观：模板统一排版标题、引用、公式和代码块，首版不提供各块的独立样式编辑。
- 保存：另存、重命名、复制和恢复默认参数；导入、导出个人模板。

个人模板保存实际参数快照、模板结构版本和基准模板版本，应用更新不悄悄重置配色与署名。首版不开放任意 HTML、CSS、脚本、远程字体或自由拖动布局。

手动分页属于当前导出任务的排版决定，不默认写回原笔记；保存个人模板时只保存通用规则，不携带某篇笔记的内容与分页位置。

## 插件与核心的分工

### 声明式导出契约

插件 API v2 已增加数据分支，提供图文导出贡献点、模板字段、默认值及参数校验。具体字段与安装示例见 [API v2](../plugins/API_V2.md)，不能作为 v1 清单安装。

- API v1 的类型、校验与运行路径继续兼容，不放宽现有未知字段检查。
- v2 不要求插件伪造一个外部内容类型才能登记导出器；允许导出用途的独立包。
- 插件选择核心支持的图片输出能力，声明模板、预设与可调参数，核心生成统一的导出界面。
- 核心按贡献类型处理，不按 `org.mewiki.social-export` 或平台名称编写特殊执行分支。
- 官方插件随应用提供，使用和其他插件一样的安装、启停、版本与校验规则。官方身份来自随附来源，不能由包自报前缀获得。
- 首版模板数据可内联在清单中；新增包资源类型、包大小与打包规则必须单独定义，不默认允许脚本文件。

这样可以先交付官方导出插件，也为社区视觉模板留下同一条发行路径；可执行运行环境仍按原计划独立验收。

### 数据流

```mermaid
flowchart LR
  A[当前笔记或所选内容] --> B[只读导出快照]
  B --> C[静态内容与资源解析]
  C --> D[模板排版与语义分页]
  D --> E[逐页预览]
  E --> F[本地生成 PNG 或 JPEG]
  F --> G[图片与 ZIP 下载]
```

宿主先提交正在输入的文字到编辑状态，再冻结当前资料库、笔记与选择的快照。插件获得的只是本次导出所需的数据与参数，不接收整个资料库状态、真实目录或任意文件读取能力。

同库同步引用只展开选择范围内的依赖，词典引用解析为当前名称或记号。预览与下载使用相同的快照、模板版本、字体和分页结果，不能临下载重新读取已经变化的正文。原笔记继续正常保存，导出专用标题与样式不回写笔记。

## 图片渲染与分页

### 渲染建议

推荐使用本地浏览器排版并逐页截图，Sharp 负责需要的图片编码与压缩，ZIP 工具负责顺序打包。理由是项目已有复杂中文正文、KaTeX、表格和图表，浏览器对这些内容的支持比另写一套 Canvas 文本排版更完整。

正式依赖与分发必须明确：实现时将所需浏览器控制库列为运行依赖，不能借用测试依赖充当产品能力。首版优先验证当前 Windows 环境中可用的 Edge；检测不到支持的浏览器时显示具体原因。跨平台浏览器随包分发属于后续决定，不在导出时临时联网下载。

导出页面仅渲染经过校验的静态内容，使用独立上下文，不打开普通应用首页读取资料库。它只能取得本次任务的内容、字体和资源；所有任意外部网络请求与其他本地 API 请求均被阻止。渲染服务只监听 `127.0.0.1`，使用同源校验和短期任务身份。

中文字体和数学字体本地提供，先确认字体加载、图片解码、公式和图表渲染完成，再测量并生成图片。检测不到资源或等待超时时指出具体内容，不把未完成的占位悄悄作为最终图片。

PNG/JPEG 的最终像素尺寸和清晰度倍率要在界面明确呈现，避免把“1080 像素预设”与额外倍率混淆。长图、最大页数、像素面积、执行时间与总包体设置上限，实际值根据技术验证确定。

### 按内容分页

自动分页必须建立在内容结构和实际测量上，不能先生成一张巨图再等高切割。

- 标题与后续内容尽量同页，普通段落按实际行高拆分；更细的孤行控制留待后续优化。
- 公式、单幅图和图注优先保持整体；超宽内容提供独立页面或用户确认的缩放，不能无限缩小正文。
- 表格按行拆分并重复表头；代码块按行拆分，不从字中间截断。
- 列表保持编号和层级，跨页引用块保留对应样式。
- 用户可在指定顶层块前分页，再次生成预览后查看结果；无法容纳内容时明确提示。
- 渲染后再检查正文边界与资源状态，出现裁切不得作为成功任务交付。

### 特殊内容的静态策略

- 标签页：默认导出当前所选页签，预览列出范围；用户可选择全部页签，按标题顺序展开。
- 同步引用：导出本次快照中的内容，之后原笔记变化不会改变已下载图片。
- 符号、术语和公式：保留当前显示形式，去除悬浮按钮等交互。
- 图表：使用对应的静态导出视图，不截取编辑器的工具和浮层。
- 音频、视频和 PDF：提供类型、标题或说明，视频有封面时保留封面；首版不展开整份媒体或 PDF 静态页。
- 外部插件与未知类型：保留可读标题、摘要和备注，不把原始 JSON、私有目录或程序连接参数放进发布图。
- 内部链接：转换为可读文字；只有作者明确提供的公开网址才作为对外来源展示。
- 网络图片：优先使用已保存的本地副本；未本地化资源在预检中提示处理，导出渲染器不自行请求外网。

## 设置保存、隔离与生命周期

个人模板、作者资料和 Logo 默认按稳定资料库 ID 与插件 ID 隔离。库 A 的署名和模板不能自动出现在库 B；跨库复用通过作者主动导入模板完成。

首版将这些内容视为插件配置，不改写笔记格式。MeWiki 本地服务按库与插件持久保存，笔记采用浏览器保存模式时也使用同一服务。个人模板通过版本化 JSON 导入导出，Logo 与封面以内联图片包含在单个 JSON 文件中；格式、图片类型与大小均有校验，不接收任意文件引用，也不提供 ZIP 模板包。

当前资料库备份不会自动携带插件包与授权。首版个人模板需要有明确的单独备份与恢复操作和说明；不要在未扩展备份协议前宣称它们已包含在现有资料备份中。插件卸载保留个人配置，清理模板与资产必须另行明确操作。

每次任务绑定库、选择快照、插件安装版本和模板版本；切库、停用、卸载或版本切换取消任务并释放资源。异步迟到结果不显示为新库的结果。同一本地服务一次处理一个生成任务，逐页处理并展示进度，支持取消；繁忙时提示稍后重试，取消后等待浏览器资源释放。临时资源在完成、取消或超时后清理，不永久缓存正文。

## 后续格式扩展

图片排版稳定后，再使用相同的静态内容层扩展：

1. **平台文稿。** 纯文本、Markdown 与可选的 X 分段草稿；分段规则可配置，用户检查后使用。
2. **适合平台编辑器的 HTML。** 提供保守的标签和行内样式。公众号、知乎各自验证粘贴效果，图片提供独立素材包；本地地址或 data URL 不能保证被平台接受。需要上传到平台的图片在流程中明确提示，不能宣称一键无损发布。
3. **PDF。** 复用排版引擎，保留可选择文本和链接，作为归档或分享格式。
4. **更深的模板设计。** 根据使用反馈再增加页面模块组合与高级主题能力。

各阶段产出均为用户可检查并自行发布的文件或文稿。账户连接与平台发布另立需求，避免把平台登录与上传流程混入首版导出体验。

## 实施顺序与验收

### 阶段一：先验证成品质量

使用隔离配置和虚构笔记完成本地浏览器渲染验证：中文、公式、表格、图表、嵌套内容、图片、缺失资源与多页。验证正式运行依赖、字体、尺寸、长图上限、逐页取消和资源清理，比较预览与实际成品。此阶段结果决定浏览器渲染方案与资源上限，不把验证页面作为用户功能发布。

### 阶段二：通用导出接口与官方插件

实现兼容 v1 的声明式导出契约、统一入口、范围选择、三套模板、四类平台预设、PNG/JPEG、长图与多页 ZIP、手动分页、个人参数持久保存及模板导入导出。用独立虚构模板插件验证登记与安装，证明没有官方插件专属分支。

### 阶段三：文稿与平台适配

增加静态 Markdown、文稿复制、平台 HTML 与素材包，再根据需要增加 PDF。分阶段验证目标平台编辑器的实际保留范围，记录已知限制，不能只用本地预览代替平台验收。

每一阶段进入用户可用状态之前：

- 同步 `docs/wiki/` 中的具体操作、示例、导出范围、模板备份和限制；首版建议增加“社交图文导出”章节，并更新手册目录、保存与备份、插件章节。
- 更新 `docs/plugins/` 的正式能力参考、`docs/integrations/README.md` 的相关边界、开发说明与路线状态。未实现字段继续放在提案中。
- 运行 `npm test`、`npm run lint`、`npm run build` 和相关 Edge 检查；通过后按本项目服务身份重新构建并重启正式服务。
- 验证模板参数往返、分页、缺失资源、多库隔离、取消和卸载保留内容；实际解码导出图片检查像素、页数、顺序和空白页。
- 使用固定虚构数据检查公式与中文、长标题、超宽表格、窄窗口及中英文界面；关注预览与成品的视觉差异，不只检查“下载成功”。

功能完成条件包括使用手册完整，手册和操作示例缺失时不标记阶段完成。测试不连接真实资料库，不自动提交、推送或上传任何导出内容。
