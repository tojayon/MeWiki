# AI 引用与精细修改对比

## 问题与行为

AI 对话的 Markdown 没有当前资料库引用上下文，有效的 `#research-note/<稳定 ID>` 被显示为已移除。对话接入当前库的引用上下文，用户点击时沿现有笔记阅读入口打开；历史、流式输出和只读查看共用解析，真正缺失的目标仍保持禁用。不按标题猜测 ID，不扩大发送给模型的资料范围。

修改预览保留当前整篇笔记、标签页与逐项决策。普通文字只在实际改动片段使用删除／新增标记；Markdown 保留标题、强调、列表、链接和公式的真实渲染，只突出对应词句。公式、代码和引用等不可安全拆开的节点作为最小完整单元。比较需要支持长段落中分散的小修改、换行变化与 emoji，并保持预算有界及两侧精确重建。

## 实施与验收

1. 用隔离笔记复现对话引用的错误状态，并覆盖编码 ID、真实缺失与刷新恢复。
2. 增加长段落、多处修改与富文本的先失败回归，改进有界文字比较和渲染中的片段标记。
3. 接通原有阅读导航，覆盖中央原生／旧文字建议、术语字段及源码切换，不改变批准、调整和保存路径。
4. 更新第 22 章、架构与接手说明；运行单测、lint、翻译、构建及相关 Edge 场景，目视检查桌面与窄屏。只使用虚构资料和受控回复。
