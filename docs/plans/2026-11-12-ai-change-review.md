# AI 中间笔记区差异审阅实现计划

> **For Codex:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 用户在中间笔记区按实际位置查看 AI 的增、删、改，审阅后应用，随时返回原编辑器。

**Architecture:** 右侧建议卡片打开中央只读审阅层，原编辑器保持挂载和草稿。预览复用 `applyAiProposal` 的纯状态转换和库／基线校验；未改动内容复用现有只读渲染，文字差异采用行级比较与行内字符强调。新增受限 `delete-text` 建议，仅删除明确的现有文字块，继续经用户批准和 controller 保存。

**Tech Stack:** React 19、TypeScript、原生 CSS、Vitest、Playwright Edge，无新增运行时依赖。

## 选择与范围

- 采用中央统一差异，红色 `−`／删除线与绿色 `+`／新增并列在原段落位置；上下文使用笔记原生只读组件。相比纯文本双栏，窄屏也能查看完整上下文；相比修改编辑器本体，不会把审阅标记写入资料或打断现有草稿。
- 每项建议独立审阅、应用和撤回；提供前后建议切换。新笔记整体显示为新增，追加在真实页尾显示，术语逐字段比较。
- 预览不会写入 controller 或资料；已过期建议保留快照供审阅并禁用应用。应用时再次校验。不实现逐行接受、任意笔记删除或结构块重写。
- 工具版本增加到 2，旧会话继续可读。改写优先使用 `replace-text`，明确删除文字时使用 `delete-text`，新增补充才用 `append`。
- 中央审阅通过稳定宿主渲染；桌面保留左右面板，窄屏审阅占满正文空间，关闭后回到原位置。切库、清空会话或关闭 AI 时清除预览。
