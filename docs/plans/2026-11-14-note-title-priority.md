# 笔记顶部标题空间与标签顺序

日期：2026-11-14。

## 用户目标

信息按钮位于标签管理按钮之前；标签管理按钮紧邻其右侧的标签徽标。空间不足时优先隐藏徽标，将可用位置留给笔记标题，放宽后恢复。

## 实施

- 交换 `ResearchNoteOrganizationBar` 的两个完整按钮，保留原操作、名称与弹层。
- 固定比例或只按窗口断点隐藏无法反映标题、字体与侧栏变化；采用正文工具栏实际宽度及标题实际字宽，预留必需工具后判断徽标是否放得下。
- `useResearchNoteTitleLayout` 观察工具栏、操作区和根字体样式，字体就绪后及内容更新时重新测量。网格按标题字宽分配，两侧共享余量；极长标题仍受单行及可见区域限制。
- 隐藏徽标使用零宽、不可见、`aria-hidden` 与 `inert`；保留子项自然尺寸以判断恢复条件，避免反复显示／隐藏。不改标签数据或标题输入实例。
- 保留既有 640px 紧凑模式与分屏行为，不改变词典或地图自身工具栏。

## 验收

`e2e/research-responsive-toolbar.spec.ts` 先复现旧版顺序相反、徽标挤占标题的问题，再覆盖中英文宽窄恢复、编辑与焦点、字体变化、增添标签、元数据草稿、基础理论与手机。同步第 2／3 章和 UI 规范，运行完整单测、lint、build 及相关 Edge 回归。只用虚构资料、隔离设置与固定构建，不提交或推送。
