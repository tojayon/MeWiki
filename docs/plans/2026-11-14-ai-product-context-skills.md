# AI 产品称呼、对象引用与资料库技能实施计划

**目标：** 用户不必记住产品术语，即可通过别称、当前对象和 @ 引用准确表达任务；资料库规范与可复用技能在新对话中沿用，并可检查本次生效内容。

**设计：** 共用产品模块目录维护标准名称、别称、帮助与适用动作；共用稳定对象引用维护当前笔记／符号／术语／地图和显式选中项。资料库默认规范、启用的技能和本对话固定要求分别管理。技能为有界文字工作流，支持默认启用、手动启用、按关键词／模块推荐及 Markdown 导入导出；不执行脚本或跟随外部路径，不增加工具权限。任务启动冻结规则与引用，重试／接续复用原快照，历史显示已启用的技能。

## 1. 模块目录与词典检索

- 新增 `src/ai/productCatalog.ts` 与测试：符号词典（符号库／符号表）、术语词典（术语库／术语表）、基础理论、研究记录、理论地图、资料库、使用手册。界面提示、帮助与 Agent 使用同一来源；操作说明以实际工具为准。
- 新增 `src/ai/dictionarySearch.ts` 与测试：现有 search_dictionary 保留 terms／symbols，补类型筛选、分页、total／nextOffset、相关性、别名与默认 tex，保持原预算和读取授权。
- 工具增加产品帮助检索，能力说明附标准模块名称；聊天通过稳定产品链接打开相应入口，不执行模型指令式导航。

## 2. 引用与情境操作

- 新增 `src/ai/references.ts` 与测试、`AiReferencePicker.tsx`／CSS：以稳定 ID 表达模块／笔记／符号／术语／地图，搜索名称／别称，中文、英文和重名路径可辨。
- 输入 @ 或点击引用入口打开选择器，选择后在原光标处插入可读的 `@名称`。按用户追加要求，引用直接参与自然语言段落，不再把每次选择都放在独立标签行；原生 textarea 保留光标、中文 IME、选字和发送键盘操作。独立固定对象与旧标签继续兼容。
- 新增 `inlineReferences.ts`，以 UTF-16 范围、显示文字与稳定 `{kind,id}` 绑定每处引用；同句多对象、重复对象与同名对象可区分。范围外编辑平移，触及内部解除关联，不按显示名重新猜测目标；最多 24 处、12 个不同对象、12000 字符。
- 发送后的引用在原句中可点击打开，复制保持自然语言；任务、恢复、重试和消息编辑分支保存范围快照。损坏或错配的重试元数据只禁用原任务重试，不丢弃对话文字。
- 当前页面对象显示在输入区，可明确附加；切换对象时不能使已选标签偷偷换目标。符号／术语／地图提供对应快捷提问；选区与行引用继续优先且保持原修改边界。
- 显式引用额外笔记只授权该笔记；模块引用不扩大整库权限。当前符号／术语页不再借用上一次笔记作为隐式目标，缺失引用明确提示。

## 3. 资料库技能

- 新增 `src/ai/skills.ts` 与测试、`AiSkillsPanel.tsx`／CSS：独立按库存储，版本和大小校验；规范最多 4000 字，技能数量／单项／启用总量有界，保存失败保留草稿。
- 技能包含 id、名称、适用描述、说明正文、关键词、适用模块、启用状态、是否默认；提供基础模板供复制编辑，不自动写入用户资料。
- 手动或默认技能实际发送，关键词／模块只推荐不偷偷启用；导入 Markdown 只预填待保存草稿，导出含完整正文，不调用任意脚本或路径。
- 任务冻结默认规范和技能正文；使用原规则重试，消息分支使用当前规范且保留明确引用。本对话固定要求继续兼容，规则优先级与生效范围在提示中明确。
