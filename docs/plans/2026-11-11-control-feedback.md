# 模板菜单文字与交互反馈统一

用户要求模板操作菜单在图标右侧显示功能文字，并移除控件原有反馈之外额外添加的蓝色外框。

## 实现范围

- 顶部模板操作入口保留纯图标；弹出面板的六个操作改为左图标、右文字，保留顺序、禁用状态、方向键与 Escape 返回焦点。宽度按文字和窗口调整，英文及手机不溢出。
- 删除全局为原生按钮、链接、输入框和选择框添加的蓝色描边及偏移；清理组件中的同类焦点描边、边框变色与描边阴影，恢复浏览器默认焦点反馈，不用全局 `outline: none` 隐藏焦点。
- 保留已有背景、文字、标签页标记和内容选择语义。已有选择背景时移除重复描边；自定义图表的必要选中标识只保留单层，拖放落点、编辑光标和内容配色继续表达原有含义。
- 透明原生选择框的可见外层采用轻量背景反馈，避免给外层再加描边；搜索框沿用用户已确定的静态边框和文字光标。
- 同步手册、开发说明和后续界面约定。模板参数、笔记内容、文件格式和服务接口不变。

## 验证

先在旧构建复现菜单缺少文字、模板选择额外描边和术语表单自定义边框，再检查桌面、390px、英文菜单、键盘焦点和方向键。检查导出、词典、内容插入、公式、标签页、表格、设置和理论地图相邻场景。运行单测、lint、翻译校验和构建；测试只使用独立本机服务和虚构资料。正式服务沿用用户暂不重启的决定。
