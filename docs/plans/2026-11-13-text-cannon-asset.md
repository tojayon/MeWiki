# MeWiki 文字大炮视觉素材

按最新反馈将深色炮耳改为带弧形高亮的正圆，并参考方形图标重画 M 左腿的饱满延伸，交付透明 SVG 和 1024px PNG，为后续文字发送动效保留分层。保留上提的薄炮嘴暗面和单个浅色底座，M 直接落在炮身上，没有圆形底托。此前版本保留在 `docs/VERIFICATION.md`。

## 造型

- 保留《捕鱼达人》参考的炮尾俯视关系，炮管沿中轴向远处伸出，内部不可见。炮身、炮管与肩部用一条连续轮廓连接，连接处控制柄共线，底部用饱满的近圆弧构成；轮廓圆角连接，不拉伸整张插画。
- 删除外围大圆盘，只保留原中间底座的大小和位置。底座表面为浅灰蓝，外沿为中性蓝灰；取消深蓝内盘及蓝色厚环。两侧炮耳使用标准 `circle`，圆心 `(360,583)`、`(664,583)`，外圆半径 52、内圆半径 46，深蓝渐变加黑色轮廓。整体范围为 `x=308–716`，分别比底盘左右边界伸出 20 个画幅单位。每侧上方使用一条半径 34、宽 7 的圆头圆弧作为高亮，统一左上光向。
- 炮嘴保持前后外沿同向拱起、中部高于两端，改用同一条平滑曲线的圆头宽描边绘制外壁与厚边，两端不再出现尖角。背面暗壁位于炮管与厚沿后方，曲线底端从 `y=383` 上提至 `357`，仅比两端水平线 `y=346` 低 11；其黑边从 12 减为 6。炮管遮住其中部，仅显露薄薄的两侧深蓝阴影，避免厚沿悬空或形成下垂的厚块；不绘制内壁、洞口或封口盖。
- M 从 `public/brand/mewiki-mark.svg` 内联并移除背景矩形。左腿参考 `mewiki-app-icon-rounded.svg` 的宽阔左下笔势重画：蓝白外弧与蓝色内弧沿腿部下行，左腿保持饱满宽度，以连续圆弧收尾；主体上部和右腿的路径保持。蓝色左腿的三处关键连接控制柄共线、同向，避免只把尖尾磨圆或拉成细钩。共用隐形蒙版在左下局部扩展，避免圆形边界重新截断延长部分。ID 添加 `product-monogram-` 前缀；192 × 192 的原 viewBox 和显示区域等大，父组仅平移。没有可见圆圈、圆形底色或徽章底托；不压缩、拉长或进行非等比投影，原品牌 Logo 文件不改动。
- 保留精简轮廓，取消横箍、尾钮和沿炮身的金属装饰线；炮耳为深色正圆面。炮嘴高亮复用厚沿曲线，炮管与左肩各用一条圆头宽描边，炮耳各有一条宽圆弧，不画尖细的锥状反光。颜色使用品牌蓝 `#2F94C7`、品牌黑 `#080A0D` 和浅灰蓝，4 个本地渐变提供大块明暗过渡。
- 全部为原生矢量，不嵌入参考截图、位图、游戏界面、数字、水印、字体、脚本或外链。Logo 源图不修改。

## 文件与动效预留

- 原件：`public/brand/mewiki-text-cannon.svg`，`viewBox="224 224 576 576"`，2048px 输出。画幅围绕当前单底座布局收紧，保留旋转和后坐所需透明空间。
- 派生：`public/brand/mewiki-text-cannon-1024.png`，由 `npm run brand:generate` 统一生成，`brand:check` 检查一致性。
- `cannon`：完整图形；`carriage` 包含唯一底座 `turntable`，`turntable-plane` 标记其平面。旧 `fixed-plinth` 和 `deck-plane` 已移除，运行时没有相关依赖。
- `aim`：炮身与深色正圆炮耳 `saddle` 的二维转向组，转轴仍为 `(512,551.7231)`。`saddle-left`、`saddle-right` 分别包含两层同心圆与高亮。`elevation` 保留炮身外层；当前未提供自动俯仰交互，二维转向不作为完整三维瞄准。
- `barrel`：独立后坐组，包含 `gun-form` 下的 `breech` 整体炮身、`tube` 蓝色炮管区、`muzzle` 圆头厚口沿和 `rear-emblem` 蓝白 M。后坐方向为 `(0,1)`，`saddle` 不随后坐平移；旧 `rear-cap`、`tail-handle` 已移除，没有运行时依赖。
- `rear-emblem` 内的 `product-monogram` 只绘制等比蓝白 M，左腿按方形图标的笔势单独适配大炮；源图的内部 ID 带 `product-monogram-` 前缀。转向及后坐只允许对外围组平移或旋转，不对笔画施加非等比缩放。
- `body-highlight`、`tube-highlight`、`muzzle-highlight` 分别为左肩、炮管与炮嘴高亮，均为圆头宽描边，随 `barrel` 后坐与转向。
- `saddle-left-highlight`、`saddle-right-highlight` 为炮耳高亮，仅随 `saddle` 转向，后坐时保持固定。
- `muzzle-rear-wall` 为炮嘴背面暗壁，位于炮管与口沿之前绘制，同属 `barrel` 后坐与转向；它表示背向光线的外侧厚度，不表示炮口内部。
- `muzzle-origin` 位于圆头厚沿最前方的中心，画幅坐标 `(512,295)`，发射方向 `(0,-1)`。根节点标记起点、发射、后坐方向及转轴。`muzzle` 保持 `data-bore-visible="false"`；`muzzle-rim-curve` 为两层厚沿共用的平滑曲线。
- 图形缩放、转向后从 `muzzle-origin.getScreenCTM()` 获取实际位置，再换算到动效容器；不能将旧版画幅或屏幕像素写死。普通静态展示直接使用图片，需要部件动画时使用内联 SVG。

后续接入已按用户授权完成为 AI 自动跟随修改预览中的装饰动效，见[动效实施计划](2026-11-13-ai-text-cannon.md)。用户发送任务后，炮身转向可见差异并发射简短文字；建议仍经审阅批准及 controller 保存，图形动效不负责写入笔记。应用头像和原品牌标志保持原样。

## 验收

核对单个浅色底座、伸出底盘的深色正圆炮耳与弧形高亮、连续轮廓、圆头炮嘴、上提后的薄背面阴影，以及没有圆圈底托的等比 M。对照方形图标确认左腿宽度和弧势，比较调整前后的左腿重心与足部位置，确认其他笔画几何保持且延长部分没有被蒙版裁切；检查圆弧切线、透明边缘、内部引用、48–256px 显示、Edge 渲染与独立后坐／转向，再运行品牌一致性、lint、i18n、单测及构建。使用临时检查目录，不读写用户资料。
