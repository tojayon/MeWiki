# 左侧底栏快捷配置卡片

日期：2026-11-14。根据用户要求，把资料库、语言和插件的常用操作放在对应按钮上方，保持中间笔记可见。

## 界面与行为

- 三个入口各打开一个非模态小卡片，白底、4px 圆角、中性细边框和短阴影，沿用现有纯图标按钮与悬停提示。一次只开一个；同按钮、外部点击、Esc 或关闭图标收起，Esc／关闭按钮恢复入口焦点。
- 资料库卡片列出已登记资料库，标记当前项，直接切换。沿用现有 workspace 的保存、切换与失败保护，切换失败留在当前库并显示具体原因。创建、迁移、改名、移除等操作由“管理资料库”进入完整页面。
- 语言卡片复用现有语言控件，即时切换简体中文／English，保留笔记、编辑草稿和当前页面。
- 插件卡片直接启停现有目录中的插件，保留原注册表及存储错误反馈；安装包、版本和卸载由“管理插件”进入完整页面。启停不改笔记内容，不增加宿主权限。
- 左侧临时浮层保留同样入口，卡片不被侧栏裁切，短窗口内部滚动。进入完整设置、切换内容／资料库或隐藏左栏时清理卡片，恢复时不留下悬空弹层。

## 实现与验证

新增独立底栏快捷组件，复用现有资料库／插件上下文及语言设置。卡片采用原有 popover 定位与关闭机制，增加顶部优先定位；不增加配置格式、服务 API 或 AI 工具。

先通过 Edge 复现点击入口仍进入设置的失败，再验证即时语言切换、双库隔离与保存、切换失败、插件启停与保存失败、管理入口、焦点、窄屏／短窗和临时侧栏。同步相关手册、集成说明及相邻测试，运行单测、lint、国际化和标准构建。

验收使用独立 `127.0.0.1:5591` 和 `.mewiki/footer-quick-checks/`，仅虚构笔记及受控目录，不读写真实资料或请求 AI。实际结果见 [验收记录](../VERIFICATION.md)。
