# 流程图矢量查看画布

**目标：** 在现有放大窗口中增加连续缩放和自由平移，让大流程图可以查看局部文字与节点。

**交互：** 打开时适应完整画布；滚轮围绕指针缩放，鼠标按住拖动平移，触屏支持单指平移与双指缩放。工具栏提供缩小、显示倍率并恢复原始大小、放大、适应画布。键盘在画布内使用加减号缩放、方向键平移、0 恢复原始大小、Home 适应全图。窗口大小变化保持当前中心，重新打开回到全图。Esc 沿用当前关闭与焦点恢复行为。

**实现：** 新增 `ResearchDiagramViewer.tsx`，复用常驻 `DeviceInspectorModal` 和安全的 SVG 图片快照，以 SVG 原始尺寸加变换实现矢量缩放，不栅格化、不重新调用 Mermaid。几何转换放在 `researchDiagramViewport.ts` 并验证光标锚定与窗口变化。查看状态仅在组件内，不更改资料格式、图形内容、导出、Agent 工具或批准保存路径。

**验收：** 先在旧窗口确认不存在缩放工具，再验证实际尺寸变化、光标锚定、拖动、100%、适应全图、键盘、触屏、窄屏英文、只读无写入、草图、AI 嵌套关闭和原生导出。完整单测、lint、翻译、构建和 Edge 使用 `.mewiki/diagram-canvas-*` 及独立 5493 端口；仅虚构资料。同步第 14、21、22 章和维护文档，最后核对并更新正式服务。不自动提交。

## 实施记录

已以独立矢量查看器替换初版按窗口宽度适配的图片，保留原有打开、关闭与焦点恢复。滚轮和双指缩放围绕操作位置，鼠标／单指平移无内容边界，支持 100%、Fit、键盘和窗口变化后的中心保持。最大显示倍率为原始图形的 6400%，不改变原图或导出尺寸。倍率既可见也作为按钮的无障碍描述；窗口中不重复添加操作说明。先在旧构建复现缺少工具栏，再以几何和真实 Edge 手势检查验证，结果见 [VERIFICATION](../VERIFICATION.md)。
