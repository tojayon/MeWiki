`ResearchSidebarTabs` 复用左右栏的按钮样式和实际 DOM 标签键盘导航；保留已有 tabpanel 的 ID 关联。右栏两个实际 header 通过相同 focusGroup 交接标签焦点，AI 激活不抢占该焦点；不重建聊天实例，不改变任务和草稿。

继续使用按钮原生焦点、title、aria-label 和 tooltip，不增加说明卡片；旧侧栏偏好和按库隔离保持。手册第 1／2／16／17／22 章和入口同步，旧用户手册副本不自动覆盖。
