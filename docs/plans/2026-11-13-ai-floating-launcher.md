# AI 浮窗视觉区分与常驻入口实施计划

目标：在白色笔记页面上清楚辨认 AI 聊天，保持轻量布局与跟手移动，并提供所有工作区视图可见、可拖动贴边的 AI 气泡入口。

方案：沿用浅色界面，聊天使用淡蓝灰底、深蓝 44px 标题栏、均匀中性细边框和短阴影；正文及输入区保持清楚可读，不增加重复标签。比整块深色面板更轻，比加厚阴影更易识别。入口为 44px 圆形 AI 按钮，替代底栏重复图标；用户可拖向左右边缘，松手贴边，方向键也可移动，位置按库记住。入口不自动隐藏，关闭和收起后仍在；设置中点击先返回原笔记再展开聊天，进行不可打断的存储操作时保持可见但禁用。

移动：Pointer Capture 保证鼠标与触屏持续拖动；每帧仅直接更新 translate，结束时才提交 React 状态与本库位置偏好。保留现有窗口尺寸、选区避让、临时视口恢复和逐项审阅；不对拖动增加惯性或跟随延迟。调整大小仍更新真实尺寸。紧凑菜单按浮窗坐标定位，不能因为 transform 成为定位容器后偏移。

布局补强：聊天为气泡所在边预留 56px，窄屏也不让气泡盖住输入、发送或菜单。ResizeObserver 的初次通知若边界未变，保留当前手势；真正视口变化时取消捕获并恢复已保存位置，不把临时投影写成用户偏好。激活、展开和输入聚焦分开处理，聚焦晚于设置返回的焦点恢复，避免收起后或从设置回来无法直接输入。

2. 在 `e2e/ai-floating-panel.spec.ts` 补入口关闭／收起／侧栏折叠仍可用，真实拖动不误开、键盘及触屏、刷新／按库恢复、设置返回与忙碌限制；保留原浮窗和审阅断言。先观察当前没有常驻入口的失败。
3. 增加 `AiFloatingLauncher.tsx/.css`，复用边界几何；连接 `ResearchNotebook`、`SettingsPage` 的忙碌状态和焦点恢复，清理底栏重复入口。
4. 精简 `AiFloatingPanel.tsx/.css` 的标题元素，调整聊天背景与输入布局；拖动使用 rAF 合并、translate 即时绘制，结束才保存。核对窄屏菜单与 Escape、外部点击行为。
