# 扁平模板与图文导出工作区

后续调整：本页记录最初实现。弹出模板菜单现已按[交互反馈统一方案](2026-11-11-control-feedback.md)改为左图标、右功能文字，顶部入口仍为纯图标；控件焦点使用浏览器自身提示。

**目标：** 内置和个人模板都表示一套可恢复的完整导出参数。选择模板会替换当前参数，用户随后继续调整；保存后即可像内置模板一样切换。导出标题、内容范围和手动分页属于本次笔记，不写入模板。

**方案：** 合并选择器，使用原生 `select` 的“系统模板／个人模板”分组，内部选值加来源前缀避免 ID 冲突。系统模板由通用默认值、插件默认画幅及模板声明解析完整参数；个人模板从已有快照读取。恢复操作重载当前选中项，保存当前个人项时更新原项，保存系统项时创建个人项。复制支持两类，删除只允许个人项，导出两类均可。

**界面：** 去掉导出窗口总标题栏，左右两栏各用 44px 工具栏。左栏为模板选择、模板操作和信息图标，六项操作以纯图标依次列在弹出工具面板；保存时才显示名称表单。三段说明只在可悬停、聚焦或点击的信息 tooltip 中显示。右栏为生成、取消、整包下载、复制文案和关闭图标。内容和预览独立滚动；窄屏保留两行工具栏，设置和预览依次滚动。全项目弹窗使用均匀的中性细边框，去掉蓝色顶部装饰。

**复用与兼容：** 继续使用既有 modal、popover 定位、图标动作规范、个人模板格式、修订冲突与隔离存储。原生主题引用仍与正文共用可信 CSS，不改变插件 API 或资料格式，不读写正式资料。

**验收：** 新增整套参数恢复的领域检查；Edge 验证分组选择、完整切换与恢复、保存及复制删除、导入导出、纯图标弹出面板、tooltip、Escape/焦点、桌面与窄屏工具栏，以及通用弹窗无顶部蓝线。同步使用手册、开发说明与验收记录，运行单测、lint、翻译、build 和相关 Edge。沿用用户暂缓正式服务重启的选择。
