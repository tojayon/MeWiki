# 井号术语输入入口

**目标：** 正文输入单个 `#` 立即打开专用术语选择框，输入查询后按名称、双语字段或别名搜索，并保留逐处引用形式。

**设计：** `ResearchMentionTextarea` 显式区分笔记、术语和符号三类输入会话。`#` 只显示术语，`@` 只显示笔记，`$ / ￥` 继续选择符号。术语弹框在空词典或无匹配结果时也保持专用标题、搜索框和显示形式选项，避免随候选内容改变类型。沿用原有分类、定位、IME、焦点、键盘与稳定引用协议。

单个 `#` 在正文和行首均可触发；继续输入第二个井号或紧随井号的空格时关闭，保留 Markdown 标题写法。转义井号、代码、数学公式、链接、URL 片段、HTML 和英文词内部的井号不触发。输入其他触发符时关闭上一类查询，选择替换只影响当前触发范围，Escape 保留原文。

**实施与验证：**

1. 先为 `findResearchTermMention` 补充失败检查，覆盖单井号、查询范围、标题、转义、代码、数学、链接与 URL；再实现解析。补充既有笔记与符号检测对井号边界的回归。
2. 更新共享正文组件为三类会话，复用现有术语引用形式及插入逻辑，同步中英文文案。将既有术语插入场景从 `@` 迁移到 `#`，增加空词典、标题输入、取消、笔记独立选择和 IME 两种提交顺序的浏览器检查。
3. 更新工作区、词典、链接与引用、分类、常用操作手册和开发说明，已有链接及资料格式保持兼容。
4. 运行 `npm run check` 及相关 Edge 检查，目视确认桌面与窄屏；记录实际结果，重启正式服务，核对首页与构建。只用隔离配置和虚构资料，保留已有修改，不自动提交。
