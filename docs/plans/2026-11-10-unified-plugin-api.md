# MeWiki 统一插件接口与本地安装实施计划

目标：完成插件路线 P0/P1，官方 WebBench 与本地社区内容插件使用相同的声明式接口、校验、视图、选择器和启停流程。首版不执行插件脚本；可执行隔离宿主、编辑器扩展与在线目录按后续阶段继续实施。

实现约定：

- 公开源码契约位于 `src/plugins/sdk/`；插件清单为纯 JSON，`manifestVersion: 1`、`apiVersion: 1`，实现版本使用 SemVer。所有插件的通用内容协议保持原样。
- 官方插件清单位于 `plugins/*/manifest.json`，由通用扫描登记；核心不按 provider 名称选择渲染器、选择器、请求服务或资料库。
- 内容类型声明受限 JSON schema、字段视图、来源 URL 规则及可选表单/目录选择器。清单只允许受限字段引用，不提供表达式、脚本、远程 schema 或 HTML。
- 本地插件通过 JSON 或仅含清单和说明的 ZIP 容器安装；后端检查包、兼容版本、摘要、重复身份和原子版本登记，支持卸载与版本切回。代码、安装信息不进入资料库。
- `IntegrationProvider` 统一加载官方与已安装清单，取消失效选择，保持旧 `mewiki:plugins:v1` 启停记录和未知状态。来源打开与插入由用户主动触发。
- 资料库管理从插件声明、当前外部连接和已保存的入口配置生成通用入口列表。移除按 Cislunar 名称推测资料库的行为；已有明确默认项和入口记忆继续生效。

实施顺序：

1. 补统一清单、受限 schema、字段引用、版本和注册表行为测试；运行确认旧实现无法满足。
2. 实现 SDK 与通用运行适配，把 WebBench 转为纯声明插件；用第二个通用测量插件证明不需要修改核心。
3. 独立实现本地包后端与恶意包、并发、升级回滚测试；资料库入口去专用分支可以独立实施。
4. 接通设置中的预览、确认安装、启停、卸载与版本切换，加入通用内容选择和详情显示。
5. 提供作者示例、校验/打包命令和稳定 API 文档，更新旧设计文档的实施状态。
6. 运行全部单测、lint、翻译、构建和 Edge；检查内嵌宿主 v1、WebBench 回放、第二插件、文件安装、未知内容保留和多资料库隔离。复核后构建并重启本项目正式服务。

工作区已有设置页和文档修改，逐文件保留，不自动提交。单元测试使用临时目录；浏览器使用独立配置和虚构服务。不会连接真实资料来验证迁移。
