# MeWiki 原生导出模板实施计划

> 按 executing-plans 逐项实现；保留现有工作区，不提交。用户已选择暂缓正式服务重启，本轮继续交付代码与隔离验证结果。

**目标：** 新增默认“MeWiki 原生”模板，让前端正文与导出正文使用同一份基础样式，后续修改共享正文样式会体现在重新生成的图片中。

**架构：** 将现有 Markdown 的静态排版提取到可信的共享文档主题模块，前端和本地渲染器直接消费。API v2 模板可用 `{ id, name, style: "document" }` 引用宿主文档样式，社区与官方走相同解析；旧参数模板和个人模板继续兼容。图片输出仍通过静态快照和分页引擎，页眉、页脚、画幅属于导出排版。

**技术：** TypeScript、CSS、React、Edge、既有声明式插件与图片导出服务。

## 设计取舍

1. 直接复制前端 CSS 到模板：实现简单，但修改前端后会再次分叉。
2. 只共享颜色与字号：能同步主题参数，段落、标题、列表、表格和代码仍会分叉。
3. 共用静态正文样式及默认参数：采用此方案。编辑按钮、悬浮态、侧栏等交互规则留在前端，不混入导出。

基础模板跟随当前版本的共享文档主题。个人模板保存明确的参数快照，升级不重写配色、字号与作者信息；使用原生基础的个人模板仍会跟随基础排版规则的修复。已下载图片不变，新版样式需更新应用、重新构建并重新生成图片。新增内容类型仍需对应的静态渲染适配，不承诺任意组件变更自动变成图片样式。
