# 社交图文导出实施计划

> 开发流程：按 executing-plans 分批实现并验证，保持当前工作区已有修改，不自动提交。

目标：交付官方声明式社交图文导出插件，支持模板参数、多平台画幅、PNG/JPEG、长图/分页、图片 ZIP、按库个人模板 JSON 和完整使用手册。当前代码与文档已落地，最终验收结果由主任务填入实际记录，不用此计划替代验证。

架构：兼容现有 API v1，新增只处理数据的 API v2 导出贡献。宿主固定所选笔记快照，将可发布内容与所需本地资源传给受限本地浏览器排版服务；预览和下载共用生成结果。插件只声明模板和预设。

技术：React、TypeScript、KaTeX、Sharp、ZIP、playwright-core 与本机 Edge，本地中文字体。

## 任务 1：导出贡献与随附插件

- 文件：`src/plugins/sdk/types.ts`、`manifest.ts`、新增导出契约文件、`plugins/social-export/manifest.json`、相关插件测试。
- 先补 API v2 接受导出用途清单、拒绝非法模板参数、v1 仍严格拒绝新字段的测试，观察失败。
- 实现模板和预设结构校验，允许 v2 的空内容类型与非空导出贡献；保留旧解析路径。
- 提供三套模板与四个平台预设，验证旧安装器与独立模板包可复用。

## 任务 2：快照、静态渲染与受限导出服务

- 文件：新增 `src/domain/publication.ts` 及测试、`server/publication*.ts` 及测试、`vite.config.ts`。
- 固定内容范围，解析公式、词典、引用、标签页与媒体，服务不读取用户资料目录。
- 先写输入限制、HTML 转义、分页与图片解码测试，再实现；使用虚构内容运行真实 Edge 渲染。
- 显式运行依赖和本地字体，阻止渲染器外网和其他本地 API，设置超时、配额和取消。
- 输出实际 PNG/JPEG，预览复用结果；长图超过边界时明确提示改分页。

## 任务 3：导出工作区与个人模板

- 文件：新增导出面板、客户端、模板存储及相邻测试；小范围修改 `ResearchNotebook.tsx`、`PluginManager.tsx`、中英文词典。
- 从统一导出菜单进入，支持整篇/勾选内容、模板/平台选择和全部已约定参数。
- 逐页预览、分页前标记、配套文案、单页/ZIP 下载。
- 个人模板按库隔离，支持保存、复制、通过名称编辑后保存进行重命名、删除和版本化 JSON 导入导出，卸载保留。图片资产内联在 JSON 中，首版未实现 ZIP 模板包。
- 切库、插件停用或换版取消旧任务；窄屏与键盘访问可用。

## 任务 4：手册、评审和最终验收

- 完善 `docs/wiki/` 操作章节、模板迁移与限制，更新开发/API/集成说明和路线。
- 进行需求与代码质量复核，解决重要问题。
- 运行 `npm run check`、导出专项及插件/多库/中英文/设置 Edge 检查；校验实际图片尺寸与分页顺序。
- 更新依赖许可证材料及实际验收记录，构建并核对身份后重启 MeWiki 正式服务。
- HTML/PDF、平台账户发布和自由画布保留为后续功能，不写成当前已提供能力。
