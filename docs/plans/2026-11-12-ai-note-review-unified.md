# AI 整篇笔记统一审阅实施计划

**目标：** 同一笔记的文字与原生修改累积在一个原生笔记页面中，标签页保持可切换；任务有进展时不在第 12 轮突然终止。

**架构：** 在纯领域投影中预检整组建议，再顺序组合，不保存。预览与用户批准共用组合转换；同一目标只显示一个页面，右侧点击定位修改。原生笔记 renderer 共用正常标签页组件，隐藏页切换后显示各自差异。任务调度独立保留总调用、上下文与无进展预算。

**技术：** React、TypeScript、Vitest、Edge / Playwright；沿用 controller 保存、会话 v1 与工具契约 v3。

## 实施与检查

1. `src/ai/proposalGroup.ts` 及相邻测试：旧文字与原生操作混合、不同块、同块多字段和重复操作累计、错误基线拒绝、删除与依赖冲突、不修改输入。批量批准记录每项效果，撤回保持安全。
2. `AiNativeProposalReview.tsx` 与 `ResearchExamples.tsx`：单一可切换标签容器，活跃页原位置差异；标签增删改移动、子块修改、新建和删除整容器仍可查看隐藏内容。文本保留词句差异和源码。
3. `AiProposalReview.tsx` 与 `AiWorkspace.tsx`：按业务目标分组，合并所有待审建议及暂态草稿；箭头只切不同目标，右侧逐项定位，中央支持批准当前笔记整组；冲突禁用批准，不静默遗漏。
4. `runner.ts`、提示词及测试：有进展允许更多轮；接近限制进入不再调用工具的总结；保留已有建议，重复无进展及时停止，取消仍拒绝迟到操作。
5. `e2e/ai-workspace.spec.ts`：模拟交替旧/原生工具、多标签多处修改，一页累计可见，切换标签、逐项与整组批准／撤回、连续生成、窄屏与英文。
6. 同步第 22 章手册、架构、接手与验收。运行 `npm test`、`npm run lint`、`npm run i18n:check`、`npm run build` 及隔离 Edge 检查。只使用虚构资料，保留已有工作区修改，不自动提交。
