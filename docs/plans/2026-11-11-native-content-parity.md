# MeWiki 原生导出内容与网页一致

**目标：** 原生模板保留网页阅读内容的结构、编号、图标和用户外观参数；正文组件及样式更新后，重新构建和生成即可同步。

**原因：** 当前三类静态内容快照将 Callout、标签页、媒体等降为普通 Markdown，网页组件的 DOM 和大部分 CSS 从未进入导出。只补基础主题无法解决。

**方案：** 保留现有参数模板。原生模板在当前上下文中用网页只读组件渲染所选内容，生成受限静态 DOM 树；本地服务校验标签、属性、内联外观和本地图片，只输出不可执行标记。构建自动收集应用 CSS 并生成内部导出样式，不另维护一份内容样式。沿用现有隔离浏览器、字体、分页、大小及取消限制。

1. 先补安全契约、内容保持和真实浏览器对照的失败检查，覆盖文件引用图标与粗体、完整笔记编号、定制 Callout、标签页主题和媒体。
2. 新增受限 DOM 快照和校验，拒绝脚本、事件、远程资源、任意样式 URL、越界树和过量正文。保持旧三类内容及模板文件兼容。
3. 原生渲染复用 `ResearchReadOnlyContent`、正文上下文及大纲；按需展开标签页，保留引用容器。PDF/图表 canvas 转本地 PNG，视频保留静态画面，音频保留播放器卡片；不自动播放。
4. 构建汇集网页 CSS，隔离渲染读取同一构建的内部样式；内容拆页保留祖先容器与完整文字，不裁断内容。
5. Edge 对照同宽网页与导出 DOM，并验证实际图片、分页、只导出所选块、标签页选择、样式更新同步及原参数模板回归。
6. 同步使用手册、API、开发约定和验收记录；运行单测、lint、翻译、正式构建和相关 Edge。继续保留既有修改，不提交、不读真实资料，按用户之前决定暂不重启正式服务。
