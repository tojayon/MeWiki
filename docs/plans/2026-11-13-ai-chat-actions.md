# AI 聊天操作与选区提问

目标：补齐单条消息／整段对话复制、失败或停止任务的手动重试，以及快捷提问和笔记文字选区入口。

设计：消息下方使用图标操作；失败结果与已完成建议保留，重试沿原服务、模型、授权笔记和选区重新运行，不重复用户消息，不清除后续草稿，也不自动应用建议。相同基线上的相同建议复用已有项。旧会话继续兼容，可选重试信息损坏只丢弃该信息。

选中文字后在附近显示 AI 入口，支持 Alt+Enter；范围只从笔记正文和稳定笔记／内容块标识生成，排除聊天、工具栏、跨笔记和非文字内容。输入框上方显示可移除的引用；快捷菜单填入任务要求，保留已有草稿，用户发送后才请求。选区任务限定其所属文字块，发送前核对原文，所有修改仍走待审阅与 controller 保存。

实施顺序：

1. 为选区校验、会话可选元数据恢复、重试范围／草稿／历史和跨尝试建议复用写失败单测。
2. 实现独立选区与聊天任务辅助模块，接入会话恢复及 runner 去重。
3. 增加复制、手动重试、服务加载重试、快捷菜单和选区浮动入口；同步英文。
4. 使用虚构笔记与受控回复进行 Edge 验收，覆盖失败部分结果、刷新、切换、草稿、选区来源、键盘和窄屏。
5. 同步第 22 章、AI 架构与验收；运行全量单测、lint、i18n、构建与相关 Edge 回归。

工作区有并行改动，只对现状做小补丁。禁止使用真实资料测试，不在本轮自动提交或推送。
